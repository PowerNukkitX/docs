## When to choose each framework?

- **PowerNukkitX:** Ideal for <span className="text-primary underline">modern servers</span>, <span className="text-primary underline">plugin development</span>, and <span className="text-primary underline">active community support</span>.
- **Nukkit:** Suitable for <span className="text-primary underline">legacy plugins</span> or servers that rely on older Nukkit plugins.
- **BDS (Official):** Recommended for a <span className="text-primary underline">vanilla Minecraft experience</span> with official updates and maximum compatibility with the Bedrock client.

---

## Migrating to PowerNukkitX

If you are switching from another framework:

1. Check plugin compatibility – some Nukkit plugins may require adaptation.
2. Export worlds and configurations, then import them into PowerNukkitX.
3. Review `pnx.yml`, permissions, and other configuration differences.

<Callout type="warning">
    Ask for help on <a href="https://discord.gg/pnx" target="_blank">Discord</a> or <a href="https://github.com/PowerNukkitX/PowerNukkitX" target="_blank">GitHub</a> if you encounter migration issues.
</Callout>
