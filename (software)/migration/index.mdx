If you are currently running a server using another Minecraft Bedrock software, you can migrate your configuration, world data, and resource packs to PowerNukkitX. 

Depending on your source software, select the appropriate guide below:

<Cards>
    <Card icon={<Hammer className="text-primary" />} title="From Nukkit / Lumi" href="/docs/migration/nukkit">
        Migrate from legacy Java server software. Includes details on our built-in configuration converter.
    </Card>

    <Card icon={<Layers className="text-primary" />} title="From Nukkit-MOT" href="/docs/migration/nukkit-mot">
        Migrate from the multi-version Nukkit-MOT fork. Automated config conversion and native world loading.
    </Card>

    <Card icon={<Boxes className="text-primary" />} title="From Nukkit PetteriM1 Edition" href="/docs/migration/petterim1">
        Migrate from the PetteriM1 multi-version Nukkit fork. Same automated config and world migration path.
    </Card>

    <Card icon={<Server className="text-primary" />} title="From Bedrock Dedicated Server (BDS)" href="/docs/migration/bds">
        Migrate from Mojang's official C++ server. Learn how to convert configurations and move LevelDB worlds.
    </Card>

    <Card icon={<CircleAlert className="text-primary" />} title="From PocketMine-MP" href="/docs/migration/pocketmine">
        Migrate from PHP-based PocketMine-MP. Understand plugin incompatibilities and config translation mapping.
    </Card>

    <Card icon={<Bug className="text-primary" />} title="From Dragonfly" href="/docs/migration/dragonfly">
        Migrate from Go-based Dragonfly. Move LevelDB worlds and rebuild compiled server logic as plugins.
    </Card>
</Cards>
