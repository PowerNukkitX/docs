## Minimum Requirements

| Component        | Minimum Specification                          |
|-----------------|-----------------------------------------------|
| CPU              | 2 cores, 2.5 GHz                               |
| RAM              | 2 GB                                           |
| Storage          | 1 GB free                                      |
| Java Version     | OpenJDK 21 or newer                            |
| Operating System | Windows 10 / 11, Linux (Ubuntu 20.04+), macOS |
| Network          | 1 Mbps upload for small servers               |

<Callout type="info">
    These are **minimum requirements** to run a small server with a few players. Performance may vary depending on world size and active plugins.
</Callout>

---

## Recommended Requirements

| Component        | Recommended Specification                     |
|-----------------|-----------------------------------------------|
| CPU              | 4+ cores, 3.0 GHz+                             |
| RAM              | 4 GB or more                                   |
| Storage          | SSD with 5 GB free                             |
| Java Version     | OpenJDK 21 or newer                            |
| Operating System | Windows 10 / 11, Linux (Ubuntu 22.04+), macOS |
| Network          | 10 Mbps+ upload for medium-sized servers      |

<Callout type="tip">
    For larger servers with 20+ players or multiple worlds, upgrading CPU, RAM, and network bandwidth is highly recommended.
</Callout>

---

## Java and Dependencies

PowerNukkitX requires **Java 21 or higher**. Ensure the following:

- Install a **64-bit Java runtime** (OpenJDK recommended).
- Set `JAVA_HOME` environment variable correctly.
- Make sure your system PATH includes the Java `bin` directory.

<Callout type="warning">
    Using outdated Java versions may cause server crashes or plugin incompatibility. Avoid Java 21 or earlier.
</Callout>

---

## Additional Recommendations

- **Backups:** Regularly backup `worlds/` and `pnx.yml`.
- **Disk Space:** Keep at least 20% free storage for logs and world growth.
- **Plugins:** Only install plugins compatible with your PowerNukkitX version to avoid errors.
- **Server Monitoring:** Use tools like `htop` (Linux) or Task Manager (Windows) to monitor CPU and memory usage.

PowerNukkitX is designed to be lightweight and flexible, but meeting the recommended requirements ensures **smooth gameplay**, **fast world loading**, and **stable plugin performance**.
