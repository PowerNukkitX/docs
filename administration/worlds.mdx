Each world (called a *level*) is a folder inside your server directory. The default world is named by the `defaultLevelName` option in `pnx.yml` (default: `world`) and is loaded automatically on startup.

## The Default World

The default world is created on first launch and is where new players spawn. To use a different world as the default, stop the server, change `baseSettings.defaultLevelName` in `pnx.yml`, and start it again.

```yaml
baseSettings:
  defaultLevelName: world
```

<Callout type="warning">
    Stop the server before editing `pnx.yml`. A running server rewrites the file from memory on shutdown and will overwrite manual edits.
</Callout>

## Importing an Existing World

You can move a world from another server or from a Bedrock client:

1. Stop the server.
2. Copy the world folder into the server's root directory.
3. Set `defaultLevelName` to the folder name (or load it with a multi-world plugin).
4. Start the server.

PowerNukkitX reads the Bedrock **LevelDB** format, so worlds exported from the Minecraft Bedrock client are compatible.

## Per-World Settings

Difficulty, spawn point, and game rules are stored per world and can be changed at runtime with commands:

```bash
difficulty normal
setworldspawn
gamerule keepInventory true
```

## Multiple Worlds

The core loads a single default world. To run several worlds at once - and teleport players between them - install a multi-world management plugin from [Jarbage](https://powernukkitx.org/plugins).

## Spawn and World Generation

- `playerSettings.spawnRadius` controls how far from the world spawn new players appear.
- `gameplaySettings.spawnProtection` protects a radius around spawn from edits by non-operators.
- Terrain is generated by the [Terra](/docs/integrations/terra) generator; chunk generation runs on the async worker threads (see [Performance](/docs/administration/performance)).
