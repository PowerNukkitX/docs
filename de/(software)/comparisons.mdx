PowerNukkitX ist nicht der einzige Bedrock-Server. Diese Seite stellt ihn Nukkit und Mojangs Bedrock Dedicated Server (BDS) gegenüber, damit du wählen kannst.

## Auf einen Blick

| | PowerNukkitX | Nukkit | BDS (offiziell) |
| :-- | :-- | :-- | :-- |
| Leistung | **Hoch** | Mittel | Hoch |
| Plugin-System | **Ja, Java** | Ja, Java | Nein |
| API | **Modern** | Veraltet | Keine |
| Neue Bedrock-Versionen | **Schnell** | Langsam | Offiziell |
| Open Source | **Ja** | Ja | Nein |
| Community | **Aktiv** | Mittel | Offiziell |
| Eigene Inhalte | **Gut** | Mittel | Gering |

## Welchen wählen

<Cards>
  <Card title="PowerNukkitX">
    Ein moderner Server, den du mit Plugins und eigenen Inhalten erweitern willst, mit einer aktiven Community dahinter.
  </Card>
  <Card title="Nukkit">
    Ein Server, der von alten, nicht aktualisierten Nukkit-Plugins abhängt.
  </Card>
  <Card title="BDS">
    Ein reines Vanilla-Erlebnis mit Mojangs offiziellen Updates und maximaler Client-Kompatibilität.
  </Card>
</Cards>

## Umstieg auf PowerNukkitX

<Steps>
  <Step>
    **Prüfe deine Plugins.** Manche Nukkit-Plugins müssen an die PowerNukkitX-API angepasst werden.
  </Step>
  <Step>
    **Nimm Welten und Einstellungen mit.** Kopiere deine Welten und übertrage deine Einstellungen nach `pnx.yml`.
  </Step>
  <Step>
    **Prüfe die Berechtigungen.** Lege deine Gruppen und Berechtigungsknoten neu an.
  </Step>
</Steps>

Jede Quelle hat ihre eigene Anleitung: [von Nukkit](/docs/de/migration/nukkit), [von BDS](/docs/de/migration/bds), [von PocketMine-MP](/docs/de/migration/pocketmine).
