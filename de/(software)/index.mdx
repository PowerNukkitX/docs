**PowerNukkitX** (PNX) betreibt einen Server für Minecraft: Bedrock Edition. Es ging aus Nukkit hervor und bringt mehr Leistung, eine reichhaltigere Plugin-API, eigene Blöcke, Items und Entitäten sowie ein Verhalten, das näher am Vanilla-Spiel liegt. Es eignet sich für einen privaten Server unter Freunden genauso wie für ein öffentliches Netzwerk.

Spieler treten mit dem normalen Bedrock-Client bei, auf jedem Gerät, ohne Mods. Alles, was der Server braucht, liegt in einem einzigen Ordner:

## Unterstützte Plattformen

PowerNukkitX läuft unter **Windows**, **Linux** und **macOS**, braucht **Java 21 oder neuer** und folgt den neuesten Versionen von Minecraft: Bedrock Edition. Die Seite [Voraussetzungen](/docs/de/requirements) nennt die Hardwarewerte.
