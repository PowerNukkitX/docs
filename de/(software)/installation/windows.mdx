Unter Windows 10 oder 11 installierst du Java 21, legst die Server-Jar in einen Ordner und startest sie über ein `start.bat`-Skript.

## Installation

<Steps>
  <Step>
    ### Java 21 installieren

    Lade den Windows-**MSI**-Installer von **Eclipse Temurin JDK 21** bei [Adoptium](https://adoptium.net/temurin/releases/?version=21&os=windows) herunter und starte ihn. Aktiviere während der Installation **Set JAVA_HOME variable** und **Associate .jar files**.

    Öffne dann eine neue Eingabeaufforderung und prüfe:

    ```bat
    java -version
    ```

    Du solltest Version `21` sehen, zum Beispiel `openjdk version "21.x.x"`.
  </Step>
  <Step>
    ### Einen Serverordner anlegen

    Lege einen Ordner für den Server an, zum Beispiel `C:\PNX-Server`.

    <Callout type="warn">
      Lege ihn nicht in `C:\Program Files` oder `C:\Windows` ab: Windows kann PowerNukkitX dort daran hindern, Welten, Konfiguration und Logs anzulegen.
    </Callout>
  </Step>
  <Step>
    ### Den Server herunterladen

    Lade die neueste `powernukkitx.jar` aus den [GitHub-Releases](https://github.com/PowerNukkitX/PowerNukkitX/releases) herunter und lege sie in deinen Ordner.
  </Step>
  <Step>
    ### Das Startskript anlegen

    PowerNukkitX braucht Java-Reflection-Flags (`--add-opens`), um seine Registry und Plugins zu laden. Starte es deshalb über ein Skript statt per Doppelklick auf die Jar. Lege im Ordner `start.bat` an:

    ```bat title="start.bat"
    @echo off
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    pause
    ```

    <Callout type="info">
      Lege sie als Textdatei an und benenne sie dann um. Aktiviere im Explorer **Ansicht > Anzeigen > Dateinamenerweiterungen**, damit die Datei wirklich auf `.bat` endet und nicht auf `.bat.txt`.
    </Callout>
  </Step>
  <Step>
    ### Den Server starten

    Doppelklicke auf `start.bat`. Beim ersten Mal fragt ein Einrichtungsassistent:

    - die Lizenz akzeptieren, indem du `y` eingibst;
    - eine Sprache wählen, zum Beispiel `deu`;
    - den Servernamen (MOTD) und den Port eingeben (Standard `19132`).

    Danach legt der Server `pnx.yml` und die Standardwelt an. Gib `stop` ein, um ihn sauber zu beenden.
  </Step>
</Steps>

Dein Ordner sieht jetzt so aus:

<Files>
  <Folder name="PNX-Server" defaultOpen>
    <File name="powernukkitx.jar" />
    <File name="start.bat" />
    <File name="pnx.yml" />
    <Folder name="worlds" />
    <Folder name="plugins" />
  </Folder>
</Files>

## Fehlerbehebung

<Accordions>
  <Accordion title="'java' wird nicht erkannt">
    Windows findet Java nicht. Wenn Java 21 installiert ist:

    1. Suche im Startmenü nach **Systemumgebungsvariablen bearbeiten** und klicke auf **Umgebungsvariablen...**.
    2. Prüfe unter *Systemvariablen*, ob `JAVA_HOME` auf deinen JDK-21-Ordner zeigt, zum Beispiel `C:\Program Files\Eclipse Adoptium\jdk-21.x.x\`.
    3. Bearbeite `Path` und stelle sicher, dass er `%JAVA_HOME%\bin` enthält.
    4. Öffne eine neue Eingabeaufforderung oder starte den PC neu.
  </Accordion>
  <Accordion title="BindException: Address already in use">
    Ein anderes Programm oder eine zweite Kopie des Servers nutzt bereits Port `19132`. Schließe das andere Serverfenster oder ändere `port` in `pnx.yml` (zum Beispiel auf `19133`).
  </Accordion>
</Accordions>
