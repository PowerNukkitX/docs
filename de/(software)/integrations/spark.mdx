[Spark](https://spark.lucko.me/) ist ein Leistungs-Profiler. Er zeigt, wohin CPU-Zeit und Speicher gehen, damit du die echte Ursache von Lag behebst.

## Einschalten

<Steps>
  <Step>
    ### Den Server stoppen

    Ein laufender Server überschreibt `pnx.yml` beim Herunterfahren, also bearbeite die Datei bei gestopptem Server.
  </Step>
  <Step>
    ### Spark aktivieren

    ```yaml title="pnx.yml"
    miscSettings:
      installSpark: true
    ```
  </Step>
  <Step>
    ### Den Server starten

    PowerNukkitX lädt die passende Spark-Jar nach `plugins/` herunter und lädt sie. Spark beobachtet dann alle Server-Threads im Hintergrund.
  </Step>
</Steps>

## Benutzen

Führe diese Befehle in der Konsole aus oder im Spiel als Operator:

| Befehl | Was er macht |
| :-- | :-- |
| `/spark profiler start` | Startet die Aufzeichnung. Lass sie einige Minuten laufen, während Spieler online sind. |
| `/spark profiler stop` | Stoppt und gibt einen Link zu einer Aufrufbaum-Ansicht mit CPU- und Speichergrafiken aus. |
| `/spark health` | Zeigt TPS, Speicher und CPU im Moment. |

Alles Weitere steht in der [Spark-Dokumentation](https://spark.lucko.me/docs).
