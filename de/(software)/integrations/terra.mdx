[Terra](https://terra.polydev.org/) ist ein Geländegenerator, der über **Config-Pakete** gesteuert wird: Jedes Paket beschreibt seine eigenen Biome und Landschaften. PowerNukkitX unterstützt ihn von Haus aus.

<Steps>
  <Step>
    ### Terra aktivieren

    Setze bei **gestopptem** Server:

    ```yaml title="pnx.yml"
    miscSettings:
      enableTerra: true
    ```

    Starte den Server: Er legt im Hauptverzeichnis einen Ordner `terra/` an.
  </Step>
  <Step>
    ### Ein Paket hinzufügen

    1. Wähle ein Paket, zum Beispiel aus den [Community-Paketen](https://terra.polydev.org/config/community-packs.html).
    2. Lege seinen Ordner oder seine ZIP-Datei in `terra/packs/`.
    3. Öffne die `pack.yml` des Pakets und notiere seine `id`, zum Beispiel `REIMAGEND`.
  </Step>
  <Step>
    ### Eine Welt anlegen, die es nutzt

    Lege in `worlds/` einen Ordner für die neue Welt an, zum Beispiel `worlds/end`, mit einer `config.json`:

    ```json title="worlds/end/config.json"
    {
      "format": "leveldb",
      "enable": true,
      "generators": {
        "2": {
          "name": "terra",
          "seed": 0,
          "enableAntiXray": false,
          "antiXrayMode": "LOW",
          "preDeobfuscate": true,
          "dimensionData": {
            "dimensionName": "minecraft:end",
            "dimensionId": 2,
            "minHeight": 0,
            "maxHeight": 255,
            "height": 256,
            "chunkSectionCount": 16
          },
          "preset": {
            "pack": "REIMAGEND"
          }
        }
      }
    }
    ```

    Ersetze `REIMAGEND` in `preset.pack` durch die id deines Pakets.
  </Step>
  <Step>
    ### Hinreisen

    Starte den Server und teleportiere dich in die neue Welt:

    ```bash
    /world tp end Dim2
    ```
  </Step>
</Steps>
