Ein Proxy lässt Spieler zwischen mehreren Servern wechseln (eine Lobby, Survival, Kreativ...), ohne die Verbindung zu trennen. PowerNukkitX unterstützt [WaterdogPE](https://github.com/WaterdogPE/WaterdogPE), mit IP-Weiterleitung und Sitzungsübergabe.

<ProxyNetwork />

## Jeden Unterserver einrichten

<Steps>
  <Step>
    ### Den Unterserver stoppen

    Bearbeite `pnx.yml` nur, während der Server gestoppt ist.
  </Step>
  <Step>
    ### Den Proxy-Modus aktivieren

    ```yaml title="pnx.yml"
    baseSettings:
      waterdogpe: true
      xboxAuth: false
    ```

    Der Proxy authentifiziert die Spieler, also dürfen die Unterserver Xbox Live nicht noch einmal prüfen: Bei ihnen steht `xboxAuth` auf `false`.
  </Step>
  <Step>
    ### Im Proxy eintragen

    Trage in der `config.yml` von WaterdogPE jeden Unterserver mit Adresse und UDP-Port ein, und stimme den IP-Weiterleitungsmodus des Proxys darauf ab.
  </Step>
  <Step>
    ### Neu starten

    Starte jeden Unterserver neu, damit die Einstellungen greifen.
  </Step>
</Steps>

![WaterdogPE-Konfiguration](../../../assets/proxy-config-waterdogpe.png)

<Callout type="warn" title="Inventare vor einem Wechsel schließen">
  Wenn du einen Spieler per Code oder Befehl auf einen anderen Server schickst, schließe vorher seine offenen Container (Truhen, Formulare). Sonst kann sein Inventar auf dem Zielserver aus dem Takt geraten.
</Callout>
