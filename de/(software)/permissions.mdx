Berechtigungen bestimmen, welche Befehle und Aktionen jeder Spieler nutzen kann. Es gibt drei Stufen, von der einfachsten bis zur flexibelsten.

## 1. Operatoren

Ein **Operator** (OP) überspringt jede Berechtigungsprüfung und kann jeden Befehl ausführen. Behalte das wenigen vertrauenswürdigen Admins vor.

```bash title="Console"
op <player>
deop <player>
```

Operatoren stehen in `ops.txt` im Hauptverzeichnis des Servers, ein Name pro Zeile. Du kannst die Datei bearbeiten, während der Server **gestoppt** ist.

## 2. Berechtigungsknoten

Befehle und Plugins prüfen **Berechtigungsknoten**: Namen mit Punkten, zum Beispiel:

- `nukkit.command.help` für `/help`
- `nukkit.command.gamemode` für `/gamemode`

Standardmäßig können normale Spieler einfache Befehle nutzen (`/tell`, `/list`, `/help`), Operatoren alle.

## 3. Ein Berechtigungs-Plugin

Für einen öffentlichen Server oder mehrere Gruppen reicht OP allein nicht. Installiere ein Berechtigungs-Plugin wie **LuckPerms**, das auf Nukkit und PowerNukkitX portiert wurde. Damit kannst du:

- Gruppen wie `admin`, `moderator` und `player` anlegen;
- Berechtigungsknoten an eine Gruppe oder einen einzelnen Spieler vergeben;
- Präfixe, Suffixe und Vererbung zwischen Gruppen festlegen.

<Callout type="info">
  Berechtigungs-Plugins findest du im [Plugin-Hub](https://powernukkitx.org/plugins).
</Callout>

## Sicherheits-Checkliste

<Steps>
  <Step>Lass die **Xbox-Authentifizierung** an (`xboxAuth: true` in `pnx.yml`), damit niemand unter dem Namen eines anderen Spielers beitreten kann.</Step>
  <Step>Vergib OP an so **wenige Leute** wie möglich und nutze Gruppen für alle anderen.</Step>
  <Step>Schalte für einen privaten Server die **Whitelist** ein. Siehe [Spielerverwaltung](/docs/de/administration/players).</Step>
</Steps>
