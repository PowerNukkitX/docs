---
title: "Schnellstart"
description: "Von null zu einem Server, dem du beitreten kannst, in etwa fünf Minuten."
icon: Zap
---

Am schnellsten geht es mit dem Kommandozeilen-Tool `pnx`. Es lädt den neuesten stabilen Build herunter und startet den Server für dich.

<Callout type="info" title="Du brauchst">
  **Java 21** oder neuer, **Node.js** (für `npm`) und 2 GB freien Arbeitsspeicher. Siehe [Voraussetzungen](/docs/de/requirements).
</Callout>

<Steps>
  <Step>
    ### Die CLI installieren

    ```bash
    npm i -g @powernukkitx/cli
    ```

    Keine globale Installation? `npx @powernukkitx/cli init` funktioniert auch.
  </Step>
  <Step>
    ### Den Server anlegen

    In einem leeren Ordner:

    ```bash
    pnx init
    ```
  </Step>
  <Step>
    ### Starten

    ```bash
    pnx start --memory 4G
    ```

    Starte `pnx` ohne Argument für ein interaktives Menü.
  </Step>
  <Step>
    ### Beitreten

    Öffne in Minecraft Bedrock **Spielen > Server > Server hinzufügen** und gib die Adresse deines Rechners mit dem Port **19132** ein. Auf demselben Computer nimmst du `127.0.0.1`.

    <Callout type="tip" title="Spieler auf einem anderen Gerät kommen nicht rein?">
      Bedrock nutzt **UDP**, nicht TCP. Erlaube den UDP-Port `19132` in deiner Firewall und leite ihn an deinem Router weiter, damit auch Spieler außerhalb deines Netzwerks beitreten können. Mehr unter [Fehlerbehebung](/docs/de/faq/troubleshooting).
    </Callout>
  </Step>
</Steps>
