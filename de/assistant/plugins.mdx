Die Ansicht **Plugins** durchsucht den [Plugin-Hub](https://powernukkitx.org/plugins) und installiert direkt in den Ordner `plugins/` des aktiven Servers.

## Marktplatz

Tippe ins Suchfeld, um ein Plugin zu finden. **Installieren** lädt das neueste **freigegebene** Release von GitHub herunter und prüft es gegen den SHA-256, den der Hub gespeichert hat, bevor es nach `plugins/` geschrieben wird. Starte den Server neu, um es zu laden.

## Installiert

Der Reiter **Installiert** listet, was der Assistant installiert hat:

- **Aktualisieren** erscheint, wenn es ein neueres freigegebenes Release gibt;
- **Entfernen** löscht das Plugin aus `plugins/`;
- **aktuell** heißt, es gibt nichts Neueres.

<Callout type="info">
  Der Assistant nutzt dieselben Hub-Endpunkte wie `pnx plugin`. Um beide auf einen anderen Hub zu richten, setze `PNX_API_URL`: siehe [die CLI](/docs/de/cli#state).
</Callout>
