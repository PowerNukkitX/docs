`pnx` legt einen PowerNukkitX-Server im Terminal an, startet und pflegt ihn: Es lädt die richtige Jar, schreibt die Startskripte, wählt die Java-Flags, installiert geprüfte Plugins und prüft die Maschine. Es ist quelloffen, im Repository [pnx-cli](https://github.com/PowerNukkitX/pnx-cli).

<CliSession />

## Installieren

Du brauchst **Node.js 20.12** oder neuer und Java 21 für den Server selbst.

```bash
npm install -g @powernukkitx/cli
pnx --version
```

Keine globale Installation? Jeder Befehl funktioniert auch über `npx @powernukkitx/cli <befehl>`.

Das Paket installiert zwei Befehle:

| Befehl | Wofür |
| :-- | :-- |
| `pnx` | Alles: die Unterbefehle auf diesen Seiten. Allein gestartet öffnet es ein interaktives Menü. |
| `pnxcli` | Der [geführte Starter](/docs/de/cli/launcher): eine Aufgabe, einen Server anlegen, mit Fragen statt Flags. |

## Auf welchen Server ein Befehl wirkt

Die meisten Befehle arbeiten mit **einem Serverordner**. `pnx` wählt ihn in dieser Reihenfolge:

<Steps>
  <Step>Der mit `--dir` angegebene Ordner, bei Befehlen, die das annehmen.</Step>
  <Step>Der Standardserver, festgelegt durch `pnx init` oder `pnx use <ordner>`.</Step>
  <Step>Sonst ein Server in der Nähe. Gibt es mehrere, wirst du gefragt.</Step>
</Steps>

## Optionen, die jeder Befehl versteht

| Option | Wirkung |
| :-- | :-- |
| `-h`, `--help` | Hilfe zu `pnx` oder zu einem Befehl: `pnx start --help`. |
| `-v`, `--version` | Zeigt die CLI-Version. |
| `--json` | Gibt ein einziges JSON-Dokument aus und sonst nichts: kein Spinner, kein Fortschrittsbalken. Für Skripte gemacht. |
| `--no-color` | Reiner Text ohne Farben, für Logs und Pipes. |
| `--debug` | Zeigt unter einem Fehler den vollständigen Stacktrace statt einer Hinweiszeile. |

```bash
pnx --json info
pnx --json doctor
```

## Wo sie ihren Zustand speichert [#state]

Die CLI schreibt ihre eigenen Dateien nach `~/.pnx-cli`: `config.json` (der Standardserver, das Hub-Token), den Release-Cache und die Einstellungen des [Assistant](/docs/de/assistant). Die Dateien deines Servers bleiben im Serverordner.

| Variable | Wirkung |
| :-- | :-- |
| `PNX_HOME` | Verlegt den Zustandsordner an einen anderen Ort als `~/.pnx-cli`. |
| `PNX_API_URL` | Lässt die Plugin-Befehle einen anderen Hub als `https://powernukkitx.org` nutzen. |
| `JAVA_HOME` | Das Java, mit dem der Server startet, vor dem in deinem `PATH`. |
| `PNX_DEBUG` | Wie `--debug`. |
