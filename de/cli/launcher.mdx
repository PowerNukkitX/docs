`pnxcli` hat eine Aufgabe: einen Server anlegen, von Anfang bis Ende. Es fragt wo, welche Version und ob er gestartet werden soll, und erledigt den Rest. Es ist der schnellste Einstieg für alle, die nicht im Terminal zu Hause sind.

```bash
pnxcli
```

Es geht dieselben Schritte wie [`pnx init`](/docs/de/cli/server#init): den Ordner, die PowerNukkitX-Version (die neueste stabile ist vorausgewählt), den Download der Jar und der Startskripte. Der neue Server wird zum Standardserver für alle `pnx`-Befehle.

## Optionen

Um eine Frage zu überspringen, beantworte sie vorab:

| Option | Wirkung |
| :-- | :-- |
| `--dir <pfad>` | Legt den Server in diesem Ordner an. |
| `--version <tag>` | Legt ein genaues PowerNukkitX-Release fest. |
| `--start` | Startet den Server, sobald er bereit ist. |
| `--no-color` | Reiner Text, für Pipes. |

```bash
pnxcli --dir ./survival --start
```

<Callout type="info">
  Lieber ein Fenster als ein Terminal? Der [Assistant](/docs/de/assistant) macht dasselbe, mit einem Einrichtungsassistenten und einem Live-Downloadbalken.
</Callout>
