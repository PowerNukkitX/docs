`pnx link` koppelt einen Server mit einem **Hub**, einem Web-Dashboard, und betreibt den Server dann unter Aufsicht: Es startet die JVM, liest die Konsole und berichtet an das Dashboard, das Befehle zurückschicken kann.

<LinkPairing />

<Callout type="info" title="Braucht einen Hub mit Kopplung">
  Die Kopplung braucht einen Hub, der Server überwacht. Die Website powernukkitx.org bietet das noch nicht an; richte `--hub` auf einen Hub, der es kann.
</Callout>

## Wie die Verbindung läuft

Jede Verbindung geht **von deiner Maschine** zum Hub: Der Hub öffnet nie eine zu dir. Kein Port zu öffnen, keine Firewall-Regel. Ist der Hub nicht erreichbar, läuft der Server weiter.

## Koppeln

<Steps>
  <Step>Erstelle im Dashboard einen Kopplungscode.</Step>
  <Step>Führe auf der Servermaschine `pnx link <code>` aus.</Step>
  <Step>Die CLI tauscht den Code gegen ein Token, speichert es und beginnt, den Server zu überwachen.</Step>
</Steps>

```bash
pnx link ABCD-1234 --hub https://hub.example.org --name "Survival"
```

| Option | Wirkung |
| :-- | :-- |
| `<code>` | Der Kopplungscode aus dem Dashboard. |
| `--hub <url>` | Die Adresse des Hubs. |
| `--allow <liste>` | Die zu gewährenden Rechte, durch Kommas getrennt. |
| `--dir <pfad>` | Der Serverordner. |
| `--memory <größe>` | Speicher für den Server. |
| `--name <name>` | Der im Dashboard angezeigte Name. |
| `--start` / `--no-start` | Startet den Server oder hängt sich nur an. |
| `--status` | Zeigt, womit diese Maschine gekoppelt ist. |
| `--forget` | Löscht das gespeicherte Token. |

## Rechte

Das Dashboard kann nur, was du erlaubst. Eine neue Kopplung erlaubt `console` und `control`; weitere fügst du mit `--allow` namentlich hinzu.

| Recht | Erlaubt dem Dashboard |
| :-- | :-- |
| `console` | Die Konsole lesen und Befehle senden. |
| `control` | Den Server starten, stoppen und neu starten. |
| `players` | Spieler verwalten, etwa die Whitelist. |
| `worlds` | Mit Welten arbeiten. |
| `config` | Die Konfiguration lesen und ändern. |
| `files` | Dateien im Serverordner lesen und schreiben. |
| `plugins` | Plugins installieren und entfernen. |
| `backups` | Backups anlegen. |
| `schedules` | Geplante Aufgaben ausführen. |

```bash
pnx link ABCD-1234 --allow console,control,backups
```

<Callout type="warn" title="Was ein entfernter Befehl nie darf">
  Der Dateizugriff ist auf den Serverordner beschränkt, geprüft auf deiner Maschine, nachdem Links aufgelöst wurden. Ausführbare Dateien und Skripte (`.jar`, `.exe`, `.sh`, `.bat`, `.js` und andere) können gelesen, aber nie aus der Ferne geschrieben werden.
</Callout>

## Prüfen und vergessen

```bash
pnx link --status
pnx link --forget
```
