**PNX-APT** ist ein Annotation-Prozessor, der beim Kompilieren läuft. Annotiere deine Klassen, und beim Bauen:

<Steps>
  <Step>erzeugt er den Deskriptor `powernukkitx.yml` in deiner Jar;</Step>
  <Step>erzeugt er eine Klasse `PNXPluginBootstrap`, die deine Befehle, Listener und Tasks registriert;</Step>
  <Step>führt er diesen Bootstrap aus, wenn dein Plugin aktiviert wird.</Step>
</Steps>

Keine `plugin.yml` zu schreiben, keine `registerEvents`-Aufrufe zu vergessen.

## Plugin-Metadaten: `@PluginMeta`

Setze sie auf deine **eine** Hauptklasse, die `PluginBase` erweitert:

```java title="MyPlugin.java"
package org.example;

import org.powernukkitx.plugin.PluginBase;
import org.powernukkitx.plugin.PluginLoadOrder;
import org.powernukkitx.plugin.annotation.PluginMeta;

@PluginMeta(
    name = "MyPlugin",
    version = "1.0.0",
    api = {"3.0.0-SNAPSHOT"},
    authors = {"AuthorName"},
    description = "An automated plugin using annotations!",
    website = "https://example.com",
    order = PluginLoadOrder.POSTWORLD
)
public class MyPlugin extends PluginBase {
    // no plugin.yml or powernukkitx.yml to write
}
```

| Parameter | Typ | |
| :-- | :-- | :-- |
| `name` | `String` | Der Name des Plugins. |
| `version` | `String` | Seine Version. |
| `api` | `String[]` | Kompatible Versionen der PowerNukkitX-API, zum Beispiel `{"3.0.0-SNAPSHOT"}`. |
| `authors` | `String[]` | Optional. Autoren. |
| `description` | `String` | Optional. Eine Beschreibung. |
| `website` | `String` | Optional. Eine Website. |
| `prefix` | `String` | Optional. Ein eigenes Logger-Präfix. |
| `depend` | `String[]` | Optional. Plugins, die zuerst laden müssen. |
| `softDepend` | `String[]` | Optional. Plugins, die zuerst laden, falls vorhanden. |
| `loadBefore` | `String[]` | Optional. Plugins, die nach diesem laden. |
| `order` | `PluginLoadOrder` | Optional. `POSTWORLD` (Standard) oder `STARTUP`. |

## Listener: `@EventListener`

Statt `registerEvents(...)` in `onEnable()` aufzurufen:

```java title="MyListener.java"
package org.example;

import org.powernukkitx.event.EventHandler;
import org.powernukkitx.event.Listener;
import org.powernukkitx.event.player.PlayerJoinEvent;
import org.powernukkitx.plugin.annotation.EventListener;

@EventListener
public class MyListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage("Welcome to the server!");
    }
}
```

## Tasks: `@ScheduleTask`

Auf einer `Runnable`- (oder `Task`-)Klasse oder auf einer `public static`-Methode:

| Option | Standard | |
| :-- | :-- | :-- |
| `delay` | `0` | Ticks vor dem ersten Lauf. |
| `period` | `0` | Ticks zwischen den Läufen. `0` läuft einmal. |
| `async` | `false` | Außerhalb des Hauptthreads ausführen. |

<Tabs items={["Auf einer Klasse", "Auf einer Methode"]}>
  <Tab value="Auf einer Klasse">
    ```java title="MyTask.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    @ScheduleTask(delay = 100, period = 200, async = false)
    public class MyTask implements Runnable {
        @Override
        public void run() {
            System.out.println("Runs every 10 seconds!");
        }
    }
    ```
  </Tab>
  <Tab value="Auf einer Methode">
    ```java title="StaticTasks.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    public class StaticTasks {
        @ScheduleTask(delay = 20, async = true)
        public static void runOnceAsync() {
            System.out.println("Runs once, asynchronously, after 1 second!");
        }
    }
    ```
  </Tab>
</Tabs>

## Befehle: `@CommandDefinition`

Registriert den Befehl in der Command-Map des Servers. `commandMode` bestimmt, wie Argumente geroutet werden:

```java title="MyCommand.java"
import org.powernukkitx.command.Command;
import org.powernukkitx.plugin.annotation.CommandDefinition;
import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

@CommandDefinition(
    name = "mycommand",
    description = "An annotation-registered command",
    usage = "/mycommand",
    aliases = {"mycmd"},
    permission = "myplugin.command.use",
    commandMode = CommandMode.COMMAND_TREE
)
public class MyCommand extends Command {
    // COMMAND_TREE: override buildCommandTree(RouteTree tree)
    // RAW: override execute(CommandSender sender, String label, String[] args)
}
```

| Modus | |
| :-- | :-- |
| `COMMAND_TREE` (Standard) | Der fluente Routing-Baum: überschreibe `buildCommandTree(RouteTree tree)`. Siehe [Befehle](/docs/de/development/basics/commands). |
| `PARAM_TREE` | Die Parameter-API für Unterbefehle. |
| `RAW` | Kein automatisches Routing: Werte die Argumente selbst in `execute` aus. |
