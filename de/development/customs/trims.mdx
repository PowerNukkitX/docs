Ein Besatz hat zwei Teile: ein **Muster** aus der Schmiedevorlage im Vorlagenslot und ein **Material** aus der Zutat im Materialslot. Registriere deine eigenen, und Spieler bringen sie am Schmiedetisch an wie die Vanilla-Besätze. Sie liegen in `TrimRegistry`, erreichbar über `Registries.TRIM`.

<Steps>
  <Step>
    ### Muster und Materialien registrieren

    Beide Aufrufe werfen `RegisterException`, wenn die Item-ID schon vergeben ist:

```java filename="MyPlugin.java"
import org.powernukkitx.registry.Registries;
import org.powernukkitx.registry.RegisterException;

@Override
public void onEnable() {
    try {
        // A smithing template item -> the pattern id written into the trim NBT
        Registries.TRIM.registerPattern("myplugin:cool_smithing_template", "cool");

        // An ingredient item -> the material id + the hex tint used for the item name
        Registries.TRIM.registerMaterial("minecraft:emerald", "emerald_special", "#17DD62");
    } catch (RegisterException e) {
        getLogger().error("Trim is already registered", e);
    }
}
```

    - `registerPattern(templateItemId, patternId)`: das Vorlagen-Item und die Muster-ID, die in das Besatz-NBT geschrieben wird.
    - `registerMaterial(ingredientItemId, materialId, color)`: das Zutaten-Item, die Material-ID und die Hex-Farbe (mit `#`), die den Namen des Besatzes einfärbt.
  </Step>
  <Step>
    ### Die Items taggen

    Der Schmiedetisch nimmt nur Items mit dem richtigen Tag an:

```java
import org.powernukkitx.item.ItemTags;
import java.util.List;

ItemTags.register("myplugin:cool_smithing_template", List.of("minecraft:trim_templates"));
ItemTags.register("minecraft:emerald", List.of("minecraft:trim_materials"));
```

    <Callout type="info">
      Die Item-IDs müssen existieren. Nutze Vanilla-IDs oder registriere zuerst deine eigenen [Items](/docs/de/development/customs/items).
    </Callout>
  </Step>
  <Step>
    ### Spieler synchronisieren, die schon online sind

    Spieler erhalten die Besatzliste beim Beitreten. Registrierst du, nachdem sie online sind? Schick ihnen die neue Liste:

```java
Registries.TRIM.resyncOnlinePlayers();
```
  </Step>
</Steps>

## Besätze entfernen und nachschlagen

```java
// Remove a registered pattern or material
Registries.TRIM.unregisterPattern("myplugin:cool_smithing_template");
Registries.TRIM.unregisterMaterial("minecraft:emerald");

// Look one up (returns an Optional)
Registries.TRIM.getPattern("myplugin:cool_smithing_template");
Registries.TRIM.getMaterial("minecraft:emerald");

// Read-only views of everything registered
Registries.TRIM.getPatterns();
Registries.TRIM.getMaterials();
```

<Callout type="warn">
  Registriere jede Vorlagen- und Zutaten-ID nur einmal: Ein zweites `registerPattern` oder `registerMaterial` für dieselbe ID wirft `RegisterException`.
</Callout>
