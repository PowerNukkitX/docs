Alles Folgende funktioniert für jede Art von Formular gleich.

## Titel [#title]

Setze ihn im Konstruktor oder mit einer Methode:

```java
// Using the constructor
CustomForm custom = new CustomForm("title");
ModalForm modal = new ModalForm("title");
SimpleForm simple = new SimpleForm("title");

// Using the method
custom.title("other title");
modal.title("other title");
simple.title("other title");
```

## Auf Antworten hören

Jedes Formular führt einen Callback aus, wenn der Spieler es absendet, und einen anderen, wenn er es schließt:

```java
form.onSubmit((player, response) -> {
    /*

    Handle the form response here,
    the object depends on the form you've created.
    For details, check out the specific form documentation.

    */
})
form.onClose(player -> player.sendMessage("You have closed the form!"));
```

## Ein Formular senden [#sending-a-form]

```java
form.send(player);
```

Du kannst auch eine ID übergeben, das wird aber nicht empfohlen:

```java
form.send(player, 123);
```

## Metadaten

Häng beliebige Daten an ein Formular, etwa um es später wiederzuerkennen oder zu aktualisieren:

```java
// Example: Saving an entity
Entity entity = ...;

form.putMeta("form-type", "manage-entity")
    .putMeta("entity", entity);
```

Lies sie mit `getMeta` wieder aus:

```java
Entity entity = form.getMeta("entity");
```

Mit einem Ersatzwert, falls der Schlüssel fehlen kann:

```java
Entity entity = form.getMeta("entity", backupEntity);
```

## Wer es geöffnet hat

Ein Formular kann mehreren Spielern gleichzeitig gezeigt werden (zum Beispiel eine Teamauswahl). Liste sie auf:

```java
ObjectArraySet<Player> viewers = form.viewers();
```

Oder prüfe einen einzelnen Spieler:

```java
boolean isViewer = form.isViewer(player);
```
