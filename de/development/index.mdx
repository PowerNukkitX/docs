Die PowerNukkitX-API ist in **Java 21** geschrieben. Ein Plugin ist eine Jar im Ordner `plugins/` des Servers: Der Server ruft es auf, wenn es geladen wird, wenn es startet und immer dann, wenn im Spiel etwas passiert.
