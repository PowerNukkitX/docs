Die Begriffe, die diese Dokumentation verwendet, und was sie auf einem PowerNukkitX-Server bedeuten.

| Begriff | Bedeutung |
| :-- | :-- |
| **Bedrock Edition** | Die Minecraft-Version auf Handys, Konsolen und Windows. PowerNukkitX bedient sie. |
| **BDS** | Bedrock Dedicated Server, Mojangs offizielle Serversoftware. |
| **Tick** | Ein Schritt der Spielschleife des Servers. Es gibt 20 pro Sekunde, 100 Ticks sind also 5 Sekunden. |
| **TPS** | Ticks pro Sekunde. 20 ist gesund; weniger heißt, der Server laggt. |
| **Level** | Eine Welt. Jede ist ein Ordner in `worlds/`. |
| **Chunk** | Eine 16 mal 16 große Säule der Welt, die als ein Stück erzeugt und geladen wird. |
| **Sichtweite** | Wie viele Chunks um sich herum jeder Spieler erhält. Der größte Hebel für die Leistung. |
| **Operator (OP)** | Ein Spieler, der jeden Befehl ausführen kann. |
| **Berechtigungsknoten** | Ein Name mit Punkten wie `nukkit.command.help`, den ein Befehl oder Plugin vor dem Handeln prüft. |
| **Whitelist** | Die Liste der Spieler, die beitreten dürfen, wenn sie aktiv ist (`white-list.txt`). Auch Allow-List genannt. |
| **Xbox-Authentifizierung** | Die Prüfung des Xbox-Kontos jedes Spielers. Ist sie aus, ist das der Offline-Modus. |
| **Plugin** | Eine Java-Jar in `plugins/`, die Befehle, Ereignisse, Inhalte oder Spielmechanik hinzufügt. |
| **Listener** | Eine Plugin-Klasse, deren `@EventHandler`-Methoden laufen, wenn ein Ereignis eintritt. |
| **Registry** | Wo eigene Blöcke, Items, Entitäten und Rezepte registriert werden. Registriere in `onLoad()`. |
| **Ressourcenpaket** | Texturen und Modelle, die Spieler beim Beitreten herunterladen; nötig, um eigene Inhalte zu sehen. |
| **Verhaltenspaket** | Spiellogik auf dem Client. Nicht unterstützt: PowerNukkitX erledigt das in Java-Plugins. |
| **Formular** | Ein Fenster, das einem Spieler gezeigt wird: SimpleForm, ModalForm, CustomForm oder DDUI. |
| **Proxy** | Ein Server wie WaterdogPE, der Spieler zwischen mehreren Servern bewegt. |
| **`pnx.yml`** | Die eine Datei, die alle Servereinstellungen enthält. |
