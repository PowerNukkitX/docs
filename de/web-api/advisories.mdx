Wenn ein Plugin-Release eine bekannte Schwachstelle hat, veröffentlicht das Team einen Hinweis, und die Plugin-Seite zeigt ihn an. Dieselben Hinweise gibt es im Format [OSV](https://ossf.github.io/osv-schema/), das Sicherheitsscanner bereits lesen.

```text
GET /api/v1/advisories/osv
```

Die Antwort ist `{ advisories }`: ein OSV-Datensatz pro veröffentlichtem Hinweis. Entwürfe und zurückgezogene Hinweise sind nie enthalten.

<Callout type="info">
  Lass in deiner CI einen Scanner über diesen Feed laufen, um gewarnt zu werden, wenn ein Plugin, das du auslieferst, einen Hinweis bekommt.
</Callout>
