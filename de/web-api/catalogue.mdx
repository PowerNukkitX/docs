Diese Endpunkte ändern sich selten und werden großzügig zwischengespeichert. Sie haben keine Parameter.

## Kategorien

```text
GET /api/v1/categories
```

Jede sichtbare Plugin-Kategorie als `{ id, label }`. Nutze eine `id` im Parameter `category` von [`/plugins`](/docs/de/web-api/plugins).

<ApiTry path="/categories" />

## Sammlungen

```text
GET /api/v1/collections
```

Veröffentlichte Sammlungen: handverlesene Plugin-Listen, jede mit den Plugins, die sie bündelt.

<ApiTry path="/collections" />

## Abzeichen

```text
GET /api/v1/badges
```

Jedes Abzeichen, das der Hub einem Plugin verleihen kann, mit Stufe und Icon.

<ApiTry path="/badges" />

## Spotlight

```text
GET /api/v1/spotlight
```

Das Plugin, das das Team gerade auf der Startseite hervorhebt, mit seiner Notiz. `data` ist `null`, wenn nichts hervorgehoben ist.

<ApiTry path="/spotlight" />
