Ein Plugin wird über seinen **Slug** angesprochen, das `owner.name`, das der Hub ihm gegeben hat, wie in `/plugins/owner.name`.

## Auflisten und suchen

```text
GET /api/v1/plugins
```

Veröffentlichte Plugins, 24 pro Seite. Die Antwort trägt Seite und Gesamtzahl auf oberster Ebene: `data`, `page`, `perPage`, `total`, `totalPages` und `fuzzy`, das `true` ist, wenn `q` nichts genau getroffen hat und die Ergebnisse die ähnlichsten Namen sind.

| Parameter | Was er macht |
| :-- | :-- |
| `q` | Volltextsuche über Name, Slug und Zusammenfassung. |
| `category` | Eine Kategorie-ID aus [`/categories`](/docs/de/web-api/catalogue). |
| `api` | Nur Plugins, die diese PowerNukkitX-API-Version in ihrer `plugin.yml` angeben. |
| `sort` | `downloads`, `trending`, `stars`, `followers`, `rating`, `updated` oder `name`. |
| `page` | Von 1 bis 500. |

<ApiTry path="/plugins" query="q=economy&sort=downloads" />

## Ein Plugin

```text
GET /api/v1/plugins/{slug}
```

Ein Plugin mit seinen GitHub-Metadaten, Releases und seiner README, aufgelöst zum Zeitpunkt der Anfrage. Nur **freigegebene** Releases können heruntergeladen werden.

## Bewertungen

```text
GET /api/v1/plugins/{slug}/reviews
```

Bewertungen der Community, die neuesten zuerst. Die Seitennavigation steht unter `meta`: `{ hasMore, limit, offset }`.

| Parameter | Was er macht |
| :-- | :-- |
| `limit` | Wie viele zurückgegeben werden. |
| `offset` | Wie viele übersprungen werden. |

<ApiTry path="/plugins/{slug}/reviews" params={{ slug: "" }} query="limit=10" />

## Download-Verlauf

```text
GET /api/v1/plugins/{slug}/history
```

Tägliche Download-Zahlen in `data.points`. Daraus wird das Diagramm auf einer Plugin-Seite gezeichnet.

## Badge

```text
GET /api/v1/plugins/{slug}/badge
```

Ein Status-Badge als **SVG-Bild**, nicht als JSON. Binde es in einer README als Bild ein:

```markdown
![downloads](https://powernukkitx.org/api/v1/plugins/owner.name/badge?metric=downloads)
```

| Parameter | Was er macht |
| :-- | :-- |
| `metric` | `api`, `downloads`, `rating`, `stars` oder `version`. |
| `label` | Ersetzt den Text links, bis zu 32 Zeichen. |

## Ein Release herunterladen

```text
GET /api/v1/plugins/{slug}/download?tag={tag}
```

Leitet auf die Jar eines freigegebenen Releases auf GitHub weiter und zählt den Download. `tag` ist Pflicht. Ein Release, das existiert, aber nicht freigegeben ist, antwortet `403 not_approved`. Das ruft `pnx plugin install` in der CLI auf.
