Das [Serververzeichnis](https://powernukkitx.org/servers) listet freigegebene Bedrock-Server, die PowerNukkitX nutzen. Seine API ist für alle nur lesend; einen Server trägst du auf der Website ein.

## Server auflisten

```text
GET /api/v1/servers
```

Hervorgehobene Server zuerst, dann die übrigen. Die Antwort ist `{ data, total }`.

| Parameter | Was er macht |
| :-- | :-- |
| `q` | Suche nach Namen. |
| `category` | Eine Kategorie, etwa Survival oder Minispiele. |
| `region` | Wo der Server gehostet wird. |
| `language` | Eine Sprache, die auf dem Server gesprochen wird. |
| `page` | Seitennummer, ab 1. |

<Callout type="info">
  Diese Liste hat ihr eigenes Budget: 60 Anfragen pro Minute und Adresse.
</Callout>

## Ein Server

```text
GET /api/v1/servers/{slug}
```

Die öffentliche Ansicht eines freigegebenen Servers: Adresse, Beschreibung, Tags und Abzeichen. Ein nicht freigegebener Server antwortet `404`.
