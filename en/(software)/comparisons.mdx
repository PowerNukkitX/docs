PowerNukkitX is not the only Bedrock server. This page sets it beside Nukkit and Mojang's Bedrock Dedicated Server (BDS), to help you choose.

## At a glance

| | PowerNukkitX | Nukkit | BDS (official) |
| :-- | :-- | :-- | :-- |
| Performance | **High** | Medium | High |
| Plugin system | **Yes, Java** | Yes, Java | No |
| API | **Modern** | Legacy | None |
| New Bedrock versions | **Fast** | Slow | Official |
| Open source | **Yes** | Yes | No |
| Community | **Active** | Medium | Official |
| Custom content | **Good** | Medium | Low |

## Which one to choose

<Cards>
  <Card title="PowerNukkitX">
    A modern server you want to extend with plugins and custom content, with an active community behind it.
  </Card>
  <Card title="Nukkit">
    A server that depends on old Nukkit plugins that have not been updated.
  </Card>
  <Card title="BDS">
    A purely vanilla experience with Mojang's official updates and maximum client compatibility.
  </Card>
</Cards>

## Moving to PowerNukkitX

<Steps>
  <Step>
    **Check your plugins.** Some Nukkit plugins need adapting to the PowerNukkitX API.
  </Step>
  <Step>
    **Bring your worlds and settings.** Copy your worlds, then move your settings into `pnx.yml`.
  </Step>
  <Step>
    **Review permissions.** Recreate your groups and permission nodes.
  </Step>
</Steps>

Each source has its own guide: [from Nukkit](/docs/migration/nukkit), [from BDS](/docs/migration/bds), [from PocketMine-MP](/docs/migration/pocketmine).
