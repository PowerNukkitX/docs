[Terra](https://terra.polydev.org/) is a terrain generator driven by **config packs**: each pack describes its own biomes and landscapes. PowerNukkitX supports it out of the box.

<Steps>
  <Step>
    ### Enable Terra

    With the server **stopped**, set:

    ```yaml title="pnx.yml"
    miscSettings:
      enableTerra: true
    ```

    Start the server: it creates a `terra/` folder at the root.
  </Step>
  <Step>
    ### Add a pack

    1. Pick a pack, for example from the [community packs](https://terra.polydev.org/config/community-packs.html).
    2. Put its folder or ZIP in `terra/packs/`.
    3. Open the pack's `pack.yml` and note its `id`, for example `REIMAGEND`.
  </Step>
  <Step>
    ### Create a world that uses it

    Create a folder for the new world inside `worlds/`, for example `worlds/end`, with a `config.json`:

    ```json title="worlds/end/config.json"
    {
      "format": "leveldb",
      "enable": true,
      "generators": {
        "2": {
          "name": "terra",
          "seed": 0,
          "enableAntiXray": false,
          "antiXrayMode": "LOW",
          "preDeobfuscate": true,
          "dimensionData": {
            "dimensionName": "minecraft:end",
            "dimensionId": 2,
            "minHeight": 0,
            "maxHeight": 255,
            "height": 256,
            "chunkSectionCount": 16
          },
          "preset": {
            "pack": "REIMAGEND"
          }
        }
      }
    }
    ```

    Replace `REIMAGEND` in `preset.pack` with your pack's id.
  </Step>
  <Step>
    ### Visit it

    Start the server and teleport to the new world:

    ```bash
    /world tp end Dim2
    ```
  </Step>
</Steps>
