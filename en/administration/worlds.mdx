Each world (a *level*) is a folder in `worlds/`. The default one is named by `defaultLevelName` in `pnx.yml` (`world` by default) and loads on startup; it is where new players spawn.

## Change the default world

```yaml title="pnx.yml"
baseSettings:
  defaultLevelName: world
```

<Callout type="warn">
  Stop the server first: a running server rewrites `pnx.yml` from memory when it shuts down.
</Callout>

## Import a world

PowerNukkitX reads the Bedrock **LevelDB** format, so worlds from another server or exported from the Bedrock client work.

<Steps>
  <Step>Stop the server.</Step>
  <Step>Copy the world folder into `worlds/`.</Step>
  <Step>Set `defaultLevelName` to the folder name, or load it with a multi-world plugin.</Step>
  <Step>Start the server.</Step>
</Steps>

## Per-world settings

Difficulty, spawn point and game rules belong to each world and change at runtime:

```bash title="Console"
difficulty normal
setworldspawn
gamerule keepInventory true
```

## Several worlds at once

The core loads one default world. To run several and move players between them, install a multi-world plugin from the [plugin hub](https://powernukkitx.org/plugins).

## Spawn and generation

| Setting | Effect |
| :-- | :-- |
| `playerSettings.spawnRadius` | How far from the world spawn new players appear. |
| `gameplaySettings.spawnProtection` | The radius around spawn that non-operators cannot edit. |

Terrain can be generated by [Terra](/docs/administration/integrations/terra); chunk generation runs on the async worker threads (see [Performance](/docs/administration/performance)).
