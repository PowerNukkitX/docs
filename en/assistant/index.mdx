The **PowerNukkitX** app is a desktop app for Windows, Linux and macOS. It creates a server, starts it, shows its console, installs plugins and edits its settings, all without a terminal. It is made for a first server, and stays useful once you run several.

<AssistantWindow />

Under the hood it drives the [PNX CLI](/docs/cli): the app ships the compiled CLI and calls the very same functions `pnx` uses, so the window and the terminal can never disagree about how a server is created or started.

## Install

Download the installer for your system from the [pnx-cli releases](https://github.com/PowerNukkitX/pnx-cli/releases):

| System | File |
| :-- | :-- |
| Windows | The installer (`.exe` setup), or the portable `.exe` that runs without installing. |
| Linux | The `.AppImage`: make it executable, then run it. |
| macOS | The `.dmg`: open it and drag the app to Applications. |

The server still needs **Java 25** or newer. The app checks for it on first launch and tells you when it is missing.

A short welcome walks through three screens:

<Steps>
  <Step>**Welcome**: what the app does.</Step>
  <Step>**Java**: it looks for Java 25+ and says what it found.</Step>
  <Step>**Your first server**: create one in a click, connect a server folder you already have, or skip for now.</Step>

Want to see it again? **Settings > Replay the intro**.

## The guided tutorial

**Guided tutorial**, in the sidebar, is seven steps for a first server, each with a button that does the work: what PowerNukkitX is, checking Java, creating the server, the first start, joining from Minecraft, adding plugins, and inviting friends from outside your network.

## Keyboard shortcuts

| Keys | Action |
| :-- | :-- |
| `Ctrl` + `K` | The command palette: jump anywhere, start or stop the server, take a backup. |
| `Ctrl` + `1` … `7` | Switch between the views of the sidebar. |
| `Esc` | Close the palette or a dialog. |
