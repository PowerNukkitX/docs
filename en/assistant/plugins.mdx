The **Plugins** view searches the [plugin hub](https://powernukkitx.org/plugins) and installs straight into the active server's `plugins/` folder.

## Marketplace

Type in the search field to find a plugin. **Install** downloads the hub's newest **approved** release from GitHub and checks it against the SHA-256 the hub recorded before writing it to `plugins/`. Restart the server to load it.

## Installed

The **Installed** tab lists what the Assistant installed:

- **Update** appears when a newer approved release exists;
- **Remove** deletes the plugin from `plugins/`;
- **up to date** means there is nothing newer.

<Callout type="info">
  The Assistant uses the same hub endpoints as `pnx plugin`. To point both at another hub, set `PNX_API_URL`: see [the CLI](/docs/cli#state).
</Callout>
