`pnx` creates, starts and maintains a PowerNukkitX server from the terminal: it downloads the right jar, writes the start scripts, picks the Java flags, installs reviewed plugins and checks the machine. It is open source, in the [pnx-cli](https://github.com/PowerNukkitX/pnx-cli) repository.

<CliSession />

## Install

You need **Node.js 20.12** or newer, and Java 21 for the server itself.

```bash
npm install -g @powernukkitx/cli
pnx --version
```

No global install? Every command also works through `npx @powernukkitx/cli <command>`.

The package installs two commands:

| Command | For |
| :-- | :-- |
| `pnx` | Everything: the subcommands on these pages. Run it alone for an interactive menu. |
| `pnxcli` | The [guided launcher](/docs/cli/launcher): one job, creating a server, with questions instead of flags. |

## Which server a command acts on

Most commands work on **one server folder**. `pnx` picks it in this order:

<Steps>
  <Step>The folder given with `--dir`, for the commands that take it.</Step>
  <Step>The default server, set by `pnx init` or by `pnx use <dir>`.</Step>
  <Step>Otherwise, a server found nearby. When there are several, you are asked to pick one.</Step>
</Steps>

## Options every command understands

| Option | Effect |
| :-- | :-- |
| `-h`, `--help` | Help for `pnx`, or for one command: `pnx start --help`. |
| `-v`, `--version` | Prints the CLI version. |
| `--json` | Prints one JSON document and nothing else: no spinner, no progress bar. Made for scripts. |
| `--no-color` | Plain text without colours, for logs and pipes. |
| `--debug` | Shows the full stack trace under an error, instead of one hint line. |

```bash
pnx --json info
pnx --json doctor
```

## Where it keeps its state [#state]

The CLI writes its own files in `~/.pnx-cli`: `config.json` (the default server, the hub token), the release cache and the [Assistant](/docs/assistant)'s preferences. Your server's files stay in the server folder.

| Variable | Effect |
| :-- | :-- |
| `PNX_HOME` | Moves the state folder somewhere other than `~/.pnx-cli`. |
| `PNX_API_URL` | Points plugin commands at another hub than `https://powernukkitx.org`. |
| `JAVA_HOME` | The Java used to start the server, before the one on your `PATH`. |
| `PNX_DEBUG` | Same as `--debug`. |
