`pnxcli` does one job: create a server, start to finish. It asks where, which version and whether to start it, and handles the rest. It is the quickest way in for someone who does not live in a terminal.

```bash
pnxcli
```

It walks through the same steps as [`pnx init`](/docs/cli/server#init): the folder, the PowerNukkitX version (the latest stable is preselected), the download of the jar and the start scripts. The new server becomes the default one for every `pnx` command.

## Options

To skip a question, answer it in advance:

| Option | Effect |
| :-- | :-- |
| `--dir <path>` | Creates the server in that folder. |
| `--version <tag>` | Pins an exact PowerNukkitX release. |
| `--start` | Boots the server as soon as it is ready. |
| `--no-color` | Plain text, for pipes. |

```bash
pnxcli --dir ./survival --start
```
