**PNX-APT** is a compile-time annotation processor. Annotate your classes and, when you build, it:

<Steps>
  <Step>generates the `powernukkitx.yml` descriptor inside your jar;</Step>
  <Step>generates a `PNXPluginBootstrap` class that registers your commands, listeners and tasks;</Step>
  <Step>runs that bootstrap when your plugin is enabled.</Step>
</Steps>

No `plugin.yml` to write, no `registerEvents` calls to remember.

## Plugin metadata: `@PluginMeta`

Put it on your **one** main class, the one that extends `PluginBase`:

```java title="MyPlugin.java"
package org.example;

import org.powernukkitx.plugin.PluginBase;
import org.powernukkitx.plugin.PluginLoadOrder;
import org.powernukkitx.plugin.annotation.PluginMeta;

@PluginMeta(
    name = "MyPlugin",
    version = "1.0.0",
    api = {"3.0.0-SNAPSHOT"},
    authors = {"AuthorName"},
    description = "An automated plugin using annotations!",
    website = "https://example.com",
    order = PluginLoadOrder.POSTWORLD
)
public class MyPlugin extends PluginBase {
    // no plugin.yml or powernukkitx.yml to write
}
```

| Parameter | Type | |
| :-- | :-- | :-- |
| `name` | `String` | The plugin's name. |
| `version` | `String` | Its version. |
| `api` | `String[]` | Compatible PowerNukkitX API versions, for example `{"3.0.0-SNAPSHOT"}`. |
| `authors` | `String[]` | Optional. Authors. |
| `description` | `String` | Optional. A description. |
| `website` | `String` | Optional. A website. |
| `prefix` | `String` | Optional. A custom logger prefix. |
| `depend` | `String[]` | Optional. Plugins that must load first. |
| `softDepend` | `String[]` | Optional. Plugins that load first if present. |
| `loadBefore` | `String[]` | Optional. Plugins that load after this one. |
| `order` | `PluginLoadOrder` | Optional. `POSTWORLD` (default) or `STARTUP`. |

## Listeners: `@EventListener`

Instead of calling `registerEvents(...)` in `onEnable()`:

```java title="MyListener.java"
package org.example;

import org.powernukkitx.event.EventHandler;
import org.powernukkitx.event.Listener;
import org.powernukkitx.event.player.PlayerJoinEvent;
import org.powernukkitx.plugin.annotation.EventListener;

@EventListener
public class MyListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage("Welcome to the server!");
    }
}
```

## Tasks: `@ScheduleTask`

On a `Runnable` (or `Task`) class, or on a `public static` method:

| Option | Default | |
| :-- | :-- | :-- |
| `delay` | `0` | Ticks before the first run. |
| `period` | `0` | Ticks between runs. `0` runs once. |
| `async` | `false` | Run off the main thread. |

<Tabs items={["On a class", "On a method"]}>
  <Tab value="On a class">
    ```java title="MyTask.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    @ScheduleTask(delay = 100, period = 200, async = false)
    public class MyTask implements Runnable {
        @Override
        public void run() {
            System.out.println("Runs every 10 seconds!");
        }
    }
    ```
  </Tab>
  <Tab value="On a method">
    ```java title="StaticTasks.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    public class StaticTasks {
        @ScheduleTask(delay = 20, async = true)
        public static void runOnceAsync() {
            System.out.println("Runs once, asynchronously, after 1 second!");
        }
    }
    ```
  </Tab>
</Tabs>

## Commands: `@CommandDefinition`

Registers the command in the server's command map. `commandMode` picks how arguments are routed:

```java title="MyCommand.java"
import org.powernukkitx.command.Command;
import org.powernukkitx.plugin.annotation.CommandDefinition;
import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

@CommandDefinition(
    name = "mycommand",
    description = "An annotation-registered command",
    usage = "/mycommand",
    aliases = {"mycmd"},
    permission = "myplugin.command.use",
    commandMode = CommandMode.COMMAND_TREE
)
public class MyCommand extends Command {
    // COMMAND_TREE: override buildCommandTree(RouteTree tree)
    // RAW: override execute(CommandSender sender, String label, String[] args)
}
```

| Mode | |
| :-- | :-- |
| `COMMAND_TREE` (default) | The fluent routing tree: override `buildCommandTree(RouteTree tree)`. See [Commands](/docs/development/basics/commands). |
| `PARAM_TREE` | The subcommand parameter API. |
| `RAW` | No automatic routing: parse the arguments yourself in `execute`. |
