## Before you start

- A **JDK 21** or newer
- Some Java
- A PowerNukkitX server to test on
- An IDE: IntelliJ IDEA, Eclipse or VS Code

<Callout type="info" title="Skip the setup">
  The [PowerNukkitX plugin template](https://github.com/PowerNukkitX/PluginTemplate) is a ready-made project with everything below already configured.
</Callout>

Your project will look like this:

<Steps>
  <Step>
    ### Configure the build

    The build pulls the server API from the PowerNukkitX repository and packages your plugin as a jar. Target **Java 21**.

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```xml title="pom.xml"
        <project xmlns="http://maven.apache.org/POM/4.0.0"
                 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                 xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
            <modelVersion>4.0.0</modelVersion>

            <groupId>org.example</groupId>
            <artifactId>MyPlugin</artifactId>
            <version>1.0.0-SNAPSHOT</version>

            <properties>
                <maven.compiler.source>21</maven.compiler.source>
                <maven.compiler.target>21</maven.compiler.target>
                <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
            </properties>

            <repositories>
                <repository>
                    <id>central</id>
                    <url>https://repo.maven.apache.org/maven2/</url>
                </repository>
                <repository>
                    <id>PowerNukkitX-releases</id>
                    <name>PowerNukkitX Repository</name>
                    <url>https://repo.powernukkitx.org/releases</url>
                </repository>
            </repositories>

            <dependencies>
                <!-- "3.0.0-SNAPSHOT" is the current release; "nightly-SNAPSHOT" the latest
                     development build, which may break the API. -->
                <dependency>
                    <groupId>org.powernukkitx</groupId>
                    <artifactId>server</artifactId>
                    <version>3.0.0-SNAPSHOT</version>
                    <scope>provided</scope>
                </dependency>
            </dependencies>

            <build>
                <plugins>
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-compiler-plugin</artifactId>
                        <version>3.11.0</version>
                        <configuration>
                            <source>21</source>
                            <target>21</target>
                        </configuration>
                    </plugin>
                    <!-- bundles your own dependencies into the jar -->
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-shade-plugin</artifactId>
                        <version>3.4.1</version>
                        <executions>
                            <execution>
                                <phase>package</phase>
                                <goals>
                                    <goal>shade</goal>
                                </goals>
                            </execution>
                        </executions>
                    </plugin>
                </plugins>
            </build>
        </project>
        ```
      </Tab>
      <Tab value="Gradle">
        ```kotlin title="settings.gradle.kts"
        rootProject.name = "MyPlugin"
        ```

        ```kotlin title="build.gradle.kts"
        plugins {
            java
            id("com.github.johnrengelman.shadow") version "8.1.1"
        }

        group = "org.example"
        version = "1.0.0-SNAPSHOT"

        repositories {
            mavenCentral()
            maven { url = uri("https://repo.powernukkitx.org/releases") }
        }

        dependencies {
            // "3.0.0-SNAPSHOT" is the current release; "nightly-SNAPSHOT" the latest
            // development build, which may break the API.
            compileOnly("org.powernukkitx:server:3.0.0-SNAPSHOT")
        }

        tasks.withType<JavaCompile> {
            options.encoding = "UTF-8"
            sourceCompatibility = "21"
            targetCompatibility = "21"
        }

        tasks {
            build { dependsOn(shadowJar) }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Describe the plugin

    The server reads a metadata file named `plugin.yml` (or `powernukkitx.yml`) in `src/main/resources`:

    ```yaml title="plugin.yml"
    name: ExamplePlugin
    main: org.example.ExamplePlugin
    # version and api must be strings: keep the quotes
    version: "1.0.0"
    api: "2.0.0"
    load: POSTWORLD
    author: PowerNukkitX Team
    # author and authors are merged into one list
    authors: ["Example", "Another"]
    description: Example plugin from the PNX documentation
    website: https://docs.powernukkitx.org/
    ```

    <Callout type="info">
      With the [annotation processor](/docs/development/basics/annotations), this file is generated for you.
    </Callout>
  </Step>
  <Step>
    ### Write the main class

    The main class extends `PluginBase`. The server calls its three methods at each stage of the plugin's life:

    ```java title="ExamplePlugin.java"
    package org.example;

    import org.powernukkitx.plugin.PluginBase;
    import org.powernukkitx.utils.TextFormat;

    public class ExamplePlugin extends PluginBase {
        @Override
        public void onLoad() {
            this.getLogger().info(TextFormat.WHITE + "Example plugin loaded!");
        }

        @Override
        public void onEnable() {
            this.getLogger().info(TextFormat.DARK_GREEN + "Example plugin enabled!");
        }

        @Override
        public void onDisable() {
            this.getLogger().info(TextFormat.DARK_RED + "Example plugin disabled!");
        }
    }
    ```

    <PluginLifecycle />
  </Step>
  <Step>
    ### Build and install

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```bash
        mvn clean package
        ```

        The jar is in `target/`.
      </Tab>
      <Tab value="Gradle">
        ```bash
        ./gradlew clean build
        ```

        The jar, with any bundled libraries, is `build/libs/MyPlugin-1.0.0-SNAPSHOT-all.jar`.
      </Tab>
    </Tabs>

    Copy the jar into your server's `plugins/` folder and restart the server. Your messages appear in the console.
  </Step>
</Steps>
