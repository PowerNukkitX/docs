A trim has two parts: a **pattern**, from the smithing template in the template slot, and a **material**, from the ingredient in the material slot. Register yours and players apply them at a smithing table like vanilla trims. They live in `TrimRegistry`, reached through `Registries.TRIM`.

<Steps>
  <Step>
    ### Register patterns and materials

    Both calls throw `RegisterException` if the item id is already taken:

```java filename="MyPlugin.java"
import org.powernukkitx.registry.Registries;
import org.powernukkitx.registry.RegisterException;

@Override
public void onEnable() {
    try {
        // A smithing template item -> the pattern id written into the trim NBT
        Registries.TRIM.registerPattern("myplugin:cool_smithing_template", "cool");

        // An ingredient item -> the material id + the hex tint used for the item name
        Registries.TRIM.registerMaterial("minecraft:emerald", "emerald_special", "#17DD62");
    } catch (RegisterException e) {
        getLogger().error("Trim is already registered", e);
    }
}
```

    - `registerPattern(templateItemId, patternId)`: the template item, and the pattern id written into the trim NBT.
    - `registerMaterial(ingredientItemId, materialId, color)`: the ingredient item, the material id, and the hex colour (with a `#`) that tints the trim's name.
  </Step>
  <Step>
    ### Tag the items

    The smithing table only accepts items with the right tag:

```java
import org.powernukkitx.item.ItemTags;
import java.util.List;

ItemTags.register("myplugin:cool_smithing_template", List.of("minecraft:trim_templates"));
ItemTags.register("minecraft:emerald", List.of("minecraft:trim_materials"));
```

    <Callout type="info">
      The item ids must exist. Use vanilla ids, or register your own [custom items](/docs/development/customs/items) first.
    </Callout>
  </Step>
  <Step>
    ### Sync players already online

    Players receive the trim list when they join. Register after they are online? Send them the new list:

```java
Registries.TRIM.resyncOnlinePlayers();
```
  </Step>
</Steps>

## Remove and look up trims

```java
// Remove a registered pattern or material
Registries.TRIM.unregisterPattern("myplugin:cool_smithing_template");
Registries.TRIM.unregisterMaterial("minecraft:emerald");

// Look one up (returns an Optional)
Registries.TRIM.getPattern("myplugin:cool_smithing_template");
Registries.TRIM.getMaterial("minecraft:emerald");

// Read-only views of everything registered
Registries.TRIM.getPatterns();
Registries.TRIM.getMaterials();
```

<Callout type="warn">
  Register each template and ingredient id only once: a second `registerPattern` or `registerMaterial` for the same id throws `RegisterException`.
</Callout>
