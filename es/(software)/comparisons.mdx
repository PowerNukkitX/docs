PowerNukkitX no es el único servidor Bedrock. Esta página lo compara con Nukkit y con el Bedrock Dedicated Server (BDS) de Mojang, para ayudarte a elegir.

## De un vistazo

| | PowerNukkitX | Nukkit | BDS (oficial) |
| :-- | :-- | :-- | :-- |
| Rendimiento | **Alto** | Medio | Alto |
| Sistema de plugins | **Sí, Java** | Sí, Java | No |
| API | **Moderna** | Antigua | Ninguna |
| Nuevas versiones de Bedrock | **Rápido** | Lento | Oficial |
| Código abierto | **Sí** | Sí | No |
| Comunidad | **Activa** | Media | Oficial |
| Contenido personalizado | **Bueno** | Medio | Bajo |

## Cuál elegir

<Cards>
  <Card title="PowerNukkitX">
    Un servidor moderno que quieres ampliar con plugins y contenido personalizado, con una comunidad activa detrás.
  </Card>
  <Card title="Nukkit">
    Un servidor que depende de plugins antiguos de Nukkit que no se han actualizado.
  </Card>
  <Card title="BDS">
    Una experiencia puramente vanilla con las actualizaciones oficiales de Mojang y la máxima compatibilidad con el cliente.
  </Card>
</Cards>

## Pasarse a PowerNukkitX

<Steps>
  <Step>
    **Revisa tus plugins.** Algunos plugins de Nukkit necesitan adaptarse a la API de PowerNukkitX.
  </Step>
  <Step>
    **Trae tus mundos y ajustes.** Copia tus mundos y pasa tus ajustes a `pnx.yml`.
  </Step>
  <Step>
    **Revisa los permisos.** Vuelve a crear tus grupos y nodos de permisos.
  </Step>
</Steps>

Cada origen tiene su propia guía: [desde Nukkit](/docs/es/migration/nukkit), [desde BDS](/docs/es/migration/bds), [desde PocketMine-MP](/docs/es/migration/pocketmine).
