**PowerNukkitX** (PNX) hace funcionar un servidor de Minecraft: Bedrock Edition. Nació a partir de Nukkit y añade mejoras de rendimiento, una API de plugins más completa, bloques, items y entidades personalizados, y un comportamiento más cercano al vanilla. Sirve tanto para un servidor privado entre amigos como para una red pública.

Los jugadores entran con el cliente normal de Bedrock, en cualquier dispositivo, sin mods. Todo lo que el servidor necesita cabe en una sola carpeta:

## Plataformas compatibles

PowerNukkitX funciona en **Windows**, **Linux** y **macOS**, necesita **Java 21 o superior** y sigue las últimas versiones de Minecraft: Bedrock Edition. La página de [Requisitos](/docs/es/requirements) da las cifras de hardware.
