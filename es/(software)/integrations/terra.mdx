[Terra](https://terra.polydev.org/) es un generador de terreno controlado por **paquetes de configuración**: cada paquete describe sus propios biomas y paisajes. PowerNukkitX lo admite de serie.

<Steps>
  <Step>
    ### Activa Terra

    Con el servidor **detenido**, pon:

    ```yaml title="pnx.yml"
    miscSettings:
      enableTerra: true
    ```

    Arranca el servidor: crea una carpeta `terra/` en la raíz.
  </Step>
  <Step>
    ### Añade un paquete

    1. Elige un paquete, por ejemplo de los [paquetes de la comunidad](https://terra.polydev.org/config/community-packs.html).
    2. Pon su carpeta o su ZIP en `terra/packs/`.
    3. Abre el `pack.yml` del paquete y apunta su `id`, por ejemplo `REIMAGEND`.
  </Step>
  <Step>
    ### Crea un mundo que lo use

    Crea una carpeta para el nuevo mundo dentro de `worlds/`, por ejemplo `worlds/end`, con un `config.json`:

    ```json title="worlds/end/config.json"
    {
      "format": "leveldb",
      "enable": true,
      "generators": {
        "2": {
          "name": "terra",
          "seed": 0,
          "enableAntiXray": false,
          "antiXrayMode": "LOW",
          "preDeobfuscate": true,
          "dimensionData": {
            "dimensionName": "minecraft:end",
            "dimensionId": 2,
            "minHeight": 0,
            "maxHeight": 255,
            "height": 256,
            "chunkSectionCount": 16
          },
          "preset": {
            "pack": "REIMAGEND"
          }
        }
      }
    }
    ```

    Sustituye `REIMAGEND` en `preset.pack` por el id de tu paquete.
  </Step>
  <Step>
    ### Visítalo

    Arranca el servidor y teletranspórtate al nuevo mundo:

    ```bash
    /world tp end Dim2
    ```
  </Step>
</Steps>
