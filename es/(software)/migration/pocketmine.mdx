PocketMine-MP está escrito en PHP y PowerNukkitX en Java. Tus mundos pueden venir contigo; los plugins y la configuración no.

## Pasos

<Steps>
  <Step>
    ### Instala PowerNukkitX

    Sigue la [guía de instalación](/docs/es/installation), arranca el servidor una vez para que cree sus archivos y luego detenlo.
  </Step>
  <Step>
    ### Copia tus mundos

    Copia las carpetas de tus mundos desde `worlds/` de PocketMine-MP a `worlds/` de PowerNukkitX y define el principal como mundo por defecto:

    ```yaml title="pnx.yml"
    baseSettings:
      defaultLevelName: "MyWorld"
    ```
  </Step>
  <Step>
    ### Copia tus ajustes

    | Ajuste de PocketMine-MP | Sección de `pnx.yml` | Clave de `pnx.yml` |
    | :-- | :-- | :-- |
    | `server-port` (`server.properties`) | `baseSettings` | `port` |
    | `max-players` (`server.properties`) | `baseSettings` | `maxPlayers` |
    | `xbox-auth` (`pocketmine.yml`) | `baseSettings` | `xboxAuth` |
    | `view-distance` (`server.properties`) | `gameplaySettings` | `viewDistance` |
    | `difficulty` (`server.properties`) | `gameplaySettings` | `difficulty` |
    | `gamemode` (`server.properties`) | `gameplaySettings` | `gamemode` |
    | `white-list` (`server.properties`) | `baseSettings` | `allowList` |
  </Step>
</Steps>

## Lo que no se conserva

<Accordions>
  <Accordion title="Plugins">
    Los plugins de PocketMine-MP son PHP y **no pueden ejecutarse** en PowerNukkitX: no copies archivos `.phar` ni código PHP en `plugins/`. Busca equivalentes en Java en el [hub de plugins](https://powernukkitx.org/plugins) o reconstruye las funciones con la [API de plugins](/docs/es/development).
  </Accordion>
  <Accordion title="Permisos">
    PocketMine-MP usa un `permissions.yml` en YAML. En PowerNukkitX, instala **LuckPerms** para volver a crear tus grupos y nodos. Consulta [Permisos y seguridad](/docs/es/permissions).
  </Accordion>
</Accordions>
