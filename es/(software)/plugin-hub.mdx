El [hub de plugins](https://powernukkitx.org/plugins) reúne los plugins de la comunidad para PowerNukkitX. Cada ficha y cada versión se **revisa** antes de publicarse, y cada jar se **analiza**.

## Instalar un plugin

<Steps>
  <Step>
    ### Encontrarlo

    Busca por nombre, repositorio o palabra clave, o navega por categorías. Ordena por descargas, tendencia, estrellas, valoración o última actualización, y filtra por versión del servidor o editor verificado. ¿Prefieres una vista compacta? Cambia a la vista de **lista** junto al orden.
  </Step>
  <Step>
    ### Descargarlo

    En la página del plugin, **Cómo instalar** te da el jar de la última versión aprobada, directamente desde la release de GitHub del autor.
  </Step>
  <Step>
    ### Instalarlo

    Pon el jar en la carpeta `plugins/` de tu servidor y reinicia el servidor.
  </Step>
</Steps>

<Callout type="info">
  Mira primero la tarjeta **Detalles**: muestra lo que necesita el plugin (dependencias, versión de la API) y avisa cuando un plugin lleva más de un año sin actualizarse.
</Callout>

## Publicar tu plugin

<Steps>
  <Step>
    ### Preparar el repositorio

    Tu plugin debe estar en un **repositorio público de GitHub** al que puedas hacer push, con una **release** que contenga un `.jar`. Consulta [Crear un plugin](/docs/es/development/basics) para hacer uno.
  </Step>
  <Step>
    ### Enviarlo

    Inicia sesión y abre [Enviar un plugin](https://powernukkitx.org/dashboard/submit). Elige el repositorio, dale un nombre, un resumen de una línea y hasta tres categorías, y si quieres un color de acento. Una vista previa en directo muestra cómo quedará.
  </Step>
  <Step>
    ### Esperar la revisión

    Un revisor comprueba la ficha y lee el jar más reciente. Recibes una notificación con la decisión; si se rechaza, ves el motivo y puedes volver a enviarlo.
  </Step>
  <Step>
    ### Mantenerlo al día

    Cada nueva release de GitHub se revisa a su vez antes de que los jugadores puedan descargarla. Gestiónalo todo desde **Panel > Mis plugins**.
  </Step>
</Steps>

## Personaliza tu página

Desde la página de gestión de tu plugin, en **Ficha**:

| Qué | Cómo | Revisión |
| :-- | :-- | :-- |
| Nombre, resumen, categorías | Editar la ficha | Se revisa en una ficha pública |
| Icono | `.jarbage/icon.png` en tu repositorio, o súbelo | Se revisa |
| Color de acento | Uno de los siete colores del sitio | Se aplica al momento |
| Enlaces | Web, documentación, Discord, reporte de errores, soporte (solo https) | Se aplica al momento |
