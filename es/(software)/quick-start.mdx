---
title: "Inicio rápido"
description: "De cero a un servidor al que puedes conectarte, en unos cinco minutos."
icon: Zap
---

La forma más rápida es la herramienta de línea de comandos `pnx`. Descarga la última versión estable y arranca el servidor por ti.

<Callout type="info" title="Necesitas">
  **Java 21** o superior, **Node.js** (para `npm`) y 2 GB de memoria libre. Consulta los [Requisitos](/docs/es/requirements).
</Callout>

<Steps>
  <Step>
    ### Instalar la CLI

    ```bash
    npm i -g @powernukkitx/cli
    ```

    ¿Sin instalación global? `npx @powernukkitx/cli init` también funciona.
  </Step>
  <Step>
    ### Crear el servidor

    En una carpeta vacía:

    ```bash
    pnx init
    ```
  </Step>
  <Step>
    ### Arrancarlo

    ```bash
    pnx start --memory 4G
    ```

    Ejecuta `pnx` sin argumentos para abrir un menú interactivo.
  </Step>
  <Step>
    ### Conectarte

    En Minecraft Bedrock, abre **Jugar > Servidores > Añadir servidor** e introduce la dirección de tu equipo con el puerto **19132**. En el mismo ordenador, usa `127.0.0.1`.

    <Callout type="tip" title="¿Los jugadores de otro dispositivo no pueden conectarse?">
      Bedrock usa **UDP**, no TCP. Permite el puerto UDP `19132` en tu cortafuegos y redirígelo en tu router para los jugadores de fuera de tu red. Más en [Solución de problemas](/docs/es/faq/troubleshooting).
    </Callout>
  </Step>
</Steps>
