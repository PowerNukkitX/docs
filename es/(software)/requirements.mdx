Antes de instalar, comprueba que tu máquina tiene el hardware, la versión de Java y el sistema que se indican abajo.

## Hardware

<Tabs items={["Mínimo", "Recomendado"]}>
  <Tab value="Mínimo">
    Suficiente para un servidor pequeño con pocos jugadores. El rendimiento depende del tamaño del mundo y de los plugins.

    | Componente | Mínimo |
    | :-- | :-- |
    | CPU | 2 núcleos, 2,5 GHz |
    | RAM | 2 GB |
    | Almacenamiento | 1 GB libre |
    | Java | OpenJDK 21 o superior |
    | Sistema | Windows 10 / 11, Linux (Ubuntu 20.04+), macOS |
    | Red | 1 Mbps de subida |
  </Tab>
  <Tab value="Recomendado">
    Para un servidor con tráfico real. Con más de 20 jugadores o varios mundos, añade CPU, RAM y ancho de banda.

    | Componente | Recomendado |
    | :-- | :-- |
    | CPU | 4+ núcleos, 3,0 GHz+ |
    | RAM | 4 GB o más |
    | Almacenamiento | SSD con 5 GB libres |
    | Java | OpenJDK 21 o superior |
    | Sistema | Windows 10 / 11, Linux (Ubuntu 22.04+), macOS |
    | Red | 10 Mbps+ de subida |
  </Tab>
</Tabs>

## Java

PowerNukkitX necesita **Java 21 o superior**, de 64 bits.

<Steps>
  <Step>Instala un entorno de ejecución de Java 21 de **64 bits**. Se recomienda OpenJDK.</Step>
  <Step>Define la variable de entorno `JAVA_HOME` apuntando a esa instalación.</Step>
  <Step>Añade la carpeta `bin` de Java a tu `PATH` y comprueba con `java -version`.</Step>
</Steps>

<Callout type="warn">
  Las versiones antiguas de Java (20 e inferiores) provocan cierres o errores de plugins. Consulta [Solución de problemas](/docs/es/faq/troubleshooting) si `java -version` muestra la versión equivocada.
</Callout>

## Buenas costumbres

- **Haz copias de seguridad** de tu carpeta `worlds/` y de `pnx.yml` con regularidad. Consulta [Copias de seguridad](/docs/es/administration/backups).
- **Deja libre el 20 % del disco** para los logs y los mundos que crecen.
- **Instala solo plugins** hechos para tu versión de PowerNukkitX.
- **Vigila la CPU y la memoria** con `htop` en Linux o el Administrador de tareas en Windows.
