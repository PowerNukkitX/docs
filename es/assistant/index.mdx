El **PowerNukkitX Assistant** es una aplicación de escritorio para Windows, Linux y macOS. Crea un servidor, lo arranca, muestra su consola, instala plugins y edita sus ajustes, todo sin terminal. Está pensado para un primer servidor y sigue siendo útil cuando llevas varios.

<AssistantWindow />

Por dentro, maneja la [PNX CLI](/docs/es/cli): la aplicación incluye la CLI compilada y llama exactamente a las mismas funciones que `pnx`, así que la ventana y la terminal nunca pueden discrepar sobre cómo se crea o se arranca un servidor.

## Instalar

Descarga el instalador de tu sistema desde las [releases de pnx-cli](https://github.com/PowerNukkitX/pnx-cli/releases):

| Sistema | Archivo |
| :-- | :-- |
| Windows | El instalador (`.exe` de instalación), o el `.exe` portable que funciona sin instalar. |
| Linux | El `.AppImage`: hazlo ejecutable y ábrelo. |
| macOS | El `.dmg`: ábrelo y arrastra la aplicación a Aplicaciones. |

El servidor sigue necesitando **Java 21** o superior. El Assistant lo comprueba en el primer arranque y te avisa si falta.

## Primer arranque

Una breve bienvenida pasa por tres pantallas:

<Steps>
  <Step>**Bienvenida**: lo que hace el Assistant.</Step>
  <Step>**Java**: busca Java 21+ y dice lo que ha encontrado.</Step>
  <Step>**Tu primer servidor**: créalo con un clic, conecta una carpeta de servidor que ya tengas, u omítelo por ahora.</Step>
</Steps>

¿Quieres volver a verla? **Ajustes > Volver a ver la introducción**.

## El tutorial guiado

**Tutorial guiado**, en la barra lateral, tiene siete pasos para un primer servidor, cada uno con un botón que hace el trabajo: qué es PowerNukkitX, comprobar Java, crear el servidor, el primer arranque, entrar desde Minecraft, añadir plugins e invitar a amigos de fuera de tu red.

## Atajos de teclado

| Teclas | Acción |
| :-- | :-- |
| `Ctrl` + `K` | La paleta de comandos: ir a cualquier sitio, arrancar o detener el servidor, hacer una copia. |
| `Ctrl` + `1` … `7` | Cambiar entre las vistas de la barra lateral. |
| `Esc` | Cerrar la paleta o un diálogo. |
