## Ajustes del servidor

La vista **Ajustes** del servidor es un editor del `pnx.yml` del servidor activo. Aparece después del primer arranque del servidor, que es cuando se crea `pnx.yml`.

- Primero van los **esenciales**: MOTD, puerto, máximo de jugadores, nombre del mundo, lista blanca, distancia de visión, autenticación Xbox y más.
- **Todas las claves** lista los demás ajustes, agrupados por sección, con un filtro para encontrar uno por su nombre.
- Cada ajuste tiene el control adecuado: un interruptor para sí o no, un campo numérico para cantidades y puertos, una lista para el idioma del servidor. Los comentarios del archivo se muestran como ayudas emergentes.

**Guardar** solo reescribe las líneas que cambiaste, así que los comentarios y la estructura del archivo se conservan, y guarda una copia única como `pnx.yml.assistant-bak`. Las listas y los bloques anidados son de solo lectura aquí: **Abrir el archivo** para cambiarlos a mano.

<Callout type="warn">
  Los ajustes se aplican en el siguiente arranque. Guarda con el servidor detenido: un servidor en marcha reescribe `pnx.yml` al apagarse.
</Callout>

## Preferencias del Assistant

Los **Ajustes** de la propia aplicación. Cada cambio se aplica al momento.

| Ajuste | Opciones |
| :-- | :-- |
| Idioma | English, Français, Español, Deutsch, Português (Brasil). |
| Tema | Claro, oscuro o el del sistema. |
| Densidad | Cómoda, o compacta para pantallas pequeñas. |
| Reducir movimiento | Desactiva las transiciones y el movimiento 3D. |
| Confirmar al cerrar | Ofrece detener el servidor correctamente antes de salir. |

## Actualizaciones

El Assistant se actualiza solo. Por defecto busca una versión nueva cada tres horas y puede descargarla en segundo plano; instalarla sigue siendo decisión tuya. **Comprobar ahora** busca al momento.

## Tus datos

El Assistant guarda sus preferencias y su lista de servidores en `~/.pnx-cli`, compartido con la CLI. **Abrir** muestra esa carpeta. **Restablecer preferencias** devuelve el tema, la densidad, el movimiento y la memoria a sus valores por defecto; tus servidores no se tocan.
