## init [#init]

Crea un servidor: una carpeta, el jar de PowerNukkitX y los scripts de inicio. Alias: `new`, `create`.

```bash
pnx init
pnx init --dir my-server
pnx init --version 1.21.0
```

| Opción | Efecto |
| :-- | :-- |
| `--dir <ruta>` | La carpeta donde crear el servidor. |
| `--version <tag>` | Un tag de versión de PowerNukkitX, que salta el selector de versión. |

En una terminal pregunta lo que falta; en un script (o con `--json`) se ejecuta sin preguntas. El jar viene de las releases de GitHub de PowerNukkitX y los scripts de [PowerNukkitX/scripts](https://github.com/PowerNukkitX/scripts). El nuevo servidor pasa a ser el servidor por defecto.

## start [#start]

Arranca el servidor en primer plano, con las opciones de Java que necesita PowerNukkitX. Alias: `run`, `up`.

```bash
pnx start
pnx start --memory 4G
pnx start --restart
pnx start --dry-run
```

| Opción | Efecto |
| :-- | :-- |
| `--dir <ruta>` | La carpeta del servidor, en lugar del servidor por defecto. |
| `-m`, `--memory <tamaño>` | Heap de Java al arrancar, `2G` por defecto. |
| `--restart` | Vuelve a arrancar el servidor cuando termina con un error. |
| `--dry-run` | Muestra el comando `java` en lugar de ejecutarlo. |

`pnx start` lanza Java con UTF-8 en todo, el recolector de basura ZGC, las opciones `--add-opens` y `-XX:MaxRAMPercentage=75.0`, para que el heap pueda crecer hasta tres cuartos de la memoria de la máquina. Usa el Java de `JAVA_HOME` cuando está definido.

## stop [#stop]

Detiene el servidor que lanzó `pnx start`, mediante el id de proceso que guardó. Alias: `down`.

```bash
pnx stop
```

<Callout type="info">
  Para una parada limpia desde dentro, escribe `stop` en la consola del servidor: primero se guarda todo.
</Callout>

## console [#console]

Abre una consola hacia un servidor en marcha, mediante **RCON**.

```bash
pnx console
```

Lee `enable-rcon`, `rcon.port` (`25575` por defecto) y `rcon.password` del `server.properties` del servidor. RCON viene desactivado; en ese caso, `pnx console` te dice qué activar. Escribe `exit` para salir.

## logs [#logs]

Muestra el log del servidor y lo sigue. Alias: `log`.

```bash
pnx logs
pnx logs --lines 200
pnx logs --no-follow
```

| Opción | Efecto |
| :-- | :-- |
| `-n`, `--lines <n>` | Cuántas líneas mostrar primero. |
| `--follow` | Sigue mostrando las líneas nuevas a medida que se escriben. `--no-follow` muestra y sale. |

## config [#config]

Muestra la configuración que lee el servidor, para comprobar un valor sin abrir el archivo.

```bash
pnx config
```

## use [#use]

Elige el servidor sobre el que trabajan todos los comandos.

```bash
pnx use
pnx use ./my-server
pnx use --clear
```

Sin carpeta, lista los servidores que encuentra y te deja elegir. `--clear` vuelve a olvidar el servidor por defecto.
