**PNX-APT** es un procesador de anotaciones que actúa al compilar. Anota tus clases y, al compilar:

<Steps>
  <Step>genera el descriptor `powernukkitx.yml` dentro de tu jar;</Step>
  <Step>genera una clase `PNXPluginBootstrap` que registra tus comandos, listeners y tareas;</Step>
  <Step>ejecuta ese bootstrap cuando se activa tu plugin.</Step>
</Steps>

Sin `plugin.yml` que escribir ni llamadas a `registerEvents` que recordar.

## Metadatos del plugin: `@PluginMeta`

Ponla en tu **única** clase principal, la que extiende `PluginBase`:

```java title="MyPlugin.java"
package org.example;

import org.powernukkitx.plugin.PluginBase;
import org.powernukkitx.plugin.PluginLoadOrder;
import org.powernukkitx.plugin.annotation.PluginMeta;

@PluginMeta(
    name = "MyPlugin",
    version = "1.0.0",
    api = {"3.0.0-SNAPSHOT"},
    authors = {"AuthorName"},
    description = "An automated plugin using annotations!",
    website = "https://example.com",
    order = PluginLoadOrder.POSTWORLD
)
public class MyPlugin extends PluginBase {
    // no plugin.yml or powernukkitx.yml to write
}
```

| Parámetro | Tipo | |
| :-- | :-- | :-- |
| `name` | `String` | El nombre del plugin. |
| `version` | `String` | Su versión. |
| `api` | `String[]` | Versiones compatibles de la API de PowerNukkitX, por ejemplo `{"3.0.0-SNAPSHOT"}`. |
| `authors` | `String[]` | Opcional. Autores. |
| `description` | `String` | Opcional. Una descripción. |
| `website` | `String` | Opcional. Un sitio web. |
| `prefix` | `String` | Opcional. Un prefijo propio para el logger. |
| `depend` | `String[]` | Opcional. Plugins que deben cargarse antes. |
| `softDepend` | `String[]` | Opcional. Plugins que se cargan antes si están presentes. |
| `loadBefore` | `String[]` | Opcional. Plugins que se cargan después de este. |
| `order` | `PluginLoadOrder` | Opcional. `POSTWORLD` (por defecto) o `STARTUP`. |

## Listeners: `@EventListener`

En lugar de llamar a `registerEvents(...)` en `onEnable()`:

```java title="MyListener.java"
package org.example;

import org.powernukkitx.event.EventHandler;
import org.powernukkitx.event.Listener;
import org.powernukkitx.event.player.PlayerJoinEvent;
import org.powernukkitx.plugin.annotation.EventListener;

@EventListener
public class MyListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage("Welcome to the server!");
    }
}
```

## Tareas: `@ScheduleTask`

En una clase `Runnable` (o `Task`), o en un método `public static`:

| Opción | Por defecto | |
| :-- | :-- | :-- |
| `delay` | `0` | Ticks antes de la primera ejecución. |
| `period` | `0` | Ticks entre ejecuciones. `0` la ejecuta una vez. |
| `async` | `false` | Ejecutar fuera del hilo principal. |

<Tabs items={["En una clase", "En un método"]}>
  <Tab value="En una clase">
    ```java title="MyTask.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    @ScheduleTask(delay = 100, period = 200, async = false)
    public class MyTask implements Runnable {
        @Override
        public void run() {
            System.out.println("Runs every 10 seconds!");
        }
    }
    ```
  </Tab>
  <Tab value="En un método">
    ```java title="StaticTasks.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    public class StaticTasks {
        @ScheduleTask(delay = 20, async = true)
        public static void runOnceAsync() {
            System.out.println("Runs once, asynchronously, after 1 second!");
        }
    }
    ```
  </Tab>
</Tabs>

## Comandos: `@CommandDefinition`

Registra el comando en el mapa de comandos del servidor. `commandMode` elige cómo se enrutan los argumentos:

```java title="MyCommand.java"
import org.powernukkitx.command.Command;
import org.powernukkitx.plugin.annotation.CommandDefinition;
import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

@CommandDefinition(
    name = "mycommand",
    description = "An annotation-registered command",
    usage = "/mycommand",
    aliases = {"mycmd"},
    permission = "myplugin.command.use",
    commandMode = CommandMode.COMMAND_TREE
)
public class MyCommand extends Command {
    // COMMAND_TREE: override buildCommandTree(RouteTree tree)
    // RAW: override execute(CommandSender sender, String label, String[] args)
}
```

| Modo | |
| :-- | :-- |
| `COMMAND_TREE` (por defecto) | El árbol de rutas fluido: sobrescribe `buildCommandTree(RouteTree tree)`. Consulta [Comandos](/docs/es/development/basics/commands). |
| `PARAM_TREE` | La API de parámetros de subcomandos. |
| `RAW` | Sin enrutado automático: analiza tú los argumentos en `execute`. |
