## Antes de empezar

- Un **JDK 21** o superior
- Algo de Java
- Un servidor PowerNukkitX para hacer pruebas
- Un IDE: IntelliJ IDEA, Eclipse o VS Code

<Callout type="info" title="Sáltate la configuración">
  La [plantilla de plugins de PowerNukkitX](https://github.com/PowerNukkitX/PluginTemplate) es un proyecto listo para usar con todo lo de abajo ya configurado.
</Callout>

Tu proyecto quedará así:

<Steps>
  <Step>
    ### Configurar la compilación

    La compilación obtiene la API del servidor del repositorio de PowerNukkitX y empaqueta tu plugin como jar. El objetivo es **Java 21**.

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```xml title="pom.xml"
        <project xmlns="http://maven.apache.org/POM/4.0.0"
                 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                 xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
            <modelVersion>4.0.0</modelVersion>

            <groupId>org.example</groupId>
            <artifactId>MyPlugin</artifactId>
            <version>1.0.0-SNAPSHOT</version>

            <properties>
                <maven.compiler.source>21</maven.compiler.source>
                <maven.compiler.target>21</maven.compiler.target>
                <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
            </properties>

            <repositories>
                <repository>
                    <id>central</id>
                    <url>https://repo.maven.apache.org/maven2/</url>
                </repository>
                <repository>
                    <id>PowerNukkitX-releases</id>
                    <name>PowerNukkitX Repository</name>
                    <url>https://repo.powernukkitx.org/releases</url>
                </repository>
            </repositories>

            <dependencies>
                <!-- "3.0.0-SNAPSHOT" is the current release; "nightly-SNAPSHOT" the latest
                     development build, which may break the API. -->
                <dependency>
                    <groupId>org.powernukkitx</groupId>
                    <artifactId>server</artifactId>
                    <version>3.0.0-SNAPSHOT</version>
                    <scope>provided</scope>
                </dependency>
            </dependencies>

            <build>
                <plugins>
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-compiler-plugin</artifactId>
                        <version>3.11.0</version>
                        <configuration>
                            <source>21</source>
                            <target>21</target>
                        </configuration>
                    </plugin>
                    <!-- bundles your own dependencies into the jar -->
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-shade-plugin</artifactId>
                        <version>3.4.1</version>
                        <executions>
                            <execution>
                                <phase>package</phase>
                                <goals>
                                    <goal>shade</goal>
                                </goals>
                            </execution>
                        </executions>
                    </plugin>
                </plugins>
            </build>
        </project>
        ```
      </Tab>
      <Tab value="Gradle">
        ```kotlin title="settings.gradle.kts"
        rootProject.name = "MyPlugin"
        ```

        ```kotlin title="build.gradle.kts"
        plugins {
            java
            id("com.github.johnrengelman.shadow") version "8.1.1"
        }

        group = "org.example"
        version = "1.0.0-SNAPSHOT"

        repositories {
            mavenCentral()
            maven { url = uri("https://repo.powernukkitx.org/releases") }
        }

        dependencies {
            // "3.0.0-SNAPSHOT" is the current release; "nightly-SNAPSHOT" the latest
            // development build, which may break the API.
            compileOnly("org.powernukkitx:server:3.0.0-SNAPSHOT")
        }

        tasks.withType<JavaCompile> {
            options.encoding = "UTF-8"
            sourceCompatibility = "21"
            targetCompatibility = "21"
        }

        tasks {
            build { dependsOn(shadowJar) }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Describir el plugin

    El servidor lee un archivo de metadatos llamado `plugin.yml` (o `powernukkitx.yml`) en `src/main/resources`:

    ```yaml title="plugin.yml"
    name: ExamplePlugin
    main: org.example.ExamplePlugin
    # version and api must be strings: keep the quotes
    version: "1.0.0"
    api: "2.0.0"
    load: POSTWORLD
    author: PowerNukkitX Team
    # author and authors are merged into one list
    authors: ["Example", "Another"]
    description: Example plugin from the PNX documentation
    website: https://docs.powernukkitx.org/
    ```

    <Callout type="info">
      Con el [procesador de anotaciones](/docs/es/development/basics/annotations), este archivo se genera solo.
    </Callout>
  </Step>
  <Step>
    ### Escribir la clase principal

    La clase principal extiende `PluginBase`. El servidor llama a sus tres métodos en cada etapa de la vida del plugin:

    ```java title="ExamplePlugin.java"
    package org.example;

    import org.powernukkitx.plugin.PluginBase;
    import org.powernukkitx.utils.TextFormat;

    public class ExamplePlugin extends PluginBase {
        @Override
        public void onLoad() {
            this.getLogger().info(TextFormat.WHITE + "Example plugin loaded!");
        }

        @Override
        public void onEnable() {
            this.getLogger().info(TextFormat.DARK_GREEN + "Example plugin enabled!");
        }

        @Override
        public void onDisable() {
            this.getLogger().info(TextFormat.DARK_RED + "Example plugin disabled!");
        }
    }
    ```

    <PluginLifecycle />
  </Step>
  <Step>
    ### Compilar e instalar

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```bash
        mvn clean package
        ```

        El jar está en `target/`.
      </Tab>
      <Tab value="Gradle">
        ```bash
        ./gradlew clean build
        ```

        El jar, con las librerías incluidas, es `build/libs/MyPlugin-1.0.0-SNAPSHOT-all.jar`.
      </Tab>
    </Tabs>

    Copia el jar en la carpeta `plugins/` de tu servidor y reinícialo. Tus mensajes aparecen en la consola.
  </Step>
</Steps>
