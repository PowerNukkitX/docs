El planificador ejecuta tu código más tarde o con un temporizador, sin bloquear el hilo principal del servidor. El tiempo se cuenta en **ticks**: el servidor hace 20 ticks por segundo.

<TickTimeline />

## Tareas rápidas

Programa una lambda directamente desde tu plugin:

<Tabs items={["Repetida", "Retrasada"]}>
  <Tab value="Repetida">
    ```java
    @Override
    public void onEnable() {
        // every 20 ticks = every second
        this.getServer().getScheduler().scheduleRepeatingTask(this, () -> {
            this.getLogger().info("Repeating task executed!");
        }, 20);
    }
    ```
  </Tab>
  <Tab value="Retrasada">
    ```java
    // once, after 100 ticks = 5 seconds
    this.getServer().getScheduler().scheduleDelayedTask(this, () -> {
        this.getLogger().info("Delayed task executed after 5 seconds!");
    }, 100);
    ```
  </Tab>
</Tabs>

## Una clase de tarea

Para una lógica más elaborada, extiende `Task`. `onRun` recibe el tick actual:

```java title="ExampleTask.java"
package com.example.task;

import org.powernukkitx.plugin.Plugin;
import org.powernukkitx.scheduler.Task;

public class ExampleTask extends Task {
    private final Plugin plugin;

    public ExampleTask(Plugin plugin) {
        this.plugin = plugin;
    }

    @Override
    public void onRun(int currentTick) {
        plugin.getLogger().info("Task executed at tick: " + currentTick);
    }
}
```

Prográmala en `onEnable()`:

```java
@Override
public void onEnable() {
    this.getServer().getScheduler().scheduleRepeatingTask(this, new ExampleTask(this), 20);
}
```

## Detener una tarea

Cada llamada `schedule…` devuelve un `TaskHandler`. Guárdalo para detener la tarea más tarde; una `Task` también puede detenerse sola con `cancel()`:

```java
private TaskHandler countdown;

@Override
public void onEnable() {
    countdown = this.getServer().getScheduler().scheduleRepeatingTask(this, new ExampleTask(this), 20);
}

public void stopCountdown() {
    countdown.cancel();
}
```

`getScheduler().cancelTask(this)` detiene de golpe todas las tareas de tu plugin. El servidor lo hace por ti cuando se desactiva tu plugin.

## Trabajo lento: fuera del hilo principal

Una tarea se ejecuta en el hilo principal, entre dos ticks: mientras dura, todo el servidor espera. Leer un archivo, llamar a una API web o consultar una base de datos corresponde a una `AsyncTask`, que se ejecuta en un hilo de trabajo:

```java title="FetchTask.java"
import org.powernukkitx.Server;
import org.powernukkitx.scheduler.AsyncTask;

public class FetchTask extends AsyncTask {
    @Override
    public void onRun() {
        // on a worker thread: slow work only, no access to players or worlds
        setResult(loadSomethingSlow()); // your own slow method
    }

    @Override
    public void onCompletion(Server server) {
        // back on the main thread: safe to use the result in the game
        server.broadcastMessage("Loaded: " + getResult());
    }
}
```

```java
this.getServer().getScheduler().scheduleAsyncTask(this, new FetchTask());
```

<Callout type="warn">
  No toques nunca jugadores, entidades ni mundos desde `onRun()`: el juego no es seguro entre hilos. Pasa el resultado a `onCompletion()`, que se ejecuta en el hilo principal.
</Callout>

<Callout type="info">
  ¿Prefieres anotaciones? `@ScheduleTask` programa una clase o un método estático por ti: consulta [Procesador de anotaciones](/docs/es/development/basics/annotations).
</Callout>
