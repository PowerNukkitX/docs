Lo que sigue funciona igual para todos los tipos de formulario.

## Título [#title]

Defínelo en el constructor o con un método:

```java
// Using the constructor
CustomForm custom = new CustomForm("title");
ModalForm modal = new ModalForm("title");
SimpleForm simple = new SimpleForm("title");

// Using the method
custom.title("other title");
modal.title("other title");
simple.title("other title");
```

## Escuchar las respuestas

Cada formulario ejecuta un callback cuando el jugador lo envía, y otro cuando lo cierra:

```java
form.onSubmit((player, response) -> {
    /*

    Handle the form response here,
    the object depends on the form you've created.
    For details, check out the specific form documentation.

    */
})
form.onClose(player -> player.sendMessage("You have closed the form!"));
```

## Enviar un formulario [#sending-a-form]

```java
form.send(player);
```

También puedes pasar un id, aunque no se recomienda:

```java
form.send(player, 123);
```

## Metadatos

Asocia lo que quieras a un formulario, por ejemplo para reconocerlo después o actualizarlo:

```java
// Example: Saving an entity
Entity entity = ...;

form.putMeta("form-type", "manage-entity")
    .putMeta("entity", entity);
```

Léelo de nuevo con `getMeta`:

```java
Entity entity = form.getMeta("entity");
```

Con un valor por defecto si la clave puede faltar:

```java
Entity entity = form.getMeta("entity", backupEntity);
```

## Quién lo tiene abierto

Un formulario puede mostrarse a varios jugadores a la vez (un selector de equipo, por ejemplo). Lístalos:

```java
ObjectArraySet<Player> viewers = form.viewers();
```

O comprueba un jugador concreto:

```java
boolean isViewer = form.isViewer(player);
```
