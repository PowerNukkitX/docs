Estos endpoints cambian poco y se guardan en caché con generosidad. No tienen parámetros.

## Categorías

```text
GET /api/v1/categories
```

Cada categoría de plugin visible, como `{ id, label }`. Usa un `id` en el parámetro `category` de [`/plugins`](/docs/es/web-api/plugins).

<ApiTry path="/categories" />

## Colecciones

```text
GET /api/v1/collections
```

Las colecciones publicadas: listas de plugins elegidas a mano, cada una con los plugins que agrupa.

<ApiTry path="/collections" />

## Insignias

```text
GET /api/v1/badges
```

Cada insignia que el hub puede otorgar a un plugin, con su nivel y su icono.

<ApiTry path="/badges" />

## Destacado

```text
GET /api/v1/spotlight
```

El plugin que el equipo destaca en la página de inicio, con su nota. `data` es `null` cuando no hay nada destacado.

<ApiTry path="/spotlight" />
