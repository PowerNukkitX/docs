PowerNukkitX n'est pas le seul serveur Bedrock. Cette page le compare à Nukkit et au Bedrock Dedicated Server (BDS) de Mojang, pour vous aider à choisir.

## En un coup d'œil

| | PowerNukkitX | Nukkit | BDS (officiel) |
| :-- | :-- | :-- | :-- |
| Performances | **Élevées** | Moyennes | Élevées |
| Système de plugins | **Oui, Java** | Oui, Java | Non |
| API | **Moderne** | Ancienne | Aucune |
| Nouvelles versions Bedrock | **Rapide** | Lent | Officiel |
| Open source | **Oui** | Oui | Non |
| Communauté | **Active** | Moyenne | Officielle |
| Contenu custom | **Bon** | Moyen | Faible |

## Lequel choisir

<Cards>
  <Card title="PowerNukkitX">
    Un serveur moderne que vous voulez étendre avec des plugins et du contenu custom, avec une communauté active derrière.
  </Card>
  <Card title="Nukkit">
    Un serveur qui dépend d'anciens plugins Nukkit jamais mis à jour.
  </Card>
  <Card title="BDS">
    Une expérience purement vanilla, avec les mises à jour officielles de Mojang et une compatibilité client maximale.
  </Card>
</Cards>

## Passer à PowerNukkitX

<Steps>
  <Step>
    **Vérifiez vos plugins.** Certains plugins Nukkit doivent être adaptés à l'API PowerNukkitX.
  </Step>
  <Step>
    **Reprenez vos mondes et vos réglages.** Copiez vos mondes, puis reportez vos réglages dans `pnx.yml`.
  </Step>
  <Step>
    **Revoyez les permissions.** Recréez vos groupes et vos nœuds de permission.
  </Step>
</Steps>

Chaque source a son guide : [depuis Nukkit](/docs/fr/migration/nukkit), [depuis BDS](/docs/fr/migration/bds), [depuis PocketMine-MP](/docs/fr/migration/pocketmine).
