## Choisissez votre système

<Cards>
  <Card icon={<Monitor />} title="Windows" href="/docs/fr/installation/windows">
    Windows 10 ou 11, avec un script `start.bat`.
  </Card>
  <Card icon={<Apple />} title="macOS" href="/docs/fr/installation/macos">
    Java via Homebrew, Intel ou Apple Silicon.
  </Card>
  <Card icon={<Terminal />} title="Linux" href="/docs/fr/installation/linux">
    Ubuntu, Debian, CentOS ou RHEL, lancé en service systemd.
  </Card>
  <Card icon={<Container />} title="Docker" href="/docs/fr/installation/docker">
    L'image officielle, avec Docker ou Docker Compose.
  </Card>
</Cards>

</Callout>
