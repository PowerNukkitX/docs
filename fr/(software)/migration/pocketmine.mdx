PocketMine-MP est écrit en PHP et PowerNukkitX en Java. Vos mondes peuvent suivre ; les plugins et la configuration, non.

## Étapes

<Steps>
  <Step>
    ### Installer PowerNukkitX

    Suivez le [guide d'installation](/docs/fr/installation), lancez le serveur une fois pour créer ses fichiers, puis arrêtez-le.
  </Step>
  <Step>
    ### Copier vos mondes

    Copiez vos dossiers de mondes depuis `worlds/` de PocketMine-MP vers `worlds/` de PowerNukkitX, puis définissez le principal par défaut :

    ```yaml title="pnx.yml"
    baseSettings:
      defaultLevelName: "MyWorld"
    ```
  </Step>
  <Step>
    ### Recopier vos réglages

    | Réglage PocketMine-MP | Section de `pnx.yml` | Clé de `pnx.yml` |
    | :-- | :-- | :-- |
    | `server-port` (`server.properties`) | `baseSettings` | `port` |
    | `max-players` (`server.properties`) | `baseSettings` | `maxPlayers` |
    | `xbox-auth` (`pocketmine.yml`) | `baseSettings` | `xboxAuth` |
    | `view-distance` (`server.properties`) | `gameplaySettings` | `viewDistance` |
    | `difficulty` (`server.properties`) | `gameplaySettings` | `difficulty` |
    | `gamemode` (`server.properties`) | `gameplaySettings` | `gamemode` |
    | `white-list` (`server.properties`) | `baseSettings` | `allowList` |
  </Step>
</Steps>

## Ce qui ne suit pas

<Accordions>
  <Accordion title="Plugins">
    Les plugins PocketMine-MP sont en PHP et **ne peuvent pas tourner** sur PowerNukkitX : ne copiez pas de fichiers `.phar` ni de code PHP dans `plugins/`. Trouvez des équivalents Java dans le [hub de plugins](https://powernukkitx.org/plugins), ou recréez les fonctionnalités avec l'[API de plugins](/docs/fr/development).
  </Accordion>
  <Accordion title="Permissions">
    PocketMine-MP utilise un fichier YAML `permissions.yml`. Sur PowerNukkitX, installez **LuckPerms** pour recréer vos groupes et vos nœuds. Voir [Permissions et sécurité](/docs/fr/permissions).
  </Accordion>
</Accordions>
