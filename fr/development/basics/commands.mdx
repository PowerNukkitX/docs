Il existe trois façons d'ajouter une commande. Choisissez la plus simple qui suffit.

| Façon | Idéal pour |
| :-- | :-- |
| `onCommand` dans la classe principale | Une ou deux commandes rapides. |
| Une classe `Command` | Des commandes propres et séparées, avec permissions. |
| Un arbre de commandes | Sous-commandes et arguments typés, avec vérifications et complétion automatiques. |

## 1. `onCommand`

Surchargez `onCommand` dans votre `PluginBase` et déclarez la commande dans `plugin.yml` :

```java title="ExamplePlugin.java"
public class ExamplePlugin extends PluginBase {
    @Override
    public boolean onCommand(CommandSender sender, Command command, String label, String[] args) {
        if (command.getName().equalsIgnoreCase("greet")) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
        return false;
    }
}
```

```yaml title="plugin.yml"
name: ExamplePlugin
main: com.example.ExamplePlugin
version: 1.0.0
commands:
  greet:
    description: Greet a player
    usage: /greet [name]
    permission: greet.permission
```

## 2. Une classe `Command`

Étendez `org.powernukkitx.command.Command` (ou `PluginCommand`). Enregistrez-la par annotation, ou à la main :

<Tabs items={["Avec @CommandDefinition", "À la main"]}>
  <Tab value="Avec @CommandDefinition">
    Pas de code d'enregistrement : le [processeur d'annotations](/docs/fr/development/basics/annotations) s'en charge.

    ```java title="GreetCommand.java"
    package org.example.command;

    import org.powernukkitx.command.Command;
    import org.powernukkitx.command.CommandSender;
    import org.powernukkitx.plugin.annotation.CommandDefinition;
    import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

    @CommandDefinition(
        name = "greet",
        description = "Greet a player",
        usage = "/greet [name]",
        permission = "greet.permission",
        commandMode = CommandMode.RAW // arguments en chaînes simples
    )
    public class GreetCommand extends Command {
        @Override
        public boolean execute(CommandSender sender, String label, String[] args) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
    }
    ```
  </Tab>
  <Tab value="À la main">
    ```java title="GreetCommand.java"
    package org.example.command;

    import org.powernukkitx.command.Command;
    import org.powernukkitx.command.CommandSender;

    public class GreetCommand extends Command {
        public GreetCommand() {
            super("greet", "Greet a player", "/greet [name]");
            this.setPermission("greet.permission");
        }

        @Override
        public boolean execute(CommandSender sender, String label, String[] args) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
    }
    ```

    Puis enregistrez-la dans `onEnable()` :

    ```java
    @Override
    public void onEnable() {
        this.getServer().getCommandMap().register("myplugin", new GreetCommand());
    }
    ```
  </Tab>
</Tabs>

## 3. Un arbre de commandes

L'arbre de commandes est une API fluide : vous décrivez la forme de la commande (mots-clés et arguments typés) et le serveur gère la complétion, les permissions, qui peut la lancer et les erreurs de syntaxe.

<CommandTree />

Appelez `enableCommandTree()` dans le constructeur et construisez les routes dans `buildCommandTree` :

```java title="MyCommand.java"
package org.example.command;

import org.powernukkitx.Player;
import org.powernukkitx.command.Command;
import org.powernukkitx.command.CommandResult;
import org.powernukkitx.command.route.RouteTree;
import org.powernukkitx.command.route.node.RouteNode;
import org.powernukkitx.command.tree.node.MessageStringNode;
import org.powernukkitx.command.tree.node.PlayersNode;
import java.util.List;

public class MyCommand extends Command {
    public MyCommand() {
        super("mycommand", "An advanced CommandTree command");
        this.enableCommandTree();
    }

    @Override
    protected void buildCommandTree(RouteTree tree) {
        // /mycommand info
        tree.getRoot().then(
            RouteNode.literal("info")
                .exec(context -> {
                    context.getSender().sendMessage("This command uses the PowerNukkitX CommandTree!");
                    return CommandResult.success();
                })
        );

        // /mycommand send <player> <message>
        tree.getRoot().then(
            RouteNode.literal("send").then(
                RouteNode.argument("player", new PlayersNode()).then(
                    RouteNode.argument("message", new MessageStringNode())
                        .exec(context -> {
                            List<Player> targets = context.getArg("player");
                            String message = context.getArg("message");
                            for (Player p : targets) {
                                p.sendMessage("Message: " + message);
                            }
                            context.getSender().sendMessage("Message sent!");
                            return CommandResult.success();
                        })
                )
            )
        );
    }
}
```

### Les briques

| Méthode | Effet |
| :-- | :-- |
| `RouteNode.literal(nom)` | Un mot-clé fixe, comme `info` dans `/mycommand info`. |
| `RouteNode.argument(nom, nœud)` | Un argument typé (`PlayersNode`, `IntNode`, `BlockNode`...). Récupérez-le avec `context.getArg(nom)`. |
| `.then(enfant)` | Ajoute le mot-clé ou l'argument suivant. |
| `.exec(context -> ...)` | Rend le nœud exécutable : ce code tourne quand la saisie s'arrête ici. |
| `.senderType(type)` | Qui peut la lancer : `SenderType.PLAYER`, `CONSOLE` ou `ANY`. |
| `.permission(nœud)` | Exige une permission. |
| `.optional(true)` | Rend l'argument facultatif. |
| `.suggest(liste)` | Remplace les suggestions de complétion. |

### Résultats

Chaque `exec` renvoie un `CommandResult` :

| Résultat | Signification |
| :-- | :-- |
| `CommandResult.success()` | Ça a fonctionné. |
| `CommandResult.fail()` | Ça a échoué. |
| `CommandResult.fail("message")` | Ça a échoué, et l'expéditeur voit le message. |
