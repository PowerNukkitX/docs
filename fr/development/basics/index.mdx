## Avant de commencer

- Un **JDK 25** ou plus récent
- Des bases en Java
- Un serveur PowerNukkitX pour tester
- Un IDE : IntelliJ IDEA, Eclipse ou VS Code

<Callout type="info" title="Sauter la configuration">
  Le [modèle de plugin PowerNukkitX](https://github.com/PowerNukkitX/PluginTemplate) est un projet prêt à l'emploi où tout ce qui suit est déjà configuré.
</Callout>

Votre projet ressemblera à ceci :

<Steps>
  <Step>
    ### Configurer le build

    Le build récupère l'API du serveur depuis le dépôt PowerNukkitX et empaquette votre plugin en jar. Ciblez **Java 25**.

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```xml title="pom.xml"
        <project xmlns="http://maven.apache.org/POM/4.0.0"
                 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                 xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
            <modelVersion>4.0.0</modelVersion>

            <groupId>org.example</groupId>
            <artifactId>MyPlugin</artifactId>
            <version>1.0.0-SNAPSHOT</version>

            <properties>
                <maven.compiler.source>21</maven.compiler.source>
                <maven.compiler.target>21</maven.compiler.target>
                <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
            </properties>

            <repositories>
                <repository>
                    <id>central</id>
                    <url>https://repo.maven.apache.org/maven2/</url>
                </repository>
                <repository>
                    <id>PowerNukkitX-releases</id>
                    <name>PowerNukkitX Repository</name>
                    <url>https://repo.powernukkitx.org/releases</url>
                </repository>
            </repositories>

            <dependencies>
                <!-- "3.0.0-SNAPSHOT" est la version actuelle ; "nightly-SNAPSHOT" le dernier
                     build de développement, qui peut casser l'API. -->
                <dependency>
                    <groupId>org.powernukkitx</groupId>
                    <artifactId>server</artifactId>
                    <version>3.0.0-SNAPSHOT</version>
                    <scope>provided</scope>
                </dependency>
            </dependencies>

            <build>
                <plugins>
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-compiler-plugin</artifactId>
                        <version>3.11.0</version>
                        <configuration>
                            <source>21</source>
                            <target>21</target>
                        </configuration>
                    </plugin>
                    <!-- intègre vos propres dépendances dans le jar -->
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-shade-plugin</artifactId>
                        <version>3.4.1</version>
                        <executions>
                            <execution>
                                <phase>package</phase>
                                <goals>
                                    <goal>shade</goal>
                                </goals>
                            </execution>
                        </executions>
                    </plugin>
                </plugins>
            </build>
        </project>
        ```
      </Tab>
      <Tab value="Gradle">
        ```kotlin title="settings.gradle.kts"
        rootProject.name = "MyPlugin"
        ```

        ```kotlin title="build.gradle.kts"
        plugins {
            java
            id("com.github.johnrengelman.shadow") version "8.1.1"
        }

        group = "org.example"
        version = "1.0.0-SNAPSHOT"

        repositories {
            mavenCentral()
            maven { url = uri("https://repo.powernukkitx.org/releases") }
        }

        dependencies {
            // "3.0.0-SNAPSHOT" est la version actuelle ; "nightly-SNAPSHOT" le dernier
            // build de développement, qui peut casser l'API.
            compileOnly("org.powernukkitx:server:3.0.0-SNAPSHOT")
        }

        tasks.withType<JavaCompile> {
            options.encoding = "UTF-8"
            sourceCompatibility = "21"
            targetCompatibility = "21"
        }

        tasks {
            build { dependsOn(shadowJar) }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Décrire le plugin

    Le serveur lit un fichier de métadonnées nommé `plugin.yml` (ou `powernukkitx.yml`) dans `src/main/resources` :

    ```yaml title="plugin.yml"
    name: ExamplePlugin
    main: org.example.ExamplePlugin
    # version et api doivent être des chaînes : gardez les guillemets
    version: "1.0.0"
    api: "2.0.0"
    load: POSTWORLD
    author: PowerNukkitX Team
    # author et authors sont fusionnés en une seule liste
    authors: ["Example", "Another"]
    description: Example plugin from the PNX documentation
    website: https://docs.powernukkitx.org/
    ```

    <Callout type="info">
      Avec le [processeur d'annotations](/docs/fr/development/basics/annotations), ce fichier est généré pour vous.
    </Callout>
  </Step>
  <Step>
    ### Écrire la classe principale

    La classe principale étend `PluginBase`. Le serveur appelle ses trois méthodes à chaque étape de la vie du plugin :

    ```java title="ExamplePlugin.java"
    package org.example;

    import org.powernukkitx.plugin.PluginBase;
    import org.powernukkitx.utils.TextFormat;

    public class ExamplePlugin extends PluginBase {
        @Override
        public void onLoad() {
            this.getLogger().info(TextFormat.WHITE + "Example plugin loaded!");
        }

        @Override
        public void onEnable() {
            this.getLogger().info(TextFormat.DARK_GREEN + "Example plugin enabled!");
        }

        @Override
        public void onDisable() {
            this.getLogger().info(TextFormat.DARK_RED + "Example plugin disabled!");
        }
    }
    ```

    <PluginLifecycle />
  </Step>
  <Step>
    ### Compiler et installer

    <Tabs items={["Maven", "Gradle"]}>
      <Tab value="Maven">
        ```bash
        mvn clean package
        ```

        Le jar se trouve dans `target/`.
      </Tab>
      <Tab value="Gradle">
        ```bash
        ./gradlew clean build
        ```

        Le jar, avec les bibliothèques intégrées, est `build/libs/MyPlugin-1.0.0-SNAPSHOT-all.jar`.
      </Tab>
    </Tabs>

    Copiez le jar dans le dossier `plugins/` de votre serveur et redémarrez-le. Vos messages apparaissent dans la console.
  </Step>
</Steps>
