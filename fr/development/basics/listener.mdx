Un **listener** est une classe dont les méthodes portent `@EventHandler`. Quand le serveur déclenche un événement de ce type, votre méthode s'exécute.

<EventFlow />

<Tabs items={["Une classe listener", "Dans la classe principale"]}>
  <Tab value="Une classe listener">
    La façon propre dès que le plugin grossit :

    ```java title="JoinListener.java"
    package com.example.listener;

    import org.powernukkitx.Player;
    import org.powernukkitx.event.EventHandler;
    import org.powernukkitx.event.Listener;
    import org.powernukkitx.event.player.PlayerJoinEvent;

    public class JoinListener implements Listener {
        @EventHandler
        public void onJoin(PlayerJoinEvent event) {
            Player player = event.getPlayer();
            player.sendMessage("Bienvenue, " + player.getName() + " !");
        }
    }
    ```

    Enregistrez-la à l'activation du plugin :

    ```java
    @Override
    public void onEnable() {
        this.getServer().getPluginManager().registerEvents(new JoinListener(), this);
    }
    ```

    <Callout type="info">
      Ou ajoutez `@EventListener` à la classe et laissez le [processeur d'annotations](/docs/fr/development/basics/annotations) l'enregistrer.
    </Callout>
  </Tab>
  <Tab value="Dans la classe principale">
    Suffisant pour un petit plugin : la classe principale est son propre listener.

    ```java title="ExamplePlugin.java"
    public class ExamplePlugin extends PluginBase implements Listener {
        @Override
        public void onEnable() {
            this.getServer().getPluginManager().registerEvents(this, this);
        }

        @EventHandler
        public void onJoin(PlayerJoinEvent event) {
            Player player = event.getPlayer();
            player.sendMessage("Bienvenue, " + player.getName() + " !");
        }
    }
    ```
  </Tab>
</Tabs>
