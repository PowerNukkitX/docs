  DDUI est une fonctionnalité expérimentale de Minecraft. Elle peut changer, casser ou disparaître dans une future mise à jour de Bedrock.
</Callout>

Un formulaire classique doit être fermé puis renvoyé pour afficher de nouvelles valeurs. Un écran **DDUI** reste ouvert et se met à jour sur place : ses champs sont liés à des valeurs côté serveur, et un changement d'un côté arrive de l'autre.

<DduiLoop />

## Les éléments

| Élément | Rôle |
| :-- | :-- |
| `DataDrivenScreen` | La classe de base d'un écran côté client. |
| `Observable<T>` | Une valeur (`String`, `Long`, `Boolean`) à laquelle l'écran est lié. `setValue()` envoie le changement au client, qui se met à jour sans recharger. |
| `subscribe(...)` | Exécute votre code quand le joueur change la valeur : saisie, glissement... Validez la saisie ou calculez d'autres valeurs ici. |

## Exemple

Adapté de la commande `/debug ddui` de PowerNukkitX. Le nom est coupé à 10 caractères pendant la saisie, la tranche d'âge suit le curseur d'âge, et un bouton remet tout à zéro :

```java filename="DDUIExample.java"
package org.example.ui;

import org.powernukkitx.Player;
import org.powernukkitx.Server;
import org.powernukkitx.ddui.CustomForm;
import org.powernukkitx.ddui.Observable;
import org.powernukkitx.ddui.element.options.SliderElementOptions;
import org.powernukkitx.ddui.element.options.TextFieldOptions;
import org.powernukkitx.plugin.InternalPlugin;

import java.util.concurrent.CompletableFuture;

public class DDUIExample {

    public static void showExample(Player player, Server server) {
        // 1. Define reactive observables
        Observable<String> name = new Observable<>("");
        Observable<String> bio = new Observable<>("");
        Observable<Long> age = new Observable<>(18L);
        Observable<String> ageGroup = new Observable<>("Adult");
        Observable<Long> difficulty = new Observable<>(3L);

        // 2. Construire les éléments du formulaire et les lier aux observables
        CustomForm form = new CustomForm("My Interactive Form")
                .label("Personal Information")
                .textField("Name", name, TextFieldOptions.builder()
                        .description("Max 10 characters")
                        .build())
                .textField("Biography", bio, TextFieldOptions.builder()
                        .description("This is your biography. Write anything you want here.")
                        .build())
                .slider("Age", 1L, 100L, age)
                .textField("Age Group", ageGroup, TextFieldOptions.builder()
                        .description("Automatically set based on age")
                        .disabled(true) // En lecture seule côté client
                        .build())
                .slider("Difficulty", 1L, 5L, difficulty, SliderElementOptions.builder()
                        .description("1 = Peaceful - 5 = Hardcore")
                        .build())
                
                // Ajouter un bouton de réinitialisation qui change toutes les valeurs de façon asynchrone
                .button("Reset", clickedPlayer -> CompletableFuture.runAsync(() -> {
                    name.setValue("");
                    bio.setValue("");
                    age.setValue(18L);
                    difficulty.setValue(3L);
                }))
                
                // Ajouter un bouton de confirmation
                .button("Confirm", clickedPlayer -> {
                    clickedPlayer.sendMessage("Confirmed successfully!");
                    clickedPlayer.sendMessage("Name: " + name.getValue());
                    clickedPlayer.sendMessage("Biography: " + bio.getValue());
                    clickedPlayer.sendMessage("Age: " + age.getValue() + " (" + ageGroup.getValue() + ")");
                    clickedPlayer.sendMessage("Difficulty: " + difficulty.getValue());

                    // Fermer l'écran pour le joueur
                    form.close(clickedPlayer);
                })
                .closeButton();

        // 3. Set up reactive validation listeners
        
        // Tronquer le nom saisi à 10 caractères maximum, en réaction à la saisie
        name.subscribe(value -> {
            String normalized = value.length() > 10 ? value.substring(0, 10) : value;
            server.getScheduler().scheduleTask(InternalPlugin.INSTANCE, () -> {
                if (!normalized.equals(value)) {
                    name.setValue(normalized);
                }
            });
            return null;
        });

        // Calculer et mettre à jour le champ en lecture seule 'Age Group' selon le curseur d'âge
        age.subscribe(value -> {
            CompletableFuture.runAsync(() -> {
                if (value <= 12) {
                    ageGroup.setValue("Kid");
                } else if (value <= 17) {
                    ageGroup.setValue("Teen");
                } else if (value <= 64) {
                    ageGroup.setValue("Adult");
                } else {
                    ageGroup.setValue("Senior");
                }
            });
            return null;
        });

        // 4. Afficher l'écran au joueur
        form.show(player);
    }
}
```

## Ce qui se passe quand le joueur fait glisser un curseur

<Steps>
  <Step>Le client envoie la nouvelle valeur au serveur.</Step>
  <Step>Le serveur met à jour l'`Observable` correspondant.</Step>
  <Step>L'`Observable` exécute ses abonnés.</Step>
  <Step>Un abonné qui appelle `setValue()`, comme `ageGroup` dans l'abonnement de `age`, renvoie la nouvelle valeur, et l'écran se met à jour aussitôt.</Step>
</Steps>
