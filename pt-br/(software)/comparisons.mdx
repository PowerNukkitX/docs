O PowerNukkitX não é o único servidor Bedrock. Esta página o coloca ao lado do Nukkit e do Bedrock Dedicated Server (BDS) da Mojang, para ajudar você a escolher.

## Resumo

| | PowerNukkitX | Nukkit | BDS (oficial) |
| :-- | :-- | :-- | :-- |
| Desempenho | **Alto** | Médio | Alto |
| Sistema de plugins | **Sim, Java** | Sim, Java | Não |
| API | **Moderna** | Antiga | Nenhuma |
| Novas versões do Bedrock | **Rápido** | Lento | Oficial |
| Código aberto | **Sim** | Sim | Não |
| Comunidade | **Ativa** | Média | Oficial |
| Conteúdo personalizado | **Bom** | Médio | Baixo |

## Qual escolher

<Cards>
  <Card title="PowerNukkitX">
    Um servidor moderno que você quer estender com plugins e conteúdo personalizado, com uma comunidade ativa por trás.
  </Card>
  <Card title="Nukkit">
    Um servidor que depende de plugins antigos do Nukkit que não foram atualizados.
  </Card>
  <Card title="BDS">
    Uma experiência puramente vanilla, com as atualizações oficiais da Mojang e compatibilidade máxima com o cliente.
  </Card>
</Cards>

## Mudando para o PowerNukkitX

<Steps>
  <Step>
    **Verifique seus plugins.** Alguns plugins do Nukkit precisam ser adaptados à API do PowerNukkitX.
  </Step>
  <Step>
    **Traga seus mundos e configurações.** Copie seus mundos e passe suas configurações para o `pnx.yml`.
  </Step>
  <Step>
    **Revise as permissões.** Recrie seus grupos e nós de permissão.
  </Step>
</Steps>

Cada origem tem seu próprio guia: [do Nukkit](/docs/pt-br/migration/nukkit), [do BDS](/docs/pt-br/migration/bds), [do PocketMine-MP](/docs/pt-br/migration/pocketmine).
