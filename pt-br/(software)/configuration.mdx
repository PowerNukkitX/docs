O PowerNukkitX guarda todas as configurações em **um único arquivo**, o `pnx.yml`, na raiz da pasta do servidor.

<ConfigSections />

<Callout type="error" title="Pare o servidor antes de editar o pnx.yml">
  Um servidor em execução mantém a configuração na memória e a grava de volta no `pnx.yml` ao desligar, o que sobrescreve tudo o que você mudou nesse meio-tempo.
</Callout>

## Configurações básicas

`baseSettings`: como os jogadores chegam ao servidor e o que veem na lista de servidores.

| Chave | Padrão | Descrição |
| :-- | :-- | :-- |
| `ip` | `"0.0.0.0"` | O endereço em que o servidor escuta. 0.0.0.0 escuta em todas as interfaces. |
| `port` | `19132` | A porta UDP a que os clientes Bedrock se conectam. |
| `maxPlayers` | `20` | Quantos jogadores podem ficar online ao mesmo tempo. |
| `defaultLevelName` | `"world"` | O nome da pasta do mundo padrão. |
| `allowList` | `false` | Só os jogadores em white-list.txt podem entrar. |
| `allowListMessage` | `"Server is white-listed"` | A mensagem de expulsão para quem não está na lista branca. |
| `motd` | `"PowerNukkitX Server"` | A linha principal mostrada na lista de servidores. |
| `subMotd` | `"powernukkitx.org"` | A segunda linha mostrada na lista de servidores. |
| `xboxAuth` | `true` | Autenticação do Xbox Live. false é o modo offline. |
| `autosaveDelay` | `6000` | Ticks entre salvamentos automáticos do mundo. |

## Configurações de jogadores

`playerSettings`: o que é salvo sobre os jogadores e como eles são verificados.

| Chave | Padrão | Descrição |
| :-- | :-- | :-- |
| `savePlayerData` | `true` | Salva posição, inventário e status quando um jogador sai. |
| `forceSkinTrusted` | `false` | Confia em todas as skins, permitindo skins personalizadas e de terceiros. |
| `checkMovement` | `true` | Verificação de movimento no servidor contra cheats simples de voo e velocidade. |
| `spawnRadius` | `16` | A que distância do spawn do mundo os novos jogadores aparecem. |

## Configurações de jogo

`gameplaySettings`: as regras do jogo.

| Chave | Padrão | Descrição |
| :-- | :-- | :-- |
| `gamemode` | `0` | Modo de jogo padrão. 0 Sobrevivência, 1 Criativo, 2 Aventura, 3 Espectador. |
| `difficulty` | `1` | Dificuldade padrão. 0 Pacífico, 1 Fácil, 2 Normal, 3 Difícil. |
| `pvp` | `true` | Os jogadores podem lutar entre si. |
| `allowFlight` | `false` | Jogadores no modo sobrevivência podem voar. |
| `viewDistance` | `20` | A maior distância, em chunks, enviada aos jogadores. |
| `allowNether` | `true` | É permitido viajar para o Nether. |
| `allowTheEnd` | `true` | É permitido viajar para o End. |
| `spawnProtection` | `16` | Raio em volta do spawn que quem não é operador não pode alterar. |

## Configurações de desempenho

`performanceSettings`: como o servidor usa a sua máquina. Veja [Ajuste de desempenho](/docs/pt-br/administration/performance) para dicas.

| Chave | Padrão | Descrição |
| :-- | :-- | :-- |
| `asyncWorkers` | `4` | Threads em segundo plano para trabalho assíncrono, como a geração de chunks. |
| `registryCacheEnabled` | `true` | Guarda em cache as entradas do registro para resolver blocos e itens mais rápido. |

## Exemplo

```yaml title="pnx.yml"
baseSettings:
  port: 19132
  maxPlayers: 50
  motd: "My Server"
gameplaySettings:
  difficulty: 2
  viewDistance: 12
```
