A imagem oficial é [`powernukkitx/server`](https://hub.docker.com/r/powernukkitx/server) no Docker Hub.

## Iniciar um contêiner

<Tabs items={["Docker Compose", "docker run"]}>
  <Tab value="Docker Compose">
    Crie um `docker-compose.yml` em uma pasta de sua escolha:

    ```yaml title="docker-compose.yml"
    services:
      pnx-server:
        image: powernukkitx/server:latest
        container_name: pnx-server
        ports:
          - "19132:19132/udp"
        volumes:
          - ./data:/data
        restart: unless-stopped
    ```

    Depois inicie-o em segundo plano:

    ```bash
    docker compose up -d
    ```
  </Tab>
  <Tab value="docker run">
    ```bash
    docker run -d \
      --name pnx-server \
      -p 19132:19132/udp \
      -v /path/to/your/data:/data \
      powernukkitx/server
    ```

    <Callout type="warn">
      Troque `/path/to/your/data` por um caminho absoluto da sua máquina, ou os dados do servidor se perdem quando o contêiner for substituído.
    </Callout>
  </Tab>
</Tabs>

## Onde ficam os dados

O volume `/data` guarda tudo o que o servidor grava:

<Files>
  <Folder name="data" defaultOpen>
    <File name="pnx.yml" />
    <Folder name="worlds" />
    <Folder name="plugins" />
    <Folder name="resource_packs" />
    <Folder name="logs" />
  </Folder>
</Files>

Um segundo volume, opcional, `/home/minecraft`, guarda o cache JLine do console.

## Usar o console

O servidor roda em segundo plano. Para digitar comandos como `op` ou `stop`, conecte-se a ele:

```bash
docker attach pnx-server
```

Para sair sem parar o servidor, pressione **Ctrl + P** e depois **Ctrl + Q**.

## Opções da JVM

Por padrão, a imagem inicia o Java com:

- o coletor de lixo ZGC: `-XX:+UseZGC`, `-XX:+ZGenerational`, `-XX:+UseStringDeduplication`;
- as flags de reflexão `--add-opens`;
- `--skip-setup --accept-license --language eng`, que pulam o assistente.

Para mudá-las, por exemplo para dar 4 GB de heap ao servidor, passe o comando completo depois do nome da imagem:

```bash
docker run -d \
  --name pnx-server \
  -p 19132:19132/udp \
  -v /path/to/your/data:/data \
  powernukkitx/server \
  -Xmx4G -Xms1G \
  -cp /app/powernukkitx.jar:./libs/* \
  org.powernukkitx.PowerNukkitX \
  --skip-setup --accept-license --language eng
```
