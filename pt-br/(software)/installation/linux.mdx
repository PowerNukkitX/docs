No Linux, você instala o Java 21 pelos pacotes da sua distribuição, inicia o servidor por um script e depois o roda como serviço systemd para que ele inicie sozinho.

## Instalar o servidor

<Steps>
  <Step>
    ### Instalar o Java 21

    <Tabs items={["Ubuntu / Debian", "CentOS / RHEL / Rocky"]}>
      <Tab value="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y openjdk-21-jre-headless wget
        ```
      </Tab>
      <Tab value="CentOS / RHEL / Rocky">
        ```bash
        sudo dnf install -y java-21-openjdk-headless wget
        ```
      </Tab>
    </Tabs>

    Confira com `java -version`.
  </Step>
  <Step>
    ### Criar um usuário dedicado

    Rode o servidor com um usuário próprio sem privilégios, nunca como `root`:

    ```bash
    sudo useradd --system --user-group --home-dir /opt/pnx-server --create-home minecraft
    ```
  </Step>
  <Step>
    ### Baixar o servidor

    ```bash
    sudo -u minecraft -s
    cd /opt/pnx-server
    wget https://github.com/PowerNukkitX/PowerNukkitX/releases/download/snapshot/powernukkitx.jar
    ```
  </Step>
  <Step>
    ### Criar o script de inicialização

    ```bash title="start.sh"
    #!/bin/bash
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    ```

    ```bash
    chmod +x start.sh
    ```
  </Step>
  <Step>
    ### Rodar o assistente uma vez

    ```bash
    ./start.sh
    ```

    Aceite a licença (`y`), escolha um idioma (`bra`) e digite o MOTD e a porta. Quando o console mostrar `Startup finished`, digite `stop` e depois `exit` para voltar ao seu usuário.
  </Step>
</Steps>

## Rodar como serviço

Um serviço systemd inicia o servidor junto com a máquina e o reinicia se ele cair.

<Steps>
  <Step>
    ### Criar o serviço

    ```bash
    sudo nano /etc/systemd/system/pnx.service
    ```

    ```ini title="/etc/systemd/system/pnx.service"
    [Unit]
    Description=PowerNukkitX Minecraft Bedrock Server
    After=network.target

    [Service]
    User=minecraft
    Group=minecraft
    WorkingDirectory=/opt/pnx-server
    ExecStart=/bin/bash /opt/pnx-server/start.sh
    Restart=on-failure
    RestartSec=10

    [Install]
    WantedBy=multi-user.target
    ```
  </Step>
  <Step>
    ### Ativar e iniciar

    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable pnx.service
    sudo systemctl start pnx.service
    ```
  </Step>
</Steps>

## Comandos do dia a dia

| O quê | Comando |
| :-- | :-- |
| Status | `sudo systemctl status pnx.service` |
| Log ao vivo (Ctrl + C para sair) | `journalctl -u pnx.service -f` |
| Parar | `sudo systemctl stop pnx.service` |
| Reiniciar | `sudo systemctl restart pnx.service` |
