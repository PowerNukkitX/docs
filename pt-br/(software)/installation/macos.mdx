No macOS, você instala o Java 21 com o Homebrew e depois roda o jar do servidor por um script de inicialização. Macs Intel e Apple Silicon seguem os mesmos passos.

## Instalação

<Steps>
  <Step>
    ### Instalar o Java 21

    Instale o Java com o [Homebrew](https://brew.sh/). No Terminal:

    ```bash
    brew install openjdk@21
    sudo ln -sfn /opt/homebrew/opt/openjdk@21/OpenJDK.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
    ```

    Em um Mac Intel mais antigo, troque `/opt/homebrew` por `/usr/local`. Confira com `java -version`: deve aparecer a versão `21`.
  </Step>
  <Step>
    ### Criar uma pasta para o servidor

    ```bash
    mkdir ~/pnx-server
    cd ~/pnx-server
    ```
  </Step>
  <Step>
    ### Baixar o servidor

    Baixe o `powernukkitx.jar` mais recente nas [releases do GitHub](https://github.com/PowerNukkitX/PowerNukkitX/releases) para `~/pnx-server`.
  </Step>
  <Step>
    ### Criar o script de inicialização

    O PowerNukkitX precisa de flags de reflexão do Java para iniciar. Crie `start.sh`:

    ```bash title="start.sh"
    #!/bin/bash
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    ```

    Depois torne-o executável:

    ```bash
    chmod +x start.sh
    ```
  </Step>
  <Step>
    ### Iniciar o servidor

    ```bash
    ./start.sh
    ```

    Na primeira vez, o assistente pede para aceitar a licença (`y`), escolher um idioma (por exemplo `bra`) e digitar o nome do servidor (MOTD) e a porta. Digite `stop` para desligá-lo corretamente.
  </Step>
</Steps>

## Solução de problemas

<Accordions>
  <Accordion title="&quot;Não é possível verificar o desenvolvedor&quot; ou um aviso do Gatekeeper">
    O macOS pode bloquear o Java ou o inicializador. Abra **Ajustes do Sistema > Privacidade e Segurança**, role até a seção de segurança e clique em **Permitir Mesmo Assim** ao lado do item bloqueado.
  </Accordion>
</Accordions>
