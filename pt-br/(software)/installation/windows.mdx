No Windows 10 ou 11, você instala o Java 21, coloca o jar do servidor em uma pasta e o inicia por um script `start.bat`.

## Instalação

<Steps>
  <Step>
    ### Instalar o Java 21

    Baixe o instalador **MSI** para Windows do **Eclipse Temurin JDK 21** no [Adoptium](https://adoptium.net/temurin/releases/?version=21&os=windows) e execute-o. Durante a instalação, marque **Set JAVA_HOME variable** e **Associate .jar files**.

    Depois abra um novo Prompt de Comando e confira:

    ```bat
    java -version
    ```

    Deve aparecer a versão `21`, por exemplo `openjdk version "21.x.x"`.
  </Step>
  <Step>
    ### Criar uma pasta para o servidor

    Crie uma pasta para o servidor, por exemplo `C:\PNX-Server`.

    <Callout type="warn">
      Não a coloque em `C:\Program Files` nem em `C:\Windows`: o Windows pode impedir que o PowerNukkitX crie ali seus mundos, configurações e logs.
    </Callout>
  </Step>
  <Step>
    ### Baixar o servidor

    Baixe o `powernukkitx.jar` mais recente nas [releases do GitHub](https://github.com/PowerNukkitX/PowerNukkitX/releases) e coloque-o na sua pasta.
  </Step>
  <Step>
    ### Criar o script de inicialização

    O PowerNukkitX precisa de flags de reflexão do Java (`--add-opens`) para carregar o registro e os plugins, então inicie-o por um script em vez de dar dois cliques no jar. Crie `start.bat` na pasta:

    ```bat title="start.bat"
    @echo off
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    pause
    ```

    <Callout type="info">
      Crie-o como arquivo de texto e depois renomeie. Ative **Exibir > Mostrar > Extensões de nomes de arquivos** no Explorador de Arquivos para que o arquivo termine mesmo em `.bat`, e não em `.bat.txt`.
    </Callout>
  </Step>
  <Step>
    ### Iniciar o servidor

    Dê dois cliques em `start.bat`. Na primeira vez, um assistente pede para:

    - aceitar a licença digitando `y`;
    - escolher um idioma, por exemplo `bra`;
    - digitar o nome do servidor (MOTD) e a porta (padrão `19132`).

    Em seguida o servidor cria o `pnx.yml` e o mundo padrão. Digite `stop` para desligá-lo corretamente.
  </Step>
</Steps>

Sua pasta agora fica assim:

<Files>
  <Folder name="PNX-Server" defaultOpen>

    <File name="start.bat" />

  </Folder>

## Solução de problemas

<Accordions>
  <Accordion title="'java' não é reconhecido">
    O Windows não encontra o Java. Se o Java 21 estiver instalado:

    1. Procure no menu Iniciar por **Editar as variáveis de ambiente do sistema** e clique em **Variáveis de Ambiente...**.
    2. Em *Variáveis do sistema*, verifique se `JAVA_HOME` aponta para a pasta do JDK 21, por exemplo `C:\Program Files\Eclipse Adoptium\jdk-21.x.x\`.
    3. Edite `Path` e confira se contém `%JAVA_HOME%\bin`.
    4. Abra um novo Prompt de Comando ou reinicie o PC.
  </Accordion>
  <Accordion title="BindException: Address already in use">
    Outro programa, ou outra cópia do servidor, já usa a porta `19132`. Feche a outra janela do servidor ou mude `port` no `pnx.yml` (por exemplo para `19133`).
  </Accordion>
</Accordions>
