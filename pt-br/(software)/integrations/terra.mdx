O [Terra](https://terra.polydev.org/) é um gerador de terreno guiado por **pacotes de configuração**: cada pacote descreve seus próprios biomas e paisagens. O PowerNukkitX o suporta de fábrica.

<Steps>
  <Step>
    ### Ative o Terra

    Com o servidor **parado**, defina:

    ```yaml title="pnx.yml"
    miscSettings:
      enableTerra: true
    ```

    Inicie o servidor: ele cria uma pasta `terra/` na raiz.
  </Step>
  <Step>
    ### Adicione um pacote

    1. Escolha um pacote, por exemplo entre os [pacotes da comunidade](https://terra.polydev.org/config/community-packs.html).
    2. Coloque a pasta ou o ZIP dele em `terra/packs/`.
    3. Abra o `pack.yml` do pacote e anote o `id` dele, por exemplo `REIMAGEND`.
  </Step>
  <Step>
    ### Crie um mundo que o use

    Crie uma pasta para o novo mundo dentro de `worlds/`, por exemplo `worlds/end`, com um `config.json`:

    ```json title="worlds/end/config.json"
    {
      "format": "leveldb",
      "enable": true,
      "generators": {
        "2": {
          "name": "terra",
          "seed": 0,
          "enableAntiXray": false,
          "antiXrayMode": "LOW",
          "preDeobfuscate": true,
          "dimensionData": {
            "dimensionName": "minecraft:end",
            "dimensionId": 2,
            "minHeight": 0,
            "maxHeight": 255,
            "height": 256,
            "chunkSectionCount": 16
          },
          "preset": {
            "pack": "REIMAGEND"
          }
        }
      }
    }
    ```

    Troque `REIMAGEND` em `preset.pack` pelo id do seu pacote.
  </Step>
  <Step>
    ### Visite-o

    Inicie o servidor e teleporte-se para o novo mundo:

    ```bash
    /world tp end Dim2
    ```
  </Step>
</Steps>
