O PocketMine-MP é escrito em PHP e o PowerNukkitX em Java. Seus mundos podem vir junto; plugins e configuração, não.

## Passos

<Steps>
  <Step>
    ### Instale o PowerNukkitX

    Siga o [guia de instalação](/docs/pt-br/installation), inicie o servidor uma vez para ele criar seus arquivos e depois pare-o.
  </Step>
  <Step>
    ### Copie seus mundos

    Copie as pastas dos mundos de `worlds/` do PocketMine-MP para `worlds/` do PowerNukkitX e defina o principal como padrão:

    ```yaml title="pnx.yml"
    baseSettings:
      defaultLevelName: "MyWorld"
    ```
  </Step>
  <Step>
    ### Copie as configurações

    | Configuração do PocketMine-MP | Seção do `pnx.yml` | Chave do `pnx.yml` |
    | :-- | :-- | :-- |
    | `server-port` (`server.properties`) | `baseSettings` | `port` |
    | `max-players` (`server.properties`) | `baseSettings` | `maxPlayers` |
    | `xbox-auth` (`pocketmine.yml`) | `baseSettings` | `xboxAuth` |
    | `view-distance` (`server.properties`) | `gameplaySettings` | `viewDistance` |
    | `difficulty` (`server.properties`) | `gameplaySettings` | `difficulty` |
    | `gamemode` (`server.properties`) | `gameplaySettings` | `gamemode` |
    | `white-list` (`server.properties`) | `baseSettings` | `allowList` |
  </Step>
</Steps>

## O que não vem junto

<Accordions>
  <Accordion title="Plugins">
    Os plugins do PocketMine-MP são em PHP e **não rodam** no PowerNukkitX: não copie arquivos `.phar` nem código PHP para `plugins/`. Procure equivalentes em Java no [hub de plugins](https://powernukkitx.org/plugins) ou refaça os recursos com a [API de plugins](/docs/pt-br/development).
  </Accordion>
  <Accordion title="Permissões">
    O PocketMine-MP usa um `permissions.yml` em YAML. No PowerNukkitX, instale o **LuckPerms** para recriar seus grupos e nós. Veja [Permissões e segurança](/docs/pt-br/permissions).
  </Accordion>
</Accordions>
