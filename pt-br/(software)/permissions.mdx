As permissões decidem quais comandos e ações cada jogador pode usar. Há três níveis, do mais simples ao mais flexível.

## 1. Operadores

Um **operador** (OP) pula todas as verificações de permissão e pode rodar qualquer comando. Reserve isso para poucos administradores de confiança.

```bash title="Console"
op <player>
deop <player>
```

Os operadores ficam em `ops.txt`, na raiz do servidor, um nome por linha. Você pode editá-lo com o servidor **parado**.

## 2. Nós de permissão

Comandos e plugins verificam **nós de permissão**: nomes com pontos, como:

- `nukkit.command.help` para `/help`
- `nukkit.command.gamemode` para `/gamemode`

Por padrão, jogadores comuns podem usar comandos básicos (`/tell`, `/list`, `/help`) e operadores podem usar todos.

## 3. Um plugin de permissões

Para um servidor público ou com vários grupos, só o OP não basta. Instale um plugin de permissões como o **LuckPerms**, que foi portado para o Nukkit e o PowerNukkitX. Com ele você pode:

- criar grupos como `admin`, `moderator` e `player`;
- dar nós de permissão a um grupo ou a um único jogador;
- definir prefixos, sufixos e herança entre grupos.

<Callout type="info">
  Encontre plugins de permissões no [hub de plugins](https://powernukkitx.org/plugins).
</Callout>

## Checklist de segurança

<Steps>
  <Step>Mantenha a **autenticação Xbox** ligada (`xboxAuth: true` no `pnx.yml`) para que ninguém entre com o nome de outro jogador.</Step>
  <Step>Dê OP para o **menor número de pessoas** possível e use grupos para todo o resto.</Step>
  <Step>Ative a **lista branca** em um servidor privado. Veja [Gerenciamento de jogadores](/docs/pt-br/administration/players).</Step>
</Steps>
