Antes de instalar, confira se a sua máquina tem o hardware, a versão do Java e o sistema abaixo.

## Hardware

<Tabs items={["Mínimo", "Recomendado"]}>
  <Tab value="Mínimo">
    Suficiente para um servidor pequeno com poucos jogadores. O desempenho depende do tamanho do mundo e dos plugins.

    | Componente | Mínimo |
    | :-- | :-- |
    | CPU | 2 núcleos, 2,5 GHz |
    | RAM | 2 GB |
    | Armazenamento | 1 GB livre |
    | Java | OpenJDK 21 ou mais recente |
    | Sistema | Windows 10 / 11, Linux (Ubuntu 20.04+), macOS |
    | Rede | 1 Mbps de upload |
  </Tab>
  <Tab value="Recomendado">
    Para um servidor com movimento de verdade. Acima de 20 jogadores ou com vários mundos, aumente CPU, RAM e banda.

    | Componente | Recomendado |
    | :-- | :-- |
    | CPU | 4+ núcleos, 3,0 GHz+ |
    | RAM | 4 GB ou mais |
    | Armazenamento | SSD com 5 GB livres |
    | Java | OpenJDK 21 ou mais recente |
    | Sistema | Windows 10 / 11, Linux (Ubuntu 22.04+), macOS |
    | Rede | 10 Mbps+ de upload |
  </Tab>
</Tabs>

## Java

O PowerNukkitX precisa do **Java 21 ou mais recente**, 64 bits.

<Steps>
  <Step>Instale um Java 21 de **64 bits**. O OpenJDK é o recomendado.</Step>
  <Step>Defina a variável de ambiente `JAVA_HOME` apontando para essa instalação.</Step>
  <Step>Coloque a pasta `bin` do Java no seu `PATH` e confira com `java -version`.</Step>
</Steps>

<Callout type="warn">
  Versões antigas do Java (20 ou anteriores) causam travamentos ou erros de plugins. Veja [Solução de problemas](/docs/pt-br/faq/troubleshooting) se `java -version` mostrar a versão errada.
</Callout>

## Bons hábitos

- **Faça backup** da pasta `worlds/` e do `pnx.yml` com frequência. Veja [Backups](/docs/pt-br/administration/backups).
- **Deixe 20% do disco livre** para logs e mundos que crescem.
- **Instale só plugins** feitos para a sua versão do PowerNukkitX.
- **Acompanhe CPU e memória** com o `htop` no Linux ou o Gerenciador de Tarefas no Windows.
