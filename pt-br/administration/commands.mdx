O PowerNukkitX tem todos os comandos vanilla do Bedrock, mais os comandos do servidor. No **console**, digite os comandos sem barra; **no jogo**, como operador, com barra.

<Tabs items={["Servidor", "Jogadores", "Mundo"]}>
  <Tab value="Servidor">
    | Comando | O que faz |
    | :-- | :-- |
    | `stop` | Salva tudo e desliga corretamente. Use sempre em vez de matar o processo. |
    | `save-all` | Grava agora no disco todos os mundos carregados. |
    | `reload` | Recarrega plugins e configuração. Reiniciar por completo é mais seguro. |
    | `version` / `plugins` | A versão do servidor e os plugins carregados. |
    | `status` | Tempo ligado, TPS, memória, e mundos e entidades carregados. |
  </Tab>
  <Tab value="Jogadores">
    | Comando | O que faz |
    | :-- | :-- |
    | `list` | Lista os jogadores online. |
    | `kick <player> [reason]` | Desconecta um jogador. |
    | `tp <player> <target>` | Teleporta um jogador até outro jogador ou até coordenadas. |
    | `gamemode <mode> [player]` | Define o modo de jogo: `survival`, `creative`, `adventure`, `spectator`. |
    | `give <player> <item> [amount]` | Dá itens. |
    | `xp <amount> [player]` | Dá experiência. |

    Operadores, banimentos e lista branca ficam em [Jogadores](/docs/pt-br/administration/players).
  </Tab>
  <Tab value="Mundo">
    | Comando | O que faz |
    | :-- | :-- |
    | `time set <value>` | Define a hora: `day`, `night` ou um número de ticks. |
    | `weather <clear\|rain\|thunder>` | Muda o clima. |
    | `difficulty <0-3>` | Pacífico, fácil, normal ou difícil. |
    | `gamerule <rule> <value>` | Muda uma regra de jogo como `doDaylightCycle` ou `keepInventory`. |
    | `setworldspawn` / `spawnpoint` | Define o spawn do mundo ou o ponto de spawn de um jogador. |
  </Tab>
</Tabs>

<Callout type="error" title="Nunca mate o processo">
  Fechar o terminal ou matar o Java pode perder dados do mundo e dos jogadores. Use `stop` para que tudo seja gravado no disco antes.
</Callout>

## Ajuda

`help` lista, página por página, todos os comandos que você pode rodar; `help <command>` mostra como usar um deles. O que um jogador pode rodar depende das [permissões](/docs/pt-br/permissions) dele.
