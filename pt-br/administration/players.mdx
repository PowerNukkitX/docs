Quem pode fazer o quê no seu servidor: operadores, lista branca, expulsões e banimentos, e o que muda no modo offline.

## Operadores

Operadores pulam as verificações de permissão e podem rodar qualquer comando.

```bash title="Console"
op <player>
deop <player>
```

Eles ficam em `ops.txt`, um nome por linha, que você pode editar com o servidor parado. Além de alguns administradores de confiança, use um plugin de permissões: veja [Permissões e segurança](/docs/pt-br/permissions).

## Lista branca

Deixe entrar só os jogadores aprovados. Ative-a no `pnx.yml`:

```yaml title="pnx.yml"
baseSettings:
  allowList: true
  allowListMessage: Server is white-listed
```

Assim só os jogadores em `white-list.txt` podem entrar; os demais são expulsos com `allowListMessage`. Gerencie-a com:

```bash title="Console"
whitelist add <player>
whitelist remove <player>
whitelist list
```

<Callout type="info">
  Com `xboxAuth` ligado (o padrão), os jogadores são identificados pela conta Xbox, então trocar o nome de exibição não burla a lista branca.
</Callout>

## Expulsões e banimentos

| Comando | Efeito |
| :-- | :-- |
| `kick <player> [reason]` | Desconecta um jogador na hora. Ele pode voltar. |
| `ban <player> [reason]` | Bane um jogador pelo nome. |
| `pardon <player>` | Remove um banimento por nome. |
| `ban-ip <address\|player>` | Bane um endereço IP. |
| `pardon-ip <address>` | Remove um banimento de IP. |

Os banimentos ficam em `banned-players.txt` e `banned-ips.txt`.

## Modo offline

Definir `baseSettings.xboxAuth` como `false` desliga a autenticação Xbox.

<Callout type="error" title="Só em redes confiáveis">
  Sem autenticação, qualquer um entra com qualquer nome, e a lista branca e os banimentos ficam fáceis de burlar. Use o modo offline só em rede local, ou atrás de um proxy que autentique os jogadores (veja [WaterdogPE](/docs/pt-br/integrations/wdpe)).
</Callout>
