O **PowerNukkitX Assistant** é um aplicativo de desktop para Windows, Linux e macOS. Ele cria um servidor, inicia, mostra o console, instala plugins e edita as configurações, tudo sem terminal. Ele é feito para um primeiro servidor e continua útil quando você roda vários.

<AssistantWindow />

Por baixo, ele usa a [PNX CLI](/docs/pt-br/cli): o aplicativo traz a CLI compilada e chama exatamente as mesmas funções do `pnx`, então a janela e o terminal nunca discordam sobre como um servidor é criado ou iniciado.

## Instalar

Baixe o instalador do seu sistema nas [releases do pnx-cli](https://github.com/PowerNukkitX/pnx-cli/releases):

| Sistema | Arquivo |
| :-- | :-- |
| Windows | O instalador (`.exe` de instalação), ou o `.exe` portátil que roda sem instalar. |
| Linux | O `.AppImage`: torne-o executável e abra. |
| macOS | O `.dmg`: abra e arraste o app para Aplicativos. |

O servidor continua precisando do **Java 21** ou mais recente. O Assistant verifica isso na primeira abertura e avisa se estiver faltando.

## Primeira abertura

Uma breve boas-vindas passa por três telas:

<Steps>
  <Step>**Boas-vindas**: o que o Assistant faz.</Step>
  <Step>**Java**: ele procura o Java 21+ e diz o que encontrou.</Step>
  <Step>**Seu primeiro servidor**: crie um com um clique, conecte uma pasta de servidor que você já tem, ou pule por enquanto.</Step>
</Steps>

Quer ver de novo? **Configurações > Rever a introdução**.

## O tutorial guiado

**Tutorial guiado**, na barra lateral, tem sete passos para um primeiro servidor, cada um com um botão que faz o trabalho: o que é o PowerNukkitX, verificar o Java, criar o servidor, a primeira inicialização, entrar pelo Minecraft, adicionar plugins e convidar amigos de fora da sua rede.

## Atalhos de teclado

| Teclas | Ação |
| :-- | :-- |
| `Ctrl` + `K` | A paleta de comandos: ir a qualquer lugar, iniciar ou parar o servidor, fazer um backup. |
| `Ctrl` + `1` … `7` | Alternar entre as visões da barra lateral. |
| `Esc` | Fechar a paleta ou um diálogo. |
