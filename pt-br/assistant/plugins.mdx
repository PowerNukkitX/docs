A visão **Plugins** busca no [hub de plugins](https://powernukkitx.org/plugins) e instala direto na pasta `plugins/` do servidor ativo.

## Loja

Digite no campo de busca para encontrar um plugin. **Instalar** baixa a última versão **aprovada** do GitHub e a confere com o SHA-256 registrado pelo hub antes de gravá-la em `plugins/`. Reinicie o servidor para carregá-la.

## Instalados

A aba **Instalados** lista o que o Assistant instalou:

- **Atualizar** aparece quando existe uma versão aprovada mais nova;
- **Remover** apaga o plugin de `plugins/`;
- **atualizado** significa que não há nada mais novo.

<Callout type="info">
  O Assistant usa os mesmos endpoints do hub que o `pnx plugin`. Para apontar os dois para outro hub, defina `PNX_API_URL`: veja [a CLI](/docs/pt-br/cli#state).
</Callout>
