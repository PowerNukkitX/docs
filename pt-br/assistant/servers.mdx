## Criar um servidor

**Criar um servidor** é um assistente de quatro passos:

<Steps>
  <Step>**Pasta**: onde o servidor fica. Uma pasta vazia, criada se não existir.</Step>
  <Step>**Versão**: a versão do PowerNukkitX. A última estável vem pré-selecionada.</Step>
  <Step>**Memória**: a RAM dada na inicialização. 2 GB cobrem com folga uns dez jogadores.</Step>
  <Step>**Construir**: o jar oficial é baixado com uma barra de progresso ao vivo, os scripts de inicialização são escritos e o servidor é registrado.</Step>
</Steps>

No fim, **Rodar agora** o inicia e **Abrir pasta** mostra os arquivos.

## Vários servidores

O Assistant mantém uma lista de servidores, mostrados como chips no topo de **Meu servidor**:

- clique em um chip para torná-lo o servidor **ativo**: iniciar, parar, plugins e configurações agem nele;
- o lápis renomeia, a lixeira tira da lista. Os arquivos ficam no disco;
- **Adicionar um servidor** conecta uma pasta que você já tem. Ela precisa conter um `powernukkitx.jar`.

O servidor padrão da CLI entra na lista sozinho na primeira vez.

## Iniciar, parar e o console

**Meu servidor** inicia e para o servidor ativo e mostra o console ao vivo, com as cores do servidor.

| No console | Faz |
| :-- | :-- |
| O campo de comando | Envia um comando ao servidor, como você digitaria no terminal dele. **Enter** executa. |
| Tudo / Avisos / Erros | Filtra as linhas. |
| Limpar, Copiar, Exportar | Esvazia a visualização, copia ou salva os logs em um arquivo. |
| Rolagem automática | Mantém a linha mais recente à vista. |

**Parar** envia ao servidor um `stop` correto, para ele salvar antes de sair. Com **Confirmar ao fechar** ligado, fechar o app com o servidor rodando oferece pará-lo antes.

## Sinais vitais

Ao lado do console, números ao vivo do servidor em execução: tempo ligado, jogadores online, a porta e quantos erros e avisos ele registrou.

## Backups

**Backups**, em **Meu servidor**, tira um instantâneo do servidor (mundos e configuração) na pasta `backups/` dele.

| Ação | Observação |
| :-- | :-- |
| Novo backup | Salva uma cópia agora. |
| Restaurar | Substitui os arquivos do servidor por essa cópia, depois de uma confirmação. O servidor precisa estar parado. As mudanças feitas desde então se perdem. |
| Apagar | Remove a cópia de vez. |

<Callout type="info">
  Os backups ficam ao lado do servidor. Para sobreviver a um disco morto, copie-os também para outra máquina: veja [Backups](/docs/pt-br/administration/backups).
</Callout>
