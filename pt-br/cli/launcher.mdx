O `pnxcli` faz uma única coisa: criar um servidor, do começo ao fim. Ele pergunta onde, qual versão e se deve iniciá-lo, e cuida do resto. É o jeito mais rápido de começar para quem não vive no terminal.

```bash
pnxcli
```

Ele segue os mesmos passos do [`pnx init`](/docs/pt-br/cli/server#init): a pasta, a versão do PowerNukkitX (a última estável vem pré-selecionada), o download do jar e dos scripts de inicialização. O novo servidor vira o padrão de todos os comandos `pnx`.

## Opções

Para pular uma pergunta, responda antes:

| Opção | Efeito |
| :-- | :-- |
| `--dir <caminho>` | Cria o servidor nessa pasta. |
| `--version <tag>` | Fixa uma versão exata do PowerNukkitX. |
| `--start` | Inicia o servidor assim que ele estiver pronto. |
| `--no-color` | Texto puro, para pipes. |

```bash
pnxcli --dir ./survival --start
```

<Callout type="info">
  Prefere uma janela a um terminal? O [Assistant](/docs/pt-br/assistant) faz o mesmo, com um assistente de criação e uma barra de download ao vivo.
</Callout>
