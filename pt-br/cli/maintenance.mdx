## update [#update]

Atualiza o próprio PowerNukkitX para a última versão. Alias: `upgrade`.

```bash
pnx update
pnx update --force
```

O jar atual é mantido ao lado do novo como `powernukkitx.jar.old`, para você poder voltar. Apague-o quando a nova versão rodar como você quer. `--force` ignora o cache de versões e consulta o GitHub de novo.

## backup [#backup]

Copia o servidor para `backups/pnx-backup-<data>/`, dentro da pasta do servidor.

```bash
pnx backup
```

Tudo é copiado, exceto `logs/`, `cache/`, `crash-reports/`, `backups/` anteriores e pastas ocultas. Para uma cópia limpa dos mundos, rode antes `save-all` no console ou pare o servidor. Para que os backups sobrevivam a um disco morto, copie-os para outra máquina: veja [Backups](/docs/pt-br/administration/backups).

## doctor [#doctor]

Verifica o que um servidor precisa e diz o que o bloqueia. Alias: `check`.

```bash
pnx doctor
pnx --json doctor
```

| Verificação | Olha |
| :-- | :-- |
| Java | Se o Java 21 ou mais recente está instalado, e o fornecedor. |
| Instalação | Se a pasta do servidor tem um `powernukkitx.jar` funcionando. |
| Disco | O espaço livre onde o servidor fica. |
| Porta 19132 | Se algo já ocupa a porta UDP padrão. |
| Memória | A memória livre e total. |

## info [#info]

Mostra o que está instalado aqui: a pasta do servidor, a versão do PowerNukkitX e os plugins. Alias: `status`.

```bash
pnx info
pnx --json info
```
