## init [#init]

Cria um servidor: uma pasta, o jar do PowerNukkitX e os scripts de inicialização. Aliases: `new`, `create`.

```bash
pnx init
pnx init --dir my-server
pnx init --version 1.21.0
```

| Opção | Efeito |
| :-- | :-- |
| `--dir <caminho>` | A pasta onde criar o servidor. |
| `--version <tag>` | Uma tag de versão do PowerNukkitX, que pula a escolha de versão. |

No terminal ele pergunta o que falta; em um script (ou com `--json`), roda sem perguntas. O jar vem das releases do PowerNukkitX no GitHub e os scripts de [PowerNukkitX/scripts](https://github.com/PowerNukkitX/scripts). O novo servidor vira o padrão.

## start [#start]

Inicia o servidor em primeiro plano, com as flags do Java de que o PowerNukkitX precisa. Aliases: `run`, `up`.

```bash
pnx start
pnx start --memory 4G
pnx start --restart
pnx start --dry-run
```

| Opção | Efeito |
| :-- | :-- |
| `--dir <caminho>` | A pasta do servidor, em vez do servidor padrão. |
| `-m`, `--memory <tamanho>` | Heap do Java na inicialização, `2G` por padrão. |
| `--restart` | Reinicia o servidor quando ele termina com erro. |
| `--dry-run` | Mostra o comando `java` em vez de executá-lo. |

O `pnx start` inicia o Java com UTF-8 em tudo, o coletor de lixo ZGC, as flags `--add-opens` e `-XX:MaxRAMPercentage=75.0`, para que o heap possa crescer até três quartos da memória da máquina. Ele usa o Java de `JAVA_HOME` quando definido.

## stop [#stop]

Para o servidor que o `pnx start` iniciou, pelo id de processo que ele guardou. Alias: `down`.

```bash
pnx stop
```

<Callout type="info">
  Para parar com segurança por dentro, digite `stop` no console do servidor: tudo é salvo antes.
</Callout>

## console [#console]

Abre um console para um servidor em execução, via **RCON**.

```bash
pnx console
```

Ele lê `enable-rcon`, `rcon.port` (`25575` por padrão) e `rcon.password` do `server.properties` do servidor. O RCON vem desligado; nesse caso, o `pnx console` diz o que ligar. Digite `exit` para sair.

## logs [#logs]

Mostra o log do servidor e continua acompanhando. Alias: `log`.

```bash
pnx logs
pnx logs --lines 200
pnx logs --no-follow
```

| Opção | Efeito |
| :-- | :-- |
| `-n`, `--lines <n>` | Quantas linhas mostrar primeiro. |
| `--follow` | Continua mostrando as linhas novas conforme são escritas. `--no-follow` mostra e sai. |

## config [#config]

Mostra a configuração que o servidor lê, para conferir um valor sem abrir o arquivo.

```bash
pnx config
```

## use [#use]

Escolhe o servidor em que todos os comandos trabalham.

```bash
pnx use
pnx use ./my-server
pnx use --clear
```

Sem pasta, ele lista os servidores que encontra e deixa você escolher. `--clear` esquece o padrão de novo.
