O **PNX-APT** é um processador de anotações que roda na compilação. Anote suas classes e, ao compilar, ele:

<Steps>
  <Step>gera o descritor `powernukkitx.yml` dentro do seu jar;</Step>
  <Step>gera uma classe `PNXPluginBootstrap` que registra seus comandos, listeners e tarefas;</Step>
  <Step>roda esse bootstrap quando o plugin é ativado.</Step>
</Steps>

Nada de `plugin.yml` para escrever, nem chamadas a `registerEvents` para lembrar.

## Metadados do plugin: `@PluginMeta`

Coloque-a na sua **única** classe principal, a que estende `PluginBase`:

```java title="MyPlugin.java"
package org.example;

import org.powernukkitx.plugin.PluginBase;
import org.powernukkitx.plugin.PluginLoadOrder;
import org.powernukkitx.plugin.annotation.PluginMeta;

@PluginMeta(
    name = "MyPlugin",
    version = "1.0.0",
    api = {"3.0.0-SNAPSHOT"},
    authors = {"AuthorName"},
    description = "An automated plugin using annotations!",
    website = "https://example.com",
    order = PluginLoadOrder.POSTWORLD
)
public class MyPlugin extends PluginBase {
    // no plugin.yml or powernukkitx.yml to write
}
```

| Parâmetro | Tipo | |
| :-- | :-- | :-- |
| `name` | `String` | O nome do plugin. |
| `version` | `String` | A versão dele. |
| `api` | `String[]` | Versões compatíveis da API do PowerNukkitX, por exemplo `{"3.0.0-SNAPSHOT"}`. |
| `authors` | `String[]` | Opcional. Autores. |
| `description` | `String` | Opcional. Uma descrição. |
| `website` | `String` | Opcional. Um site. |
| `prefix` | `String` | Opcional. Um prefixo próprio para o logger. |
| `depend` | `String[]` | Opcional. Plugins que precisam carregar antes. |
| `softDepend` | `String[]` | Opcional. Plugins que carregam antes, se existirem. |
| `loadBefore` | `String[]` | Opcional. Plugins que carregam depois deste. |
| `order` | `PluginLoadOrder` | Opcional. `POSTWORLD` (padrão) ou `STARTUP`. |

## Listeners: `@EventListener`

Em vez de chamar `registerEvents(...)` em `onEnable()`:

```java title="MyListener.java"
package org.example;

import org.powernukkitx.event.EventHandler;
import org.powernukkitx.event.Listener;
import org.powernukkitx.event.player.PlayerJoinEvent;
import org.powernukkitx.plugin.annotation.EventListener;

@EventListener
public class MyListener implements Listener {
    @EventHandler
    public void onJoin(PlayerJoinEvent event) {
        event.getPlayer().sendMessage("Welcome to the server!");
    }
}
```

## Tarefas: `@ScheduleTask`

Em uma classe `Runnable` (ou `Task`), ou em um método `public static`:

| Opção | Padrão | |
| :-- | :-- | :-- |
| `delay` | `0` | Ticks antes da primeira execução. |
| `period` | `0` | Ticks entre execuções. `0` roda uma vez. |
| `async` | `false` | Rodar fora da thread principal. |

<Tabs items={["Em uma classe", "Em um método"]}>
  <Tab value="Em uma classe">
    ```java title="MyTask.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    @ScheduleTask(delay = 100, period = 200, async = false)
    public class MyTask implements Runnable {
        @Override
        public void run() {
            System.out.println("Runs every 10 seconds!");
        }
    }
    ```
  </Tab>
  <Tab value="Em um método">
    ```java title="StaticTasks.java"
    import org.powernukkitx.plugin.annotation.ScheduleTask;

    public class StaticTasks {
        @ScheduleTask(delay = 20, async = true)
        public static void runOnceAsync() {
            System.out.println("Runs once, asynchronously, after 1 second!");
        }
    }
    ```
  </Tab>
</Tabs>

## Comandos: `@CommandDefinition`

Registra o comando no mapa de comandos do servidor. `commandMode` escolhe como os argumentos são roteados:

```java title="MyCommand.java"
import org.powernukkitx.command.Command;
import org.powernukkitx.plugin.annotation.CommandDefinition;
import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

@CommandDefinition(
    name = "mycommand",
    description = "An annotation-registered command",
    usage = "/mycommand",
    aliases = {"mycmd"},
    permission = "myplugin.command.use",
    commandMode = CommandMode.COMMAND_TREE
)
public class MyCommand extends Command {
    // COMMAND_TREE: override buildCommandTree(RouteTree tree)
    // RAW: override execute(CommandSender sender, String label, String[] args)
}
```

| Modo | |
| :-- | :-- |
| `COMMAND_TREE` (padrão) | A árvore de rotas fluente: sobrescreva `buildCommandTree(RouteTree tree)`. Veja [Comandos](/docs/pt-br/development/basics/commands). |
| `PARAM_TREE` | A API de parâmetros de subcomandos. |
| `RAW` | Sem roteamento automático: interprete os argumentos você mesmo em `execute`. |
