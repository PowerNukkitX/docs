Há três formas de adicionar um comando. Escolha a mais simples que resolva.

| Forma | Bom para |
| :-- | :-- |
| `onCommand` na classe principal | Um ou dois comandos rápidos. |
| Uma classe `Command` | Comandos limpos e separados, com permissões. |
| Uma árvore de comandos | Subcomandos e argumentos tipados, com verificações automáticas e autocompletar. |

## 1. `onCommand`

Sobrescreva `onCommand` na sua `PluginBase` e declare o comando no `plugin.yml`:

```java title="ExamplePlugin.java"
public class ExamplePlugin extends PluginBase {
    @Override
    public boolean onCommand(CommandSender sender, Command command, String label, String[] args) {
        if (command.getName().equalsIgnoreCase("greet")) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
        return false;
    }
}
```

```yaml title="plugin.yml"
name: ExamplePlugin
main: com.example.ExamplePlugin
version: 1.0.0
commands:
  greet:
    description: Greet a player
    usage: /greet [name]
    permission: greet.permission
```

## 2. Uma classe `Command`

Estenda `org.powernukkitx.command.Command` (ou `PluginCommand`). Registre-a com uma anotação ou à mão:

<Tabs items={["Com @CommandDefinition", "À mão"]}>
  <Tab value="Com @CommandDefinition">
    Não precisa de código de registro: o [processador de anotações](/docs/pt-br/development/basics/annotations) cuida disso.

    ```java title="GreetCommand.java"
    package org.example.command;

    import org.powernukkitx.command.Command;
    import org.powernukkitx.command.CommandSender;
    import org.powernukkitx.plugin.annotation.CommandDefinition;
    import org.powernukkitx.plugin.annotation.CommandDefinition.CommandMode;

    @CommandDefinition(
        name = "greet",
        description = "Greet a player",
        usage = "/greet [name]",
        permission = "greet.permission",
        commandMode = CommandMode.RAW // plain string arguments
    )
    public class GreetCommand extends Command {
        @Override
        public boolean execute(CommandSender sender, String label, String[] args) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
    }
    ```
  </Tab>
  <Tab value="À mão">
    ```java title="GreetCommand.java"
    package org.example.command;

    import org.powernukkitx.command.Command;
    import org.powernukkitx.command.CommandSender;

    public class GreetCommand extends Command {
        public GreetCommand() {
            super("greet", "Greet a player", "/greet [name]");
            this.setPermission("greet.permission");
        }

        @Override
        public boolean execute(CommandSender sender, String label, String[] args) {
            sender.sendMessage(args.length > 0 ? "Hello, " + args[0] + "!" : "Hello!");
            return true;
        }
    }
    ```

    Depois registre-a em `onEnable()`:

    ```java
    @Override
    public void onEnable() {
        this.getServer().getCommandMap().register("myplugin", new GreetCommand());
    }
    ```
  </Tab>
</Tabs>

## 3. Uma árvore de comandos

A árvore de comandos é uma API fluente: você descreve a forma do comando (palavras-chave e argumentos tipados) e o servidor cuida do autocompletar, das permissões, de quem pode rodá-lo e dos erros de sintaxe.

<CommandTree />

Chame `enableCommandTree()` no construtor e monte as rotas em `buildCommandTree`:

```java title="MyCommand.java"
package org.example.command;

import org.powernukkitx.Player;
import org.powernukkitx.command.Command;
import org.powernukkitx.command.CommandResult;
import org.powernukkitx.command.route.RouteTree;
import org.powernukkitx.command.route.node.RouteNode;
import org.powernukkitx.command.tree.node.MessageStringNode;
import org.powernukkitx.command.tree.node.PlayersNode;
import java.util.List;

public class MyCommand extends Command {
    public MyCommand() {
        super("mycommand", "An advanced CommandTree command");
        this.enableCommandTree();
    }

    @Override
    protected void buildCommandTree(RouteTree tree) {
        // /mycommand info
        tree.getRoot().then(
            RouteNode.literal("info")
                .exec(context -> {
                    context.getSender().sendMessage("This command uses the PowerNukkitX CommandTree!");
                    return CommandResult.success();
                })
        );

        // /mycommand send <player> <message>
        tree.getRoot().then(
            RouteNode.literal("send").then(
                RouteNode.argument("player", new PlayersNode()).then(
                    RouteNode.argument("message", new MessageStringNode())
                        .exec(context -> {
                            List<Player> targets = context.getArg("player");
                            String message = context.getArg("message");
                            for (Player p : targets) {
                                p.sendMessage("Message: " + message);
                            }
                            context.getSender().sendMessage("Message sent!");
                            return CommandResult.success();
                        })
                )
            )
        );
    }
}
```

### Peças

| Método | O que faz |
| :-- | :-- |
| `RouteNode.literal(name)` | Uma palavra-chave fixa, como `info` em `/mycommand info`. |
| `RouteNode.argument(name, node)` | Um argumento tipado (`PlayersNode`, `IntNode`, `BlockNode`...). Leia com `context.getArg(name)`. |
| `.then(child)` | Adiciona a próxima palavra-chave ou argumento. |
| `.exec(context -> ...)` | Torna o nó executável: este código roda quando a entrada termina aqui. |
| `.senderType(type)` | Quem pode rodá-lo: `SenderType.PLAYER`, `CONSOLE` ou `ANY`. |
| `.permission(node)` | Exige uma permissão. |
| `.optional(true)` | Torna o argumento opcional. |
| `.suggest(list)` | Substitui as sugestões do autocompletar. |

### Resultados

Todo `exec` retorna um `CommandResult`:

| Resultado | Significado |
| :-- | :-- |
| `CommandResult.success()` | Funcionou. |
| `CommandResult.fail()` | Falhou. |
| `CommandResult.fail("message")` | Falhou, e quem enviou vê a mensagem. |
