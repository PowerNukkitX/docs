Um acabamento tem duas partes: um **padrão**, vindo do molde de ferraria no slot de molde, e um **material**, vindo do ingrediente no slot de material. Registre os seus e os jogadores vão aplicá-los na mesa de ferraria como os acabamentos vanilla. Eles ficam no `TrimRegistry`, acessível por `Registries.TRIM`.

<Steps>
  <Step>
    ### Registre padrões e materiais

    As duas chamadas lançam `RegisterException` se o id do item já estiver em uso:

```java filename="MyPlugin.java"
import org.powernukkitx.registry.Registries;
import org.powernukkitx.registry.RegisterException;

@Override
public void onEnable() {
    try {
        // A smithing template item -> the pattern id written into the trim NBT
        Registries.TRIM.registerPattern("myplugin:cool_smithing_template", "cool");

        // An ingredient item -> the material id + the hex tint used for the item name
        Registries.TRIM.registerMaterial("minecraft:emerald", "emerald_special", "#17DD62");
    } catch (RegisterException e) {
        getLogger().error("Trim is already registered", e);
    }
}
```

    - `registerPattern(templateItemId, patternId)`: o item de molde e o id do padrão gravado no NBT do acabamento.
    - `registerMaterial(ingredientItemId, materialId, color)`: o item ingrediente, o id do material e a cor hexadecimal (com `#`) que tinge o nome do acabamento.
  </Step>
  <Step>
    ### Marque os itens com tags

    A mesa de ferraria só aceita itens com a tag certa:

```java
import org.powernukkitx.item.ItemTags;
import java.util.List;

ItemTags.register("myplugin:cool_smithing_template", List.of("minecraft:trim_templates"));
ItemTags.register("minecraft:emerald", List.of("minecraft:trim_materials"));
```

    <Callout type="info">
      Os ids dos itens precisam existir. Use ids vanilla ou registre antes os seus [itens personalizados](/docs/pt-br/development/customs/items).
    </Callout>
  </Step>
  <Step>
    ### Sincronize os jogadores já online

    Os jogadores recebem a lista de acabamentos ao entrar. Vai registrar com eles já online? Envie a nova lista:

```java
Registries.TRIM.resyncOnlinePlayers();
```
  </Step>
</Steps>

## Remover e consultar acabamentos

```java
// Remove a registered pattern or material
Registries.TRIM.unregisterPattern("myplugin:cool_smithing_template");
Registries.TRIM.unregisterMaterial("minecraft:emerald");

// Look one up (returns an Optional)
Registries.TRIM.getPattern("myplugin:cool_smithing_template");
Registries.TRIM.getMaterial("minecraft:emerald");

// Read-only views of everything registered
Registries.TRIM.getPatterns();
Registries.TRIM.getMaterials();
```

<Callout type="warn">
  Registre cada id de molde e de ingrediente uma única vez: um segundo `registerPattern` ou `registerMaterial` para o mesmo id lança `RegisterException`.
</Callout>
