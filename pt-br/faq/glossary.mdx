As palavras que esta documentação usa e o que significam em um servidor PowerNukkitX.

| Termo | Significado |
| :-- | :-- |
| **Bedrock Edition** | A versão do Minecraft em celulares, consoles e Windows. O PowerNukkitX a atende. |
| **BDS** | Bedrock Dedicated Server, o software de servidor oficial da Mojang. |
| **Tick** | Um passo do loop de jogo do servidor. São 20 por segundo, então 100 ticks são 5 segundos. |
| **TPS** | Ticks por segundo. 20 é o saudável; menos que isso significa que o servidor está com lag. |
| **Level** | Um mundo. Cada um é uma pasta em `worlds/`. |
| **Chunk** | Uma coluna de 16 por 16 do mundo, gerada e carregada como uma única peça. |
| **Distância de visão** | Quantos chunks ao redor cada jogador recebe. A maior alavanca de desempenho. |
| **Operador (OP)** | Um jogador que pode rodar qualquer comando. |
| **Nó de permissão** | Um nome com pontos, como `nukkit.command.help`, que um comando ou plugin verifica antes de agir. |
| **Lista branca** | A lista de jogadores que podem entrar quando está ligada (`white-list.txt`). Também chamada de whitelist. |
| **Autenticação Xbox** | A verificação da conta Xbox de cada jogador. Desligá-la é o modo offline. |
| **Plugin** | Um jar Java em `plugins/` que adiciona comandos, eventos, conteúdo ou jogabilidade. |
| **Listener** | Uma classe de plugin cujos métodos `@EventHandler` rodam quando um evento acontece. |
| **Registro** | Onde blocos, itens, entidades e receitas personalizados são registrados. Registre em `onLoad()`. |
| **Pacote de recursos** | Texturas e modelos que os jogadores baixam ao entrar; necessários para ver o conteúdo personalizado. |
| **Pacote de comportamento** | Lógica de jogo do lado do cliente. Não suportado: o PowerNukkitX faz isso em plugins Java. |
| **Formulário** | Uma janela mostrada a um jogador: SimpleForm, ModalForm, CustomForm ou DDUI. |
| **Proxy** | Um servidor, como o WaterdogPE, que move jogadores entre vários servidores. |
| **`pnx.yml`** | O único arquivo que guarda todas as configurações do servidor. |
