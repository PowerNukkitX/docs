Respostas curtas para as perguntas mais comuns. Para erros e travamentos, vá para [Solução de problemas](/docs/pt-br/faq/troubleshooting).

<Accordions type="single">
  <Accordion title="O que é o PowerNukkitX?">
    Software de servidor de código aberto para Minecraft: Bedrock Edition. Jogadores em celulares, consoles e Windows entram com o cliente normal, sem mods.
  </Accordion>
  <Accordion title="Jogadores da Java Edition podem entrar?">
    Não. O PowerNukkitX fala o protocolo do Bedrock, que os clientes da Java Edition não conseguem usar. Para jogadores Java, use Paper, Purpur ou similares.
  </Accordion>
  <Accordion title="Posso usar plugins do Spigot, Paper ou Purpur?">
    Não. Eles são feitos para servidores da Java Edition; as APIs e o protocolo são completamente diferentes.
  </Accordion>
  <Accordion title="Pacotes de recursos e de comportamento são suportados?">
    Pacotes de recursos, sim: coloque o pacote compactado em `resource_packs/`. Pacotes de comportamento, não: o PowerNukkitX implementa mobs, blocos e itens no servidor, em Java.
  </Accordion>
  <Accordion title="Qual versão do Java eu preciso?">
    **Java 21 ou mais recente**, 64 bits. Java 8, 11, 17 e 20 causam erros de versão de classe. Veja os [Requisitos](/docs/pt-br/requirements).
  </Accordion>
  <Accordion title="Por que aparece um aviso de reflexão na inicialização?">
    Desde o Java 9 a reflexão é restrita por padrão, e o PowerNukkitX a usa para registrar itens e blocos personalizados e carregar plugins. Inicie-o com estas flags, ou com os scripts de inicialização fornecidos:

    ```bash
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    ```
  </Accordion>
  <Accordion title="Qual a diferença para o Nukkit e o PowerNukkit?">
    O PowerNukkitX é o fork moderno e ativo. Ele traz blocos, itens e entidades personalizados, IA de mobs próxima do vanilla, o gerador Terra e um único `pnx.yml` no lugar de `server.properties` e `nukkit.yml`.
  </Accordion>
  <Accordion title="Onde consigo plugins?">
    No [hub de plugins](https://powernukkitx.org/plugins). Cada plugin aponta para a release do GitHub do autor: coloque o jar em `plugins/` e reinicie.
  </Accordion>
  <Accordion title="Como publico meu próprio plugin?">
    Escreva-o com a API do PowerNukkitX, publique uma release no GitHub com o jar, entre no hub e envie o repositório. A equipe revisa antes de ir ao ar. Comece pelos [guias de desenvolvimento](/docs/pt-br/development).
  </Accordion>
  <Accordion title="Posso usar comercialmente?">
    Sim. O PowerNukkitX é LGPL-3.0: você pode rodá-lo e modificá-lo comercialmente e licenciar seus plugins como quiser. Alterações no próprio PowerNukkitX continuam LGPL.
  </Accordion>
  <Accordion title="Onde consigo ajuda?">
    Ajuda rápida no [Discord](https://discord.gg/powernukkitx), bugs nas [GitHub Issues](https://github.com/PowerNukkitX/PowerNukkitX/issues), perguntas mais longas nas [GitHub Discussions](https://github.com/PowerNukkitX/PowerNukkitX/discussions).
  </Accordion>
</Accordions>
