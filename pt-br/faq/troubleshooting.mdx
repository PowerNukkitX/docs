Comece pela primeira verificação e depois abra o problema que combina com o que você está vendo.

<Callout type="info" title="Primeiro, verifique o Java">
  Rode `java -version`. Deve aparecer **21 ou superior**: o PowerNukkitX precisa do Java 21+ (veja os [Requisitos](/docs/pt-br/requirements)).
</Callout>

## Java

<Accordions>
  <Accordion title="UnsupportedClassVersionError">
    ```text
    java.lang.UnsupportedClassVersionError: org.powernukkitx/Nukkit has been compiled by a more
    recent version of the Java Runtime (class file version 65.0), this version of the Java
    Runtime only recognizes class file versions up to ...
    ```

    Seu Java é antigo demais: a versão de classe `65.0` é o Java 21. Instale o Java 21 ou mais recente e confira com `java -version`.
  </Accordion>
  <Accordion title="Há várias versões do Java instaladas">
    Provavelmente a errada está na frente. Você pode:

    - definir `JAVA_HOME` apontando para o seu Java 21+ e colocar a pasta `bin` dele no início do `PATH`;
    - ou iniciar o servidor com o caminho completo para o Java certo:

    ```bash
    /path/to/jdk-21/bin/java -jar powernukkitx.jar
    ```

    No Linux, troque a versão padrão com `sudo update-alternatives --config java`. No Windows, confira se `JAVA_HOME` nas variáveis de ambiente do sistema aponta para uma pasta do JDK 21+.
  </Accordion>
  <Accordion title="Java de 32 bits">
    O PowerNukkitX precisa de Java de **64 bits**: uma JVM de 32 bits não consegue usar memória suficiente e trava sob carga. Se `java -version` mencionar `Client VM` ou `32-Bit`, instale o OpenJDK de 64 bits.
  </Accordion>
</Accordions>

## Inicialização

<Accordions>
  <Accordion title="BindException: Address already in use">
    Outro programa já usa a porta do servidor (`19132/UDP` por padrão). Pare qualquer outro servidor Bedrock ou mude `port` em `baseSettings` no `pnx.yml`.
  </Accordion>
  <Accordion title="OutOfMemoryError, ou o servidor fecha na hora">
    O servidor pode estar sem memória suficiente. Inicie-o com limites explícitos, deixando espaço para o sistema:

    ```bash
    java -Xms1G -Xmx2G -jar powernukkitx.jar
    ```
  </Accordion>
  <Accordion title="Arquivos faltando ou erros de permissão na primeira inicialização">
    Na primeira inicialização, o PowerNukkitX cria mundos e configuração na pasta dele. Rode-o a partir de uma pasta própria e gravável, não de uma pasta do sistema ou somente leitura. No Linux e no macOS, garanta que o seu usuário é dono do jar e da pasta (`chown`, `chmod`).
  </Accordion>
  <Accordion title="O servidor iniciou, mas ninguém consegue se conectar">
    - Confira se as versões do cliente e do servidor batem.
    - Abra ou redirecione a porta UDP `19132` no firewall e no roteador.
    - Na mesma máquina, conecte em `127.0.0.1` ou `localhost`.
  </Accordion>
</Accordions>
