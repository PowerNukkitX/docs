Quando uma versão de plugin tem uma vulnerabilidade conhecida, a equipe publica um aviso e a página do plugin o mostra. Os mesmos avisos estão disponíveis no formato [OSV](https://ossf.github.io/osv-schema/), que os scanners de segurança já leem.

```text
GET /api/v1/advisories/osv
```

A resposta é `{ advisories }`: um registro OSV por aviso publicado. Rascunhos e avisos retirados nunca entram.

<ApiTry path="/advisories/osv" />

<Callout type="info">
  Rode um scanner sobre este feed na sua CI para ser avisado quando um plugin que você distribui receber um aviso.
</Callout>
