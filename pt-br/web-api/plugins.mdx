Um plugin é identificado pelo **slug**, o `owner.name` que o hub deu a ele, como em `/plugins/owner.name`.

## Listar e buscar

```text
GET /api/v1/plugins
```

Plugins publicados, 24 por página. A resposta traz a página e o total no primeiro nível: `data`, `page`, `perPage`, `total`, `totalPages`, e `fuzzy`, que é `true` quando `q` não bateu exatamente com nada e os resultados são os nomes mais parecidos.

| Parâmetro | O que faz |
| :-- | :-- |
| `q` | Busca de texto em nome, slug e resumo. |
| `category` | Um id de categoria, de [`/categories`](/docs/pt-br/web-api/catalogue). |
| `api` | Só plugins que declaram esta versão da API do PowerNukkitX no `plugin.yml`. |
| `sort` | `downloads`, `trending`, `stars`, `followers`, `rating`, `updated` ou `name`. |
| `page` | De 1 a 500. |

<ApiTry path="/plugins" query="q=economy&sort=downloads" />

## Um plugin

```text
GET /api/v1/plugins/{slug}
```

Um plugin com os metadados do GitHub, as versões e o README, resolvidos na hora da requisição. Só versões **aprovadas** podem ser baixadas.

<ApiTry path="/plugins/{slug}" params={{ slug: "" }} />

## Avaliações

```text
GET /api/v1/plugins/{slug}/reviews
```

Avaliações da comunidade, as mais recentes primeiro. A paginação fica em `meta`: `{ hasMore, limit, offset }`.

| Parâmetro | O que faz |
| :-- | :-- |
| `limit` | Quantas retornar. |
| `offset` | Quantas pular. |

<ApiTry path="/plugins/{slug}/reviews" params={{ slug: "" }} query="limit=10" />

## Histórico de downloads

```text
GET /api/v1/plugins/{slug}/history
```

Downloads por dia, em `data.points`. É isso que desenha o gráfico na página de um plugin.

<ApiTry path="/plugins/{slug}/history" params={{ slug: "" }} />

## Emblema

```text
GET /api/v1/plugins/{slug}/badge
```

Um emblema de status como **imagem SVG**, não JSON. Use como imagem em um README:

```markdown
![downloads](https://powernukkitx.org/api/v1/plugins/owner.name/badge?metric=downloads)
```

| Parâmetro | O que faz |
| :-- | :-- |
| `metric` | `api`, `downloads`, `rating`, `stars` ou `version`. |
| `label` | Troca o texto da esquerda, até 32 caracteres. |

## Baixar uma versão

```text
GET /api/v1/plugins/{slug}/download?tag={tag}
```

Redireciona para o jar de uma versão aprovada no GitHub e conta o download. `tag` é obrigatório. Uma versão que existe mas não foi aprovada responde `403 not_approved`. É o que o `pnx plugin install` da CLI chama.
