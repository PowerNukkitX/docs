PowerNukkitX 并不是唯一的基岩版服务器。本页把它与 Nukkit 和 Mojang 的 Bedrock Dedicated Server（BDS）放在一起比较，帮助你做出选择。

## 一览

| | PowerNukkitX | Nukkit | BDS（官方） |
| :-- | :-- | :-- | :-- |
| 性能 | **高** | 中 | 高 |
| 插件系统 | **有，Java** | 有，Java | 无 |
| API | **现代** | 陈旧 | 无 |
| 新基岩版版本 | **快** | 慢 | 官方 |
| 开源 | **是** | 是 | 否 |
| 社区 | **活跃** | 一般 | 官方 |
| 自定义内容 | **好** | 一般 | 少 |

## 如何选择

<Cards>
  <Card title="PowerNukkitX">
    想用插件和自定义内容扩展的现代服务器，背后有活跃的社区。
  </Card>
  <Card title="Nukkit">
    依赖于未再更新的旧 Nukkit 插件的服务器。
  </Card>
  <Card title="BDS">
    纯原版体验，跟随 Mojang 官方更新，客户端兼容性最好。
  </Card>
</Cards>

## 迁移到 PowerNukkitX

<Steps>
  <Step>
    **检查插件。** 部分 Nukkit 插件需要适配 PowerNukkitX API。
  </Step>
  <Step>
    **带上世界和设置。** 复制你的世界，再把设置迁移到 `pnx.yml`。
  </Step>
  <Step>
    **检查权限。** 重新创建你的权限组和权限节点。
  </Step>
</Steps>

每种来源都有单独的指南：[从 Nukkit](/docs/zh/migration/nukkit)、[从 BDS](/docs/zh/migration/bds)、[从 PocketMine-MP](/docs/zh/migration/pocketmine)。

</Callout>
