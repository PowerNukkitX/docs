PowerNukkitX 把所有设置都放在**一个文件**里，即服务器文件夹根目录下的 `pnx.yml`。

<ConfigSections />

<Callout type="error" title="编辑 pnx.yml 之前先停止服务器">
  运行中的服务器会把配置保存在内存中，并在关闭时写回 `pnx.yml`，这会覆盖你在此期间做的所有修改。
</Callout>

## 基础设置

`baseSettings`：玩家如何连接服务器，以及他们在服务器列表中看到的内容。

| 键 | 默认值 | 说明 |
| :-- | :-- | :-- |
| `ip` | `"0.0.0.0"` | 服务器监听的地址。0.0.0.0 表示监听所有网卡。 |
| `port` | `19132` | 基岩版客户端连接的 UDP 端口。 |
| `maxPlayers` | `20` | 同时在线的最大玩家数。 |
| `defaultLevelName` | `"world"` | 默认世界的文件夹名。 |
| `allowList` | `false` | 只有 white-list.txt 中的玩家可以加入。 |
| `allowListMessage` | `"Server is white-listed"` | 不在白名单中的玩家被踢出时看到的消息。 |
| `motd` | `"PowerNukkitX Server"` | 服务器列表中显示的主标题。 |
| `subMotd` | `"powernukkitx.org"` | 服务器列表中显示的第二行。 |
| `xboxAuth` | `true` | Xbox Live 验证。false 表示离线模式。 |
| `autosaveDelay` | `6000` | 两次自动保存世界之间的刻数。 |

## 玩家设置

`playerSettings`：保存哪些玩家数据，以及如何检查玩家。

| 键 | 默认值 | 说明 |
| :-- | :-- | :-- |
| `savePlayerData` | `true` | 玩家离开时保存位置、背包和状态。 |
| `forceSkinTrusted` | `false` | 信任所有皮肤，允许自定义和第三方皮肤。 |
| `checkMovement` | `true` | 服务器端移动检查，防止简单的飞行和加速作弊。 |
| `spawnRadius` | `16` | 新玩家出现在距离世界出生点多远的范围内。 |

## 游戏设置

`gameplaySettings`：游戏规则。

| 键 | 默认值 | 说明 |
| :-- | :-- | :-- |
| `gamemode` | `0` | 默认游戏模式。0 生存，1 创造，2 冒险，3 旁观。 |
| `difficulty` | `1` | 默认难度。0 和平，1 简单，2 普通，3 困难。 |
| `pvp` | `true` | 玩家之间可以互相攻击。 |
| `allowFlight` | `false` | 生存模式的玩家可以飞行。 |
| `viewDistance` | `20` | 发送给玩家的最远距离，单位为区块。 |
| `allowNether` | `true` | 允许前往下界。 |
| `allowTheEnd` | `true` | 允许前往末地。 |
| `spawnProtection` | `16` | 出生点周围非管理员不能修改的半径。 |

## 性能设置

`performanceSettings`：服务器如何使用你的机器。建议参见[性能调优](/docs/zh/administration/performance)。

| 键 | 默认值 | 说明 |
| :-- | :-- | :-- |
| `asyncWorkers` | `4` | 用于异步任务（如区块生成）的后台线程数。 |
| `registryCacheEnabled` | `true` | 缓存注册表条目，更快地解析方块和物品。 |

## 示例

```yaml title="pnx.yml"
baseSettings:
  port: 19132
  maxPlayers: 50
  motd: "My Server"
gameplaySettings:
  difficulty: 2
  viewDistance: 12
```
