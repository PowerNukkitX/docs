官方镜像是 Docker Hub 上的 [`powernukkitx/server`](https://hub.docker.com/r/powernukkitx/server)。

## 启动容器

<Tabs items={["Docker Compose", "docker run"]}>
  <Tab value="Docker Compose">
    在你选择的文件夹中创建 `docker-compose.yml`：

    ```yaml title="docker-compose.yml"
    services:
      pnx-server:
        image: powernukkitx/server:latest
        container_name: pnx-server
        ports:
          - "19132:19132/udp"
        volumes:
          - ./data:/data
        restart: unless-stopped
    ```

    然后在后台启动：

    ```bash
    docker compose up -d
    ```
  </Tab>
  <Tab value="docker run">
    ```bash
    docker run -d \
      --name pnx-server \
      -p 19132:19132/udp \
      -v /path/to/your/data:/data \
      powernukkitx/server
    ```

    <Callout type="warn">
      把 `/path/to/your/data` 换成你机器上的绝对路径，否则替换容器时服务器数据会丢失。
    </Callout>
  </Tab>
</Tabs>

## 数据存放位置

`/data` 卷保存服务器写入的所有内容：

<Files>
  <Folder name="data" defaultOpen>
    <File name="pnx.yml" />
    <Folder name="worlds" />
    <Folder name="plugins" />
    <Folder name="resource_packs" />
    <Folder name="logs" />
  </Folder>
</Files>

第二个可选卷 `/home/minecraft` 用于保存控制台的 JLine 缓存。

## 使用控制台

服务器在后台运行。要输入 `op` 或 `stop` 等命令，请连接到它：

```bash
docker attach pnx-server
```

要离开而不停止服务器，请先按 **Ctrl + P**，再按 **Ctrl + Q**。

## JVM 参数

默认情况下，镜像用以下参数启动 Java：

- ZGC 垃圾回收器：`-XX:+UseZGC`、`-XX:+ZGenerational`、`-XX:+UseStringDeduplication`；
- `--add-opens` 反射参数；
- `--skip-setup --accept-license --language eng`，用于跳过设置向导。

要修改这些参数，例如给服务器 4 GB 堆内存，请在镜像名之后写出完整命令：

```bash
docker run -d \
  --name pnx-server \
  -p 19132:19132/udp \
  -v /path/to/your/data:/data \
  powernukkitx/server \
  -Xmx4G -Xms1G \
  -cp /app/powernukkitx.jar:./libs/* \
  org.powernukkitx.PowerNukkitX \
  --skip-setup --accept-license --language eng
```
