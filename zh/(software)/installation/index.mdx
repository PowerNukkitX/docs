运行 PowerNukkitX 需要 Java 21 和服务器 jar 文件。各平台的步骤都一样，只是命令不同。

## 选择你的系统

<Cards>
  <Card icon={<Monitor />} title="Windows" href="/docs/zh/installation/windows">
    Windows 10 或 11，使用 `start.bat` 脚本。
  </Card>
  <Card icon={<Apple />} title="macOS" href="/docs/zh/installation/macos">
    通过 Homebrew 安装 Java，支持 Intel 和 Apple Silicon。
  </Card>
  <Card icon={<Terminal />} title="Linux" href="/docs/zh/installation/linux">
    Ubuntu、Debian、CentOS 或 RHEL，作为 systemd 服务运行。
  </Card>
  <Card icon={<Container />} title="Docker" href="/docs/zh/installation/docker">
    官方镜像，使用 Docker 或 Docker Compose。
  </Card>
</Cards>

<Callout type="info">
  想用一条命令完成安装？[安装页面](https://powernukkitx.org/install)也介绍了 `pnx` 命令行工具。
</Callout>
