在 Linux 上，先从发行版的软件包安装 Java 21，用脚本启动服务器，然后把它作为 systemd 服务运行，让它自动启动。

## 安装服务器

<Steps>
  <Step>
    ### 安装 Java 21

    <Tabs items={["Ubuntu / Debian", "CentOS / RHEL / Rocky"]}>
      <Tab value="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y openjdk-21-jre-headless wget
        ```
      </Tab>
      <Tab value="CentOS / RHEL / Rocky">
        ```bash
        sudo dnf install -y java-21-openjdk-headless wget
        ```
      </Tab>
    </Tabs>

    用 `java -version` 检查。
  </Step>
  <Step>
    ### 创建专用用户

    用一个独立的无特权用户运行服务器，绝不要用 `root`：

    ```bash
    sudo useradd --system --user-group --home-dir /opt/pnx-server --create-home minecraft
    ```
  </Step>
  <Step>
    ### 下载服务器

    ```bash
    sudo -u minecraft -s
    cd /opt/pnx-server
    wget https://github.com/PowerNukkitX/PowerNukkitX/releases/download/snapshot/powernukkitx.jar
    ```
  </Step>
  <Step>
    ### 创建启动脚本

    ```bash title="start.sh"
    #!/bin/bash
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    ```

    ```bash
    chmod +x start.sh
    ```
  </Step>
  <Step>
    ### 运行一次设置向导

    ```bash
    ./start.sh
    ```

    接受许可协议（`y`），选择语言（`chs`），输入 MOTD 和端口。当控制台显示 `Startup finished` 时，输入 `stop`，再输入 `exit` 回到你自己的用户。
  </Step>
</Steps>

## 作为服务运行

systemd 服务会在开机时启动服务器，并在崩溃后自动重启。

<Steps>
  <Step>
    ### 创建服务

    ```bash
    sudo nano /etc/systemd/system/pnx.service
    ```

    ```ini title="/etc/systemd/system/pnx.service"
    [Unit]
    Description=PowerNukkitX Minecraft Bedrock Server
    After=network.target

    [Service]
    User=minecraft
    Group=minecraft
    WorkingDirectory=/opt/pnx-server
    ExecStart=/bin/bash /opt/pnx-server/start.sh
    Restart=on-failure
    RestartSec=10

    [Install]
    WantedBy=multi-user.target
    ```
  </Step>
  <Step>
    ### 启用并启动

    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable pnx.service
    sudo systemctl start pnx.service
    ```
  </Step>
</Steps>

## 日常命令

| 操作 | 命令 |
| :-- | :-- |
| 状态 | `sudo systemctl status pnx.service` |
| 实时日志（Ctrl + C 退出） | `journalctl -u pnx.service -f` |
| 停止 | `sudo systemctl stop pnx.service` |
| 重启 | `sudo systemctl restart pnx.service` |
