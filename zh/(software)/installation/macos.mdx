在 macOS 上，先用 Homebrew 安装 Java 21，然后用启动脚本运行服务器 jar。Intel 和 Apple Silicon 的 Mac 步骤相同。

## 安装

<Steps>
  <Step>
    ### 安装 Java 21

    使用 [Homebrew](https://brew.sh/) 安装 Java。在终端中：

    ```bash
    brew install openjdk@21
    sudo ln -sfn /opt/homebrew/opt/openjdk@21/OpenJDK.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
    ```

    在较旧的 Intel Mac 上，把 `/opt/homebrew` 换成 `/usr/local`。用 `java -version` 检查：应该显示版本 `21`。
  </Step>
  <Step>
    ### 创建服务器文件夹

    ```bash
    mkdir ~/pnx-server
    cd ~/pnx-server
    ```
  </Step>
  <Step>
    ### 下载服务器

    从 [GitHub releases](https://github.com/PowerNukkitX/PowerNukkitX/releases) 下载最新的 `powernukkitx.jar` 到 `~/pnx-server`。
  </Step>
  <Step>
    ### 创建启动脚本

    PowerNukkitX 启动时需要 Java 反射参数。创建 `start.sh`：

    ```bash title="start.sh"
    #!/bin/bash
    java -jar --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.io=ALL-UNNAMED powernukkitx.jar
    ```

    然后赋予执行权限：

    ```bash
    chmod +x start.sh
    ```
  </Step>
  <Step>
    ### 启动服务器

    ```bash
    ./start.sh
    ```

    第一次启动时，设置向导会让你接受许可协议（`y`）、选择语言（例如 `chs`），并输入服务器名称（MOTD）和端口。输入 `stop` 可以正常关闭。
  </Step>
</Steps>

## 故障排除

<Accordions>
  <Accordion title="提示“无法验证开发者”或 Gatekeeper 警告">
    macOS 可能会拦截 Java 或启动器。打开 **系统设置 > 隐私与安全性**，滚动到安全性部分，点击被拦截项目旁边的 **仍要允许**。
  </Accordion>
</Accordions>
