[Terra](https://terra.polydev.org/) 是一款由**配置包**驱动的地形生成器：每个配置包都描述了自己的生物群系和地貌。PowerNukkitX 开箱即用地支持它。

<Steps>
  <Step>
    ### 启用 Terra

    在服务器**停止**时设置：

    ```yaml title="pnx.yml"
    miscSettings:
      enableTerra: true
    ```

    启动服务器：它会在根目录创建 `terra/` 文件夹。
  </Step>
  <Step>
    ### 添加配置包

    1. 选择一个配置包，例如[社区配置包](https://terra.polydev.org/config/community-packs.html)中的。
    2. 把它的文件夹或 ZIP 放进 `terra/packs/`。
    3. 打开配置包的 `pack.yml`，记下它的 `id`，例如 `REIMAGEND`。
  </Step>
  <Step>
    ### 创建使用它的世界

    在 `worlds/` 中为新世界创建一个文件夹，例如 `worlds/end`，并放入 `config.json`：

    ```json title="worlds/end/config.json"
    {
      "format": "leveldb",
      "enable": true,
      "generators": {
        "2": {
          "name": "terra",
          "seed": 0,
          "enableAntiXray": false,
          "antiXrayMode": "LOW",
          "preDeobfuscate": true,
          "dimensionData": {
            "dimensionName": "minecraft:end",
            "dimensionId": 2,
            "minHeight": 0,
            "maxHeight": 255,
            "height": 256,
            "chunkSectionCount": 16
          },
          "preset": {
            "pack": "REIMAGEND"
          }
        }
      }
    }
    ```

    把 `preset.pack` 中的 `REIMAGEND` 换成你的配置包 id。
  </Step>
  <Step>
    ### 前往新世界

    启动服务器并传送到新世界：

    ```bash
    /world tp end Dim2
    ```
  </Step>
</Steps>
