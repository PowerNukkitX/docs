[插件中心](https://powernukkitx.org/plugins)收录了社区为 PowerNukkitX 制作的插件。每个条目和每个版本在上线前都会经过**审核**，每个 jar 文件也会被**扫描**。

## 安装插件

<Steps>
  <Step>
    ### 查找

    按名称、仓库或关键词搜索，或按分类浏览。可以按下载量、热度、星标、评分或最近更新排序，并按服务器版本或认证发布者筛选。想要更紧凑的显示？在排序旁边切换到**列表**视图。
  </Step>
  <Step>
    ### 下载

    在插件页面上，**如何安装**会提供最新已批准版本的 jar，直接来自作者的 GitHub release。
  </Step>
  <Step>
    ### 安装

    把 jar 放进服务器的 `plugins/` 文件夹，然后重启服务器。
  </Step>
</Steps>

<Callout type="info">
  先看看**详情**卡片：它会显示插件需要什么（依赖、API 版本），并在插件超过一年未更新时给出提醒。
</Callout>

## 发布你的插件

<Steps>
  <Step>
    ### 准备仓库

    你的插件必须放在你有推送权限的**公开 GitHub 仓库**中，并且有一个包含 `.jar` 的 **release**。如何构建插件，参见[创建插件](/docs/zh/development/basics)。
  </Step>
  <Step>
    ### 提交

    登录后打开[提交插件](https://powernukkitx.org/dashboard/submit)。选择仓库，填写名称、一句话简介和最多三个分类，还可以选择一种强调色。实时预览会显示它的样子。
  </Step>
  <Step>
    ### 等待审核

    审核员会检查条目并查看最新的 jar。你会收到包含结果的通知；如果被拒绝，可以看到原因并重新提交。
  </Step>
  <Step>
    ### 保持更新

    每个新的 GitHub release 也会先经过审核，玩家才能下载。在 **控制台 > 我的插件** 中管理一切。
  </Step>
</Steps>

## 定制你的页面

在插件的管理页面中，**条目**下：

| 内容 | 方式 | 审核 |
| :-- | :-- | :-- |
| 名称、简介、分类 | 编辑条目 | 公开条目需审核 |
| 图标 | 仓库中的 `.jarbage/icon.png`，或直接上传 | 需审核 |
| 强调色 | 网站七种颜色之一 | 立即生效 |
| 链接 | 网站、文档、Discord、问题反馈、支持（仅限 https） | 立即生效 |
