PowerNukkitX 拥有完整的基岩版原版命令，外加服务器命令。在**控制台**中输入命令时不带斜杠；作为管理员**在游戏中**输入时带斜杠。

<Tabs items={["服务器", "玩家", "世界"]}>
  <Tab value="服务器">
    | 命令 | 作用 |
    | :-- | :-- |
    | `stop` | 保存一切并正常关闭。请始终用它，而不是强制结束进程。 |
    | `save-all` | 立即把所有已加载的世界写入磁盘。 |
    | `reload` | 重新加载插件和配置。完整重启更安全。 |
    | `version` / `plugins` | 服务器版本，以及已加载的插件。 |
    | `status` | 运行时间、TPS、内存，以及已加载的世界和实体。 |
  </Tab>
  <Tab value="玩家">
    | 命令 | 作用 |
    | :-- | :-- |
    | `list` | 列出在线玩家。 |
    | `kick <player> [reason]` | 断开某个玩家的连接。 |
    | `tp <player> <target>` | 把玩家传送到另一名玩家或某个坐标。 |
    | `gamemode <mode> [player]` | 设置游戏模式：`survival`、`creative`、`adventure`、`spectator`。 |
    | `give <player> <item> [amount]` | 给予物品。 |
    | `xp <amount> [player]` | 给予经验。 |

    管理员、封禁和白名单请参见[玩家](/docs/zh/administration/players)。
  </Tab>
  <Tab value="世界">
    | 命令 | 作用 |
    | :-- | :-- |
    | `time set <value>` | 设置时间：`day`、`night` 或刻数。 |
    | `weather <clear\|rain\|thunder>` | 改变天气。 |
    | `difficulty <0-3>` | 和平、简单、普通或困难。 |
    | `gamerule <rule> <value>` | 修改游戏规则，例如 `doDaylightCycle` 或 `keepInventory`。 |
    | `setworldspawn` / `spawnpoint` | 设置世界出生点或玩家的重生点。 |
  </Tab>
</Tabs>

<Callout type="error" title="绝不要强制结束进程">
  关闭终端或强制结束 Java 可能会丢失世界和玩家数据。请使用 `stop`，确保所有内容先写入磁盘。
</Callout>

## 帮助

`help` 会分页列出你可以执行的所有命令；`help <command>` 会显示某个命令的用法。玩家能执行哪些命令取决于他的[权限](/docs/zh/permissions)。
