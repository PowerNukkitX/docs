每个世界（*level*）都是 `worlds/` 中的一个文件夹。默认世界由 `pnx.yml` 中的 `defaultLevelName` 指定（默认为 `world`），会在启动时加载；新玩家会出现在这里。

## 更改默认世界

```yaml title="pnx.yml"
baseSettings:
  defaultLevelName: world
```

<Callout type="warn">
  请先停止服务器：运行中的服务器会在关闭时用内存中的内容重写 `pnx.yml`。
</Callout>

## 导入世界

PowerNukkitX 读取基岩版的 **LevelDB** 格式，所以来自其他服务器或从基岩版客户端导出的世界都可以使用。

<Steps>
  <Step>停止服务器。</Step>
  <Step>把世界文件夹复制到 `worlds/`。</Step>
  <Step>把 `defaultLevelName` 设为该文件夹名，或用多世界插件加载它。</Step>
  <Step>启动服务器。</Step>
</Steps>

## 每个世界的设置

难度、出生点和游戏规则属于各个世界，可以在运行时修改：

```bash title="Console"
difficulty normal
setworldspawn
gamerule keepInventory true
```

## 同时运行多个世界

核心只加载一个默认世界。要运行多个世界并在它们之间转移玩家，请从[插件中心](https://powernukkitx.org/plugins)安装多世界插件。

## 出生点与生成

| 设置 | 效果 |
| :-- | :-- |
| `playerSettings.spawnRadius` | 新玩家出现在距离世界出生点多远的范围内。 |
| `gameplaySettings.spawnProtection` | 出生点周围非管理员不能修改的半径。 |

地形可以由 [Terra](/docs/zh/integrations/terra) 生成；区块生成在异步工作线程上运行（参见[性能](/docs/zh/administration/performance)）。
