**PowerNukkitX Assistant** 是一款适用于 Windows、Linux 和 macOS 的桌面应用。它可以创建服务器、启动服务器、显示控制台、安装插件和修改设置，全程无需终端。它为第一个服务器而设计，当你运行多个服务器时依然好用。

<AssistantWindow />

在底层，它驱动的是 [PNX CLI](/docs/zh/cli)：应用内置了编译好的 CLI，调用的就是 `pnx` 所用的同一套函数，因此窗口和终端在创建或启动服务器的方式上永远不会不一致。

## 安装

从 [pnx-cli releases](https://github.com/PowerNukkitX/pnx-cli/releases) 下载适合你系统的安装包：

| 系统 | 文件 |
| :-- | :-- |
| Windows | 安装程序（安装版 `.exe`），或无需安装即可运行的便携版 `.exe`。 |
| Linux | `.AppImage`：赋予执行权限后运行。 |
| macOS | `.dmg`：打开后把应用拖到“应用程序”。 |

服务器仍然需要 **Java 21** 或更高版本。Assistant 会在首次启动时检查，缺少时会提示你。

## 快捷键

| 按键 | 操作 |
| :-- | :-- |
| `Ctrl` + `K` | 命令面板：跳转到任意位置、启动或停止服务器、创建备份。 |
| `Ctrl` + `1` … `7` | 在侧边栏的各个视图之间切换。 |
| `Esc` | 关闭命令面板或对话框。 |
