**插件**视图会搜索[插件中心](https://powernukkitx.org/plugins)，并直接安装到当前服务器的 `plugins/` 文件夹。

## 插件市场

在搜索框中输入即可查找插件。**安装**会从 GitHub 下载最新的**已批准**版本，并在写入 `plugins/` 之前用中心记录的 SHA-256 校验。重启服务器以加载它。

## 已安装

**已安装**标签页列出 Assistant 安装过的插件：

- 有更新的已批准版本时会出现**更新**；
- **移除**会把插件从 `plugins/` 删除；
- **已是最新**表示没有更新的版本。

<Callout type="info">
  Assistant 与 `pnx plugin` 使用相同的中心接口。要让两者都指向其他中心，请设置 `PNX_API_URL`：参见 [CLI](/docs/zh/cli#state)。
</Callout>
