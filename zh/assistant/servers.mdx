## 创建服务器

**创建服务器**是一个四步向导：

<Steps>
  <Step>**文件夹**：服务器存放的位置。一个空文件夹，不存在时会自动创建。</Step>
  <Step>**版本**：PowerNukkitX 版本。默认选中最新稳定版。</Step>
  <Step>**内存**：启动时分配的内存。2 GB 足以轻松支撑约十名玩家。</Step>
  <Step>**构建**：官方 jar 会在实时进度条中下载，写入启动脚本并登记服务器。</Step>
</Steps>

完成后，**立即运行**会启动它，**打开文件夹**会显示文件。

## 多个服务器

Assistant 维护着一个服务器列表，以标签形式显示在**我的服务器**顶部：

- 点击一个标签，让它成为**当前**服务器：启动、停止、插件和设置都作用于它；
- 铅笔图标用于重命名，垃圾桶图标把它从列表中移除，文件仍保留在磁盘上；
- **添加服务器**用于连接你已有的文件夹，其中必须包含 `powernukkitx.jar`。

CLI 的默认服务器会在第一次时自动加入列表。

## 启动、停止与控制台

**我的服务器**可以启动和停止当前服务器，并以服务器自身的颜色实时显示控制台。

| 控制台中 | 作用 |
| :-- | :-- |
| 命令输入框 | 向服务器发送命令，就像在它的终端中输入一样。按 **Enter** 执行。 |
| 全部 / 警告 / 错误 | 筛选日志行。 |
| 清空、复制、导出 | 清空显示、复制内容，或把日志保存为文件。 |
| 自动滚动 | 始终显示最新一行。 |

**停止**会向服务器发送正常的 `stop`，让它在退出前保存。开启**关闭时确认**后，在服务器运行时关闭应用会先询问是否停止服务器。

## 运行状态

控制台旁边显示运行中服务器的实时数据：运行时间、在线玩家、端口，以及记录的错误和警告数量。

## 备份

**我的服务器**中的**备份**会把服务器（世界和配置）的快照保存到它的 `backups/` 文件夹。

| 操作 | 说明 |
| :-- | :-- |
| 新建备份 | 立即保存一份副本。 |
| 恢复 | 确认后用该副本替换服务器文件。服务器必须处于停止状态。之后的更改会丢失。 |
| 删除 | 永久删除该副本。 |

<Callout type="info">
  备份保存在服务器旁边。为了在磁盘损坏时仍可恢复，也请把它们复制到另一台机器：参见[备份](/docs/zh/administration/backups)。
</Callout>
