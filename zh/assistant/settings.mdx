## 服务器设置

服务器的**设置**视图是当前服务器 `pnx.yml` 的编辑器。它在服务器首次启动后出现，因为 `pnx.yml` 是在那时创建的。

- **常用项**排在最前面：MOTD、端口、最大玩家数、世界名称、白名单、视距、Xbox 验证等。
- **全部键**按分区列出其余所有设置，并提供按名称查找的筛选框。
- 每项设置都有合适的控件：是或否用开关，数量和端口用数字框，服务器语言用下拉列表。文件中的注释会以提示的形式显示。

**保存**只重写你修改过的行，文件的注释和格式都会保留，同时保存一份 `pnx.yml.assistant-bak` 副本。列表和嵌套块在这里是只读的：点击**打开文件**手动修改。

<Callout type="warn">
  设置在下次启动时生效。请在服务器停止时保存：运行中的服务器会在关闭时重写 `pnx.yml`。
</Callout>

## Assistant 偏好设置

应用本身的**设置**。每项修改立即生效。

| 设置 | 选项 |
| :-- | :-- |
| 语言 | English、Français、Español、Deutsch、Português (Brasil)。 |
| 主题 | 浅色、深色或跟随系统。 |
| 密度 | 舒适，或适合小屏幕的紧凑模式。 |
| 减少动画 | 关闭过渡效果和 3D 动态。 |
| 关闭时确认 | 退出前询问是否正常停止服务器。 |

## 更新

Assistant 会自动更新。默认每三小时检查一次新版本，并可在后台下载；是否安装由你决定。**立即检查**会马上查找。

## 你的数据

Assistant 把偏好设置和服务器列表保存在 `~/.pnx-cli` 中，与 CLI 共用。**打开**会显示这个文件夹。**重置偏好设置**会把主题、密度、动画和内存恢复默认；你的服务器不受影响。
