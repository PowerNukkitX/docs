`pnx` 在终端中创建、启动和维护 PowerNukkitX 服务器：它会下载正确的 jar、编写启动脚本、选择 Java 参数、安装经过审核的插件，并检查机器状态。它是开源的，位于 [pnx-cli](https://github.com/PowerNukkitX/pnx-cli) 仓库。

<CliSession />

## 安装

需要 **Node.js 20.12** 或更高版本，服务器本身需要 Java 21。

```bash
npm install -g @powernukkitx/cli
pnx --version
```

不想全局安装？每个命令也可以通过 `npx @powernukkitx/cli <命令>` 运行。

这个包会安装两个命令：

| 命令 | 用途 |
| :-- | :-- |
| `pnx` | 所有功能：本文档中的子命令。单独运行会打开交互式菜单。 |
| `pnxcli` | [引导式启动器](/docs/zh/cli/launcher)：只做一件事，创建服务器，用提问代替参数。 |

## 命令作用于哪个服务器

大多数命令都作用于**一个服务器文件夹**。`pnx` 按以下顺序选择：

<Steps>
  <Step>通过 `--dir` 指定的文件夹（对支持该参数的命令）。</Step>
  <Step>默认服务器，由 `pnx init` 或 `pnx use <文件夹>` 设置。</Step>
  <Step>否则，使用附近找到的服务器。如果有多个，会让你选择。</Step>
</Steps>

## 所有命令通用的选项

| 选项 | 效果 |
| :-- | :-- |
| `-h`、`--help` | 显示 `pnx` 或某个命令的帮助：`pnx start --help`。 |
| `-v`、`--version` | 显示 CLI 版本。 |
| `--json` | 只输出一个 JSON 文档：没有加载动画和进度条。适合脚本使用。 |
| `--no-color` | 不带颜色的纯文本，适合日志和管道。 |
| `--debug` | 出错时显示完整的堆栈，而不是一行提示。 |

```bash
pnx --json info
pnx --json doctor
```

## 状态保存位置 [#state]

CLI 把自己的文件写在 `~/.pnx-cli` 中：`config.json`（默认服务器、中心 token）、版本缓存，以及 [Assistant](/docs/zh/assistant) 的偏好设置。服务器的文件仍保存在服务器文件夹中。

| 变量 | 效果 |
| :-- | :-- |
| `PNX_HOME` | 把状态文件夹放到 `~/.pnx-cli` 以外的位置。 |
| `PNX_API_URL` | 让插件命令使用 `https://powernukkitx.org` 以外的中心。 |
| `JAVA_HOME` | 启动服务器时使用的 Java，优先于 `PATH` 中的 Java。 |
| `PNX_DEBUG` | 等同于 `--debug`。 |
