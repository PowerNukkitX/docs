`pnxcli` 只做一件事：从头到尾创建一个服务器。它会询问位置、版本以及是否启动，其余的都由它完成。对于不常用终端的人来说，这是最快的入门方式。

```bash
pnxcli
```

它的步骤与 [`pnx init`](/docs/zh/cli/server#init) 相同：选择文件夹、PowerNukkitX 版本（默认选中最新稳定版）、下载 jar 和启动脚本。新服务器会成为所有 `pnx` 命令的默认服务器。

## 选项

想跳过某个问题，可以提前给出答案：

| 选项 | 效果 |
| :-- | :-- |
| `--dir <路径>` | 在该文件夹中创建服务器。 |
| `--version <tag>` | 指定确切的 PowerNukkitX 版本。 |
| `--start` | 服务器准备好后立即启动。 |
| `--no-color` | 纯文本，适合管道。 |

```bash
pnxcli --dir ./survival --start
```

<Callout type="info">
  更喜欢窗口而不是终端？[Assistant](/docs/zh/assistant) 能做同样的事，还有创建向导和实时下载进度条。
</Callout>
