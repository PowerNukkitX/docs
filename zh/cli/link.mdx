`pnx link` 把服务器与一个**中心**（Web 控制面板）配对，然后在监管下运行服务器：它启动 JVM、读取控制台并向控制面板报告，控制面板可以回传命令。

<LinkPairing />

<Callout type="info" title="需要支持配对的中心">
  配对需要一个能监管服务器的中心。powernukkitx.org 网站目前还不提供该功能；请把 `--hub` 指向支持它的中心。
</Callout>

## 连接方式

所有连接都**从你的机器**发往中心：中心从不主动连接你。无需开放端口，也无需防火墙规则。中心无法访问时，服务器照常运行。

## 配对

<Steps>
  <Step>在控制面板中生成配对码。</Step>
  <Step>在服务器所在机器上运行 `pnx link <配对码>`。</Step>
  <Step>CLI 用配对码换取 token，保存它，并开始监管服务器。</Step>
</Steps>

```bash
pnx link ABCD-1234 --hub https://hub.example.org --name "Survival"
```

| 选项 | 效果 |
| :-- | :-- |
| `<配对码>` | 控制面板给出的配对码。 |
| `--hub <url>` | 中心的地址。 |
| `--allow <列表>` | 要授予的权限，用逗号分隔。 |
| `--dir <路径>` | 服务器文件夹。 |
| `--memory <大小>` | 服务器内存。 |
| `--name <名称>` | 在控制面板上显示的名称。 |
| `--start` / `--no-start` | 启动服务器，或只附加到它。 |
| `--status` | 显示这台机器与什么配对。 |
| `--forget` | 删除保存的 token。 |

## 权限

控制面板只能做你允许的事。新的配对默认允许 `console` 和 `control`；用 `--allow` 按名称添加其他权限。

| 权限 | 允许控制面板 |
| :-- | :-- |
| `console` | 读取控制台并发送命令。 |
| `control` | 启动、停止和重启服务器。 |
| `players` | 管理玩家，例如白名单。 |
| `worlds` | 处理世界。 |
| `config` | 读取和修改配置。 |
| `files` | 读写服务器文件夹中的文件。 |
| `plugins` | 安装和移除插件。 |
| `backups` | 创建备份。 |
| `schedules` | 运行计划任务。 |

```bash
pnx link ABCD-1234 --allow console,control,backups
```

<Callout type="warn" title="远程命令永远做不到的事">
  文件访问仅限于服务器文件夹，并在解析链接后在你的机器上进行检查。可执行文件和脚本（`.jar`、`.exe`、`.sh`、`.bat`、`.js` 等）可以读取，但绝不能被远程写入。
</Callout>

## 查看与解除

```bash
pnx link --status
pnx link --forget
```
