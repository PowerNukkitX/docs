`plugin` 命令通过与网站相同的 [Web API](/docs/zh/web-api/plugins) 访问[插件中心](https://powernukkitx.org/plugins)。它们只安装**中心已批准的版本**，并在放入 `plugins/` 之前用中心记录的 SHA-256 校验每个 jar。

| 命令 | 作用 |
| :-- | :-- |
| `pnx plugin list` | 浏览中心，星标最多的在前。 |
| `pnx plugin search [关键词]` | 按名称搜索。未提供关键词时会询问。 |
| `pnx plugin info [slug]` | 显示某个插件的完整信息。 |
| `pnx plugin install [slugs]` | 安装一个或多个插件。 |
| `pnx plugin installed` | 列出 `plugins/` 中的内容。 |
| `pnx plugin update [slugs]` | 把插件更新到最新的已批准版本。 |
| `pnx plugin remove [名称]` | 从文件夹中移除插件。 |
| `pnx install <slug>` | 按 slug 安装一个已批准的插件，即中心安装按钮给出的快捷方式。 |

`pnx plugins` 是 `pnx plugin` 的别名。

## 查找插件

```bash
pnx plugin list --sort updated --limit 20
pnx plugin list --query chat
pnx plugin search worldedit
pnx plugin info owner.name
```

`plugin list` 支持 `--sort`（`newest`、`updated` 或 `stars`）、每页结果数 `--limit`、`--page` 和 `--query`。

## 安装与更新

```bash
pnx plugin install owner.name
pnx plugin install owner.one owner.two
pnx plugin update
```

可以指定一个或多个 slug。插件用它的 slug `owner.name` 表示，与插件页面一致。不带 slug 时，`install` 会让你搜索并选择；`update` 会更新它安装过的所有插件。重启服务器以加载它们。

<Callout type="warn">
  `plugin install` 也接受 `.jar` 的直接链接。这样的 jar 没有经过任何审核：只从可信来源安装。
</Callout>

## 查看与移除

```bash
pnx plugin installed
pnx --json plugin installed
pnx plugin remove owner.name
```

不带名称时，`remove` 会显示一个列表供你选择。
