## init [#init]

创建服务器：一个文件夹、PowerNukkitX jar 和启动脚本。别名：`new`、`create`。

```bash
pnx init
pnx init --dir my-server
pnx init --version 1.21.0
```

| 选项 | 效果 |
| :-- | :-- |
| `--dir <路径>` | 创建服务器的文件夹。 |
| `--version <tag>` | PowerNukkitX 版本标签，跳过版本选择。 |

在终端中它会询问缺少的信息；在脚本中（或使用 `--json`）则不提问直接运行。jar 来自 PowerNukkitX 的 GitHub releases，脚本来自 [PowerNukkitX/scripts](https://github.com/PowerNukkitX/scripts)。新服务器会成为默认服务器。

## start [#start]

在前台启动服务器，并使用 PowerNukkitX 所需的 Java 参数。别名：`run`、`up`。

```bash
pnx start
pnx start --memory 4G
pnx start --restart
pnx start --dry-run
```

| 选项 | 效果 |
| :-- | :-- |
| `--dir <路径>` | 指定服务器文件夹，而不是默认服务器。 |
| `-m`、`--memory <大小>` | 启动时的 Java 堆内存，默认 `2G`。 |
| `--restart` | 服务器异常退出时自动重启。 |
| `--dry-run` | 只打印 `java` 命令而不执行。 |

`pnx start` 启动 Java 时全程使用 UTF-8、ZGC 垃圾回收器、`--add-opens` 参数和 `-XX:MaxRAMPercentage=75.0`，让堆内存最多可以增长到机器内存的四分之三。设置了 `JAVA_HOME` 时，会使用其中的 Java。

## stop [#stop]

通过记录的进程 id 停止由 `pnx start` 启动的服务器。别名：`down`。

```bash
pnx stop
```

<Callout type="info">
  想从内部正常关闭，在服务器控制台输入 `stop`：所有内容会先被保存。
</Callout>

## console [#console]

通过 **RCON** 打开正在运行的服务器的控制台。

```bash
pnx console
```

它会读取服务器 `server.properties` 中的 `enable-rcon`、`rcon.port`（默认 `25575`）和 `rcon.password`。RCON 默认关闭；此时 `pnx console` 会告诉你需要开启什么。输入 `exit` 退出。

## logs [#logs]

显示服务器日志并持续跟踪。别名：`log`。

```bash
pnx logs
pnx logs --lines 200
pnx logs --no-follow
```

| 选项 | 效果 |
| :-- | :-- |
| `-n`、`--lines <n>` | 先显示多少行。 |
| `--follow` | 持续输出新写入的行。`--no-follow` 输出后退出。 |

## config [#config]

显示服务器读取的配置，无需打开文件即可查看某个值。

```bash
pnx config
```

## use [#use]

选择所有命令作用的服务器。

```bash
pnx use
pnx use ./my-server
pnx use --clear
```

不带文件夹时，它会列出找到的服务器让你选择。`--clear` 会清除默认服务器。
