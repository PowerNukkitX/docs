本文档使用的术语，以及它们在 PowerNukkitX 服务器上的含义。

| 术语 | 含义 |
| :-- | :-- |
| **基岩版** | 手机、主机和 Windows 上的 Minecraft 版本。PowerNukkitX 为它提供服务。 |
| **BDS** | Bedrock Dedicated Server，Mojang 官方的服务器软件。 |
| **刻（Tick）** | 服务器游戏循环的一步。每秒 20 刻，所以 100 刻就是 5 秒。 |
| **TPS** | 每秒刻数。20 表示正常；低于 20 表示服务器卡顿。 |
| **世界（Level）** | 一个世界。每个世界都是 `worlds/` 中的一个文件夹。 |
| **区块（Chunk）** | 世界中 16 × 16 的一列，作为一个整体生成和加载。 |
| **视距** | 每名玩家能收到周围多少个区块。对性能影响最大的设置。 |
| **管理员（OP）** | 可以执行任何命令的玩家。 |
| **权限节点** | 用点分隔的名称，例如 `nukkit.command.help`，命令或插件在执行前会检查它。 |
| **白名单** | 开启后允许加入的玩家列表（`white-list.txt`）。 |
| **Xbox 验证** | 检查每名玩家的 Xbox 账号。关闭它就是离线模式。 |
| **插件** | 放在 `plugins/` 中的 Java jar，用于添加命令、事件、内容或玩法。 |
| **监听器（Listener）** | 插件中的一个类，其 `@EventHandler` 方法会在事件发生时执行。 |
| **注册表** | 注册自定义方块、物品、实体和配方的地方。请在 `onLoad()` 中注册。 |
| **资源包** | 玩家加入时下载的材质和模型，用于显示自定义内容。 |
| **行为包** | 客户端侧的游戏逻辑。不支持：PowerNukkitX 用 Java 插件实现这些。 |
| **表单** | 显示给玩家的窗口：SimpleForm、ModalForm、CustomForm 或 DDUI。 |
| **代理** | 例如 WaterdogPE 这样的服务器，可以在多个服务器之间转移玩家。 |
| **`pnx.yml`** | 保存所有服务器设置的唯一文件。 |
