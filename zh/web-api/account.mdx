这些接口针对已登录的用户。它们在浏览器中使用 powernukkitx.org 的**会话 Cookie**，而不是 API token：token 只能读取已经公开的内容。

## 你的资料

```text
GET /api/v1/me
```

控制面板中可编辑的设置：简介、链接、所在地、置顶插件、资料可见性和通知偏好。没有会话时返回 `401 unauthorized`。

## 你的 token

```text
GET    /api/v1/me/tokens
POST   /api/v1/me/tokens
DELETE /api/v1/me/tokens/{keyId}
```

| 调用 | 作用 |
| :-- | :-- |
| `GET` | 列出你的 token：名称、密钥 id、创建日期、最后使用时间。永远不包含密文。 |
| `POST` | 根据 `{ "name": "..." }` 创建一个。完整 token 只会在这个响应中出现。 |
| `DELETE` | 撤销带有该密钥 id 的 token。 |

创建和撤销只能从网站本身发起（同源），所以要在控制面板中操作：**Dashboard > Settings > Feed and API**。

## 你的订阅源

```text
GET /api/v1/feed/{key}
```

一个 Atom 订阅源，记录你关注的插件的动态：新版本、审核通过等。每个账户都有自己的秘密 `key`；在 **Dashboard > Settings > Feed and API** 复制订阅源地址，粘贴到任意阅读器即可。密钥更换或错误时返回 `404`，这样阅读器会停止请求失效的地址。
