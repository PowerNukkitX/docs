当某个插件版本存在已知漏洞时，团队会发布公告，插件页面也会显示它。同样的公告也以 [OSV](https://ossf.github.io/osv-schema/) 格式提供，安全扫描工具可以直接读取。

```text
GET /api/v1/advisories/osv
```

响应为 `{ advisories }`：每条已发布公告对应一条 OSV 记录。草稿和已撤回的公告不会出现。

<ApiTry path="/advisories/osv" />

<Callout type="info">
  在 CI 中用扫描工具检查这个订阅源，当你分发的插件出现公告时就能及时收到提醒。
</Callout>
