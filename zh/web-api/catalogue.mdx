这些接口很少变化，缓存时间较长。它们没有参数。

## 分类

```text
GET /api/v1/categories
```

每个可见的插件分类，格式为 `{ id, label }`。在 [`/plugins`](/docs/zh/web-api/plugins) 的 `category` 参数中使用 `id`。

<ApiTry path="/categories" />

## 合集

```text
GET /api/v1/collections
```

已发布的合集：人工挑选的插件列表，每个合集包含它收录的插件。

<ApiTry path="/collections" />

## 徽章

```text
GET /api/v1/badges
```

中心可以授予插件的所有徽章，包括等级和图标。

<ApiTry path="/badges" />

## 精选

```text
GET /api/v1/spotlight
```

团队当前在首页推荐的插件及其说明。没有推荐时 `data` 为 `null`。

<ApiTry path="/spotlight" />
