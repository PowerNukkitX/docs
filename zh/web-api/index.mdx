[powernukkitx.org](https://powernukkitx.org) 中心在 `/api/v1` 下提供 JSON API。网站、[CLI](/docs/zh/cli) 和 [Assistant](/docs/zh/assistant) 搜索插件和下载已批准版本时用的就是这套 API。这些页面介绍的内容全部**只读**，无需账户即可使用。

## 基础地址

```text
https://powernukkitx.org/api/v1
```

每个接口都以 JSON 文档响应 `GET`，只有插件徽章是 SVG 图片，个人订阅源是 Atom XML。

```bash
curl "https://powernukkitx.org/api/v1/plugins?q=economy&sort=downloads"
```

## Token

token 是可选的。它用于标识你的调用，让它们拥有独立且比匿名更高的额度。它**不会开放任何额外数据**：token 能读到的，匿名请求也能读到。

<Steps>
  <Step>用 GitHub 登录 powernukkitx.org。</Step>
  <Step>打开 **Dashboard > Settings > Feed and API** 并创建一个。最多可保留 10 个。</Step>
  <Step>立即复制：它只显示一次，服务器只保存它的哈希。</Step>
  <Step>在 `Authorization` 请求头中发送它。</Step>
</Steps>

```bash
curl -H "Authorization: Bearer pnx_<keyId>_<secret>" \
  "https://powernukkitx.org/api/v1/plugins"
```

token 的格式是 `pnx_`，后接 12 位密钥 id、一个下划线和 64 位密文。格式错误、未知或已撤销的 token 会得到 `401 invalid_token`：它绝不会被悄悄降级为匿名额度。

<Callout type="warn">
  不要把 token 放进公开仓库或在客户端运行的代码。泄露的 token 无法修改任何内容，但别人可以消耗它的额度。在同一个设置页面撤销它。
</Callout>

## 频率限制

额度按分钟计算。

| 调用方 | 额度 | 计入 |
| :-- | :-- | :-- |
| 匿名 | 每分钟 240 次请求 | 你的 IP 地址 |
| 使用 token | 每分钟 600 次请求 | 该 token |
| 服务器列表、插件下载 | 每分钟 60 次请求 | 你的 IP 地址 |

超出额度时，API 返回 `429`，并带有 `Retry-After` 请求头，给出需要等待的秒数。

## 错误

错误以 JSON 返回，包含 `error` 代码：

```json
{ "error": "invalid_query", "issues": [] }
```

| 状态码 | 何时出现 |
| :-- | :-- |
| `400` | 某个查询参数未通过校验。`issues` 会指出是哪个。 |
| `401` | token 无法识别，或已被撤销。 |
| `403` | 该版本存在但尚未批准（下载）。 |
| `404` | 没有这个插件或服务器，或它尚未发布。 |
| `429` | 额度用完。等待 `Retry-After` 秒。 |

## 缓存

列表在边缘缓存一分钟，变化较慢的数据（服务器、合集、安全公告）缓存十分钟。响应带有 `ETag`：发送 `If-None-Match` 的客户端在内容未变化时会收到没有正文的 `304`。
