[服务器目录](https://powernukkitx.org/servers)列出了运行 PowerNukkitX 的已批准基岩版服务器。它的 API 对所有人只读；登记服务器需要在网站上完成。

## 列出服务器

```text
GET /api/v1/servers
```

精选服务器排在前面，然后是其他服务器。响应为 `{ data, total }`。

| 参数 | 作用 |
| :-- | :-- |
| `q` | 按名称搜索。 |
| `category` | 一个分类，例如生存或小游戏。 |
| `region` | 服务器所在地区。 |
| `language` | 服务器使用的语言。 |
| `page` | 页码，从 1 开始。 |

<Callout type="info">
  这个列表有独立额度：每个地址每分钟 60 次请求。
</Callout>

<ApiTry path="/servers" />

## 单个服务器

```text
GET /api/v1/servers/{slug}
```

已批准服务器的公开信息：地址、描述、标签和徽章。未批准的服务器返回 `404`。
